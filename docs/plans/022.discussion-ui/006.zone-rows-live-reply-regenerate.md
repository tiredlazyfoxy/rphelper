# Step 006 — Role-aware zone rows, the live reply, and the Regenerate control

## Goal

Make the zone render what the assistant did:

- assistant rows through `AssistantBody`, with thinking collapsed;
- tool rows as collapsed `ToolBlock`s, with **no** edit control (021 D8);
- a read-only mode on `ZoneMessage`, for `007`'s discussion rows;
- the **live reply** (`LiveMessage`) beneath the zone rows while streaming, with its thinking
  and tool blocks open (D6, U4);
- the **Regenerate** button after the last zone row when `showsRegenerate` (D8, U3).

## Interface intent

**`app/ZoneList.tsx`** (changed)

- **`ZoneMessage`** (exported) gains an **`editable`** prop (boolean, default true). Its body
  is chosen by role:
  - **`user`**: `MessageBody` `"painted"`, exactly as today.
  - **`assistant`**: `AssistantBody` with `live` false, so thinking starts collapsed.
  - **`tool`**: `ToolBlock` with:
    - name from `tool_name`;
    - status `"ok"` when `tool_status` is `"ok"`, else `"failed"`;
    - arguments from `tool_args`, or `{}` when null or absent;
    - summary = the row's `text`;
    - starts collapsed.

  The author labels are unchanged ("You", "Assistant", "Tool").
- **The "Edit message" control** renders iff `editable` is true **and** the role is not
  `"tool"`. Otherwise it is **absent**, not disabled.
- **The in-place editor** (013 D10) is unchanged. For an assistant row it holds the row's
  **raw stored text**, think tags included (D10).
- **`ZoneList`**:
  - It still renders the "Zone messages" list only when `zone` is non-empty, with each row an
    editable `ZoneMessage`.
  - **Beneath the list** (rendered even when `zone` is empty), it adds:
    1. `LiveMessage` for the state;
    2. when `showsRegenerate(state)`, a labelled Mantine `Button` **"Regenerate"** (subtle,
       `IconRefresh` left section at the inline size) that calls `regenerate(state, signal)`
       with the `signal` prop `ZoneList` already receives. When `showsRegenerate` is false,
       the button is **absent**, not disabled.
  - No Send, Settle, Stop or discard control lives here.

**`app/LiveMessage.tsx`** (new)

- **`LiveMessage`**: an `observer` component. Props: the `StreamState`.
- When `isStreaming(state)` is false it renders nothing.
- Otherwise it renders a region with accessible name **"Live reply"**, containing:
  - the author label **"Assistant"**;
  - one `ToolBlock` per live tool call in list order, each **starting open**, with its name,
    status, arguments and summary;
  - then `AssistantBody` over the streaming text with `live` **true**.
- It has **no edit control** and no other control.
