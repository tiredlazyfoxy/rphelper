# Step 004 — step-specific context

## The rotated chevron through `IconButton`

`IconButton`'s props are fixed: `icon`, `label`, `onClick`, `disabled?`, `color?` and
`sizeVariant?`. They take no style and no children, and `ui-conventions.md` forbids widening
them. `icon` is a component receiving `size` and `stroke`.

To rotate the chevron, pass a small local component that renders `IconChevronDown` with the
size and stroke it is given plus an inline `style` transform (`rotate(-90deg)` when collapsed,
none when open). Define it once at module level per open state, or pick between two such
components. Do not create one per render. `src/shared/IconButton.tsx` is out of scope.

## `MessageBody`

`MessageBody` (013 `004`) is a plain function with variants `"painted"`, `"decision"` and
`"plain"`. Painted renders a wholly-parenthesised text as the out-of-character card
(`data-paren="ooc"`, label "Out of character"). Otherwise it renders prose through
`react-markdown`, with each `(( ))` fragment as a chip. `AssistantBody` passes each answer
segment's text to it unchanged. `MessageBody.tsx` is not modified.

## Styling

- Mantine only: `Group`, `Text` (`c="dimmed"`, `style={{ whiteSpace: "pre-wrap" }}`),
  `Code block`, `Stack`, `Box` with a light border via style props.
- No `.css`, and no `Collapse`, which D5 does not use because the body is conditionally
  rendered.
- Tabler icons in decorative use (`IconBulb`, `IconTool`) take the inline size (16 / stroke
  1.5) and are not buttons.
