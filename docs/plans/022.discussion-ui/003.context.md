## Parser notes

- **Scanning.** Find `<think>` from the current position. The block ends at the first
  `</think>` **after** that opener. If there is none, the think segment runs to the end of the
  text and is not closed. Continue after the closer.
- **Stray closers.** A `</think>` before any opener, or between blocks, is ordinary answer
  text (row 7).
- **When a block is found**, answer pieces are trimmed and empty ones dropped (rows 3, 4, 8).
  **When none is found**, the whole input is one answer segment, untrimmed (rows 1, 2, 10).
- **Think text is never trimmed.** Row 8's think text is exactly `x` + newline + `y`.
- **Live use.** The function runs on every token of the streaming text, so a single linear
  index scan is the right shape.
