# Step 010 — The session configuration modal

## Goal

Add `app/SessionConfigModal.tsx`: a Mantine `Modal` titled "Session configuration" that
edits the session's system prompt, three tool switches, RP language and preferred
language. Each setting has an explicit Inherit choice and shows what it would inherit and
from where. A fresh draft is created per open, and Save sends only what changed (D18,
UC-049).

frontend/src/app/SessionConfigModal.tsx

## Interface intent

**`app/SessionConfigModal.tsx`** (new)

- **`SessionConfigModal`**: component. Props: `opened` (boolean), `sessionId` (string),
  `configuration` (the loaded `SessionConfiguration`), `onClose`, and `onSaved` (receives
  the saved `SessionConfiguration`). A Mantine `Modal` titled **"Session configuration"**
  whose body is **mounted only while open**. The body creates a `SessionConfigDraft` from
  `sessionId` and `configuration` once with `useState`, so every open starts fresh.
- The body (an `observer`) renders, in order:
  - **System prompt**: a `SegmentedControl` labelled **"System prompt"** with
    **"Inherit"** / **"Set"**; on Set, a `Textarea` **"Session system prompt"** (autosize)
    bound to the draft text; below, the inherited line: **"Inherited from the
    character:"** followed by the inherited prompt as plain text, or **"Nothing to inherit:
    the character has no system prompt."**;
  - **Tools**: for each of **"Memo search"**, **"Session search"**, **"Web search"**, a
    `SegmentedControl` labelled with that name with **"Inherit"** / **"On"** / **"Off"**,
    and its inherited line: **"Inherited from the character: on"** / **"… off"** when the
    inherited level is `character`, otherwise **"Inherited: on (default)"**;
  - **Languages**: `SegmentedControl`s **"RP language"** and **"Preferred language"**
    with **"Inherit"** / **"Set"**; on Set, a text input **"Session RP language"** /
    **"Session preferred language"**; the inherited line **"Inherited from your settings:
    <value>"** or **"Nothing to inherit: no default in your settings."**;
  - each field's error from `errors(draft)` under its input; the general error in an
    `Alert` above the buttons;
  - buttons **"Cancel"** (calls `onClose`, sends nothing) and **"Save"** (enabled iff
    `canSubmit`; runs `submitSessionConfig` with an `onSaved` that calls the prop
    `onSaved` and then `onClose`).
- No model control, no notification, no confirm.

## Definition of done

1. `[test]` Opened over a configuration where everything is inherited (character prompt
   "Stay in character.", character memo search off, user RP language "Japanese", nothing
   else set), the modal titled "Session configuration" shows every source control on
   "Inherit" and no session input. The lines are "Inherited from the character:" with
   "Stay in character.", "Inherited from the character: off" for memo search, "Inherited:
   on (default)" for session search and web search, "Inherited from your settings:
   Japanese", and "Nothing to inherit: no default in your settings." for the preferred
   language. (US-108.AC-1, US-108.AC-2, D18)
2. `[test]` Choosing "Set" for the system prompt shows "Session system prompt" prefilled
   with "Stay in character.". Typing "Be terse." and pressing "Save" sends exactly
   `{"system_prompt":"Be terse."}`. On 200, `onSaved` receives the served configuration
   and `onClose` is called. (US-060.AC-1, UC-049)
3. `[test]` Opened over a configuration whose session overrides web search (off) and the
   RP language ("French"): those controls show "Off" and "Set" with "French". Switching
   both to "Inherit" and saving sends exactly `{"tool_web_search":null,"rp_language":null}`.
   (R1 — clearing restores inheritance; US-061.AC-2, US-062.AC-2)
4. `[test]` "Set" for the preferred language with an empty input shows "Enter a language,
   or choose Inherit." and "Save" is disabled. Typing a value enables it. (D18)
5. `[test]` Pressing "Save" with nothing changed sends no request, calls `onSaved` with
   the original configuration, and closes. "Cancel" sends nothing and calls `onClose`
   only. (D18)
6. `[test]` A failed save shows "Could not save the session configuration." in the modal,
   keeps the typed values, does not call `onSaved` or `onClose`, and raises no
   notification. (D19)
7. `[test]` Closing after typing (without saving) and reopening shows the controls seeded
   from the `configuration` prop again, not the abandoned typing (fresh draft per open).
   (`ui-conventions.md` draft lifetime)
8. `[test]` The modal contains no control labelled "Model" and no RP-language or
   preferred-language control is labelled as a character setting. The only language
   inherited line names "your settings". (UC-077 — the picker is the one model control;
   US-061.AC-3)
9. `[manual/live]` In a browser, in both colour schemes: the modal opens over the session,
   the inherited lines read clearly beside each control, a long inherited system prompt
   wraps without widening the modal, and the session textarea grows with its content.
