# Step 009 — The session configuration draft

## Goal

Add `app/sessionConfigDraft.ts`, the MobX draft behind the session configuration modal
(D18). It is seeded from a `SessionConfiguration`, holds an Inherit / Set (or Inherit /
On / Off) choice and text per setting, and validates. Its submit sends only the
overrides that changed.

## Source files

frontend/src/app/sessionConfigDraft.ts

## Test files

frontend/tests/app/sessionConfigDraft.test.ts

## Interface intent

**`app/sessionConfigDraft.ts`** (new)

- **`TextSource`**: `"inherit"` or `"set"`. **`ToolChoice`**: `"inherit"`, `"on"` or
  `"off"`.
- **`SessionConfigDraft`**: data class, observable fields only, constructed from a
  session id and the loaded `SessionConfiguration` (kept as `original`):
  - `systemPromptSource` + `systemPrompt`; `rpLanguageSource` + `rpLanguage`;
    `preferredLanguageSource` + `preferredLanguage`. A source starts `"set"` when the
    setting's `session` value is non-null, else `"inherit"`. A text starts from the
    `session` value, else the `inherited` value, else `""`;
  - `toolMemoSearch`, `toolSessionSearch`, `toolWebSearch`: `"inherit"` when the
    setting's `session` is null, else `"on"` / `"off"` from it;
  - `serverErrors` (field key → message, plus a general key), `submitStatus` (`"idle"`,
    `"submitting"`, `"done"`).
- **`clientErrors`**: pure. A text setting on `"set"` with blank text gets **"Enter a
  system prompt, or choose Inherit."** (system prompt) or **"Enter a language, or choose
  Inherit."** (each language), keyed by that setting's field.
- **`errors`**: pure; client errors merged with `serverErrors`.
- **`canSubmit`**: pure; no client errors and not submitting.
- **`patchOf`**: pure. Builds the `SessionConfigurationPatch` holding **only** the
  settings whose resulting session override differs from `original`'s `session`. A
  resulting override is null for `"inherit"`. For `"set"` it is the system prompt text
  as typed (verbatim) or the language text trimmed. For a tool it is `true` / `false`. No
  `model` key, ever.
- **`submitSessionConfig`**: the draft, an `onSaved` callback receiving a
  `SessionConfiguration`, and an optional signal. Does nothing unless `canSubmit`. An
  empty `patchOf` → `onSaved(original)` with no request. Otherwise it sets
  `"submitting"` and PATCHes. On success `"done"` and `onSaved(response)`. On any failure
  it sets the general error **"Could not save the session configuration."** and returns
  to `"idle"`. No code is branched on (a 422 is general too). Never rejects.

## Definition of done

1. `[test]` Seeded from a configuration where the session overrides the system prompt
   ("S") and web search (off), and inherits everything else (character prompt "C", user
   RP language "Japanese"): `systemPromptSource` is `"set"` with text "S",
   `toolWebSearch` is `"off"`, the other tools are `"inherit"`, `rpLanguageSource` is
   `"inherit"` with text "Japanese", and `preferredLanguage` text is `""` when nothing is
   inherited. (D18)
2. `[test]` `patchOf` on an untouched draft is empty. Switching the system prompt to
   `"inherit"` gives exactly `{ system_prompt: null }` (R1 — clearing restores
   inheritance). Setting memo search to `"off"` gives exactly `{ tool_memo_search: false
   }`. Setting web search from `"off"` to `"inherit"` gives `{ tool_web_search: null }`.
   (US-060.AC-1, US-062.AC-2)
3. `[test]` Setting the RP language source to `"set"` with text `"  French "` gives
   `{ rp_language: "French" }`. A system prompt set to `"  Be terse.\n"` is sent with
   those exact characters. A text on `"inherit"` is ignored whatever it holds.
   (US-061.AC-2, D6)
4. `[test]` A `"set"` text setting with blank text yields its client error, and
   `canSubmit` is false. Switching it to `"inherit"` removes the error. (D18)
5. `[test]` `submitSessionConfig` with a non-empty patch sends `PATCH
   /api/sessions/<id>/configuration` with exactly `patchOf`'s keys and no `model` key.
   On 200 `submitStatus` is `"done"` and `onSaved` receives the served configuration.
   (US-060.AC-1, US-061.AC-2, US-062.AC-2)
6. `[test]` `submitSessionConfig` with an empty patch makes no request and calls `onSaved`
   with the original configuration.
7. `[test]` A failed PATCH (500 or 422) sets the general error "Could not save the
   session configuration.", returns `submitStatus` to `"idle"`, keeps every field as
   typed, does not call `onSaved`, and does not reject. `notifyFailure` is not called.
   (D19)
