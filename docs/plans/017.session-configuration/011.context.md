## Select value encoding

Mantine `Select` values are strings. Encode an option's value from both parts of the
model ref with a separator that cannot occur in a decimal id (the first `:`, for example
`"<server_id>:<model_name>"`), and decode by splitting at the first separator. Never use
the list index (the list can be re-read while the dropdown is open), and never parse the
id. The skeleton freezes the helper if it is exported. A local helper inside the
component is fine.
