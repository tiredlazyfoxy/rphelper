## The ordering inside the paste handler

1. read the text; 2. if not blank and enormous → `notifyWarning` (sync, not awaited);
3. if *partner* → `preventDefault()` and `filePastedPartner(...)` (not awaited by the
handler, as in 013); else return without touching the event. The warning never sits
between the paste and its effect in a way that could stop it: a throwing outlet is not a
concern the handler guards against (Mantine's `show` does not throw), but nothing after
step 2 is conditional on it.
