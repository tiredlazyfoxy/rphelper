# Step 004 — step-specific context

## Declared behaviour this sweep re-asserts (from planned step files)

- **025 hybrid port** — every variant requires a user id; the candidate
  subquery carries `user_id = :user_id`. The `vec0` and FTS5 tables have **no**
  user column; they are scoped only through candidate ids (025/004 DoD-7). This
  is why DoD-2 targets B's material with both a text match and a matching fake
  embedding: a variant that skipped the candidate subquery would surface B.
- **026** `search_memos` (DoD-9) and its adapter (026/002 DoD-5/7); predicate
  `is_enabled AND NOT is_forced` (R3) — so B's *searchable* memos are the
  meaningful targets; disabled/forced ones never come back to anyone via tools.
- **027** `search_sessions` (DoD-5), excerpts (027/002 DoD-2), adapter (027/003
  DoD-6/7). Character-boundary crossing within one user (UC-054) is 027's and is
  not re-tested here.
- **021/004** `build_tool_scope` → a scope of user, session, character, setup
  derived from the owner-scoped session lookup; tool declarations expose only
  `query`; extra model keys never alter scope (DoD-1/4/8 there).
- **028** web_search reads no instance data; the outbound request carries no
  decimal id (028/002 DoD-5). DoD-7 here reuses that assertion across the whole
  seeded world (every seeded id of A and B is a candidate leak).
- **029** — five groups (029/003 DoD-5), LIKE corpora (029/001 DoD-4),
  orchestrator (029/002 DoD-7). my-search legitimately returns the **owner's**
  disabled memos (R3) — positive controls may include them for B.
- **024/004-006** — memo, settle, reopen, entries, edit and persona fan-out
  paths write `memo_vec` / `session_vec` / FTS; `write_vector` / `delete_vector`
  take **no** user id (caller-scoped). No 024 step had a cross-user DoD — DoD-9
  and DoD-10 close that gap.
- **020/002** `assemble_context` (DoD-7/8 there).

## Mechanics

- Compare index state by reading the derived tables directly in the test
  (rowids/keys and stored content for B's ids before and after). Direct reads
  are fine in a test; they are not an admin surface.
- The fake embedding client should map each sentinel to a distinct, stable
  vector so a nearest-neighbour hit on B's row is guaranteed if the user
  predicate were missing.
- DoD-7's outbound request is captured at the web-search HTTP seam declared by
  028 (name from 028's `## Skeleton`).
