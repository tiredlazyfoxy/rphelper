# Step 004 — step-specific context

Feature-wide facts are in `context.md`: the wire contract, D8 (landing params), U4,
the frontend constraints (pure data contracts, ids are strings) and Test conventions. Only
what is narrow to this step is below.

## Targets

| Hit | Path |
|---|---|
| character | `/characters/<id>` |
| setup | `/characters/<character_id>` (setups have no route) |
| session | `/sessions/<id>` |
| entry | `/sessions/<session_id>?entry=<id>` |
| memo, scope `user` | `/settings` |
| memo, scope `character` | `/characters/<character_id>` |
| memo, scope `setup` | `/characters/<character_id>` |
| memo, scope `session` | `/sessions/<scope_id>?notes=open` |

Ids are decimal digit strings, so they need no encoding; `encodeURIComponent` on them is
harmless and matches `sessionsApi.ts`'s path helpers.

## Borrowed interfaces (built source)

- `shared/api.ts`: `apiGet<T>(path, signal?)`; paths start with `/api/`. An abort rejects
  with the original `AbortError` (not wrapped).
- `shared/apiError.ts`: `ApiError` (`code`, `message`, `detail`, `status`) and the
  `isApiError` guard — the one sanctioned narrowing in a `catch`.
- `app/sessionsApi.ts` is the typed-module example (types + `encodeURIComponent` path
  helpers).
- `app/charactersState.ts` is the state-module example: class with observable fields +
  `makeAutoObservable(this, {}, { autoBind: true })`; free `loadX(state, signal?)` with
  `runInAction`; an `isAbortRejection` check before writing on failure.
