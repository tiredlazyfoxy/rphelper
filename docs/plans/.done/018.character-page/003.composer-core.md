# Step 003 — The shared composer core

## Goal

Split 013's `Composer` into a presentational `ComposerCore` (the auto-growing text area,
the stream-column geometry, the labelled Send, the enormous-paste warning and the optional
send-blocked reason) and a stream `Composer` rebuilt on it. The stream composer's public
props and behaviour do not change (D4).

## Interface intent

**`app/ComposerCore.tsx`** (new)

- **`ComposerCore`**: a presentational component that holds no MobX state of its own and
  makes no request. Props:
  - the **draft** text and a **draft-change** callback;
  - a **send** callback and whether **Send is enabled**;
  - an optional **send-blocked reason** (a sentence or null). When non-null, Send is
    disabled whatever else says, and the sentence renders as text in the composer;
  - an optional **paste hook**, called with the pasted plain text and the paste event
    **after** the core's own paste handling;
  - an optional slot rendered **under the text area** and an optional slot rendered **in
    the button row beside Send**.
- Renders, in the stream column (`maw` 720, centred, `px` 18, Mantine style props): a
  Mantine `Textarea` labelled **"Composer"** with `autosize`, a `minRows` of about 42px, no
  `maxRows` and no resize handle, showing the draft; the under-area slot; then the button
  row with a labelled **"Send"** button (013's secondary variant) followed by the
  beside-Send slot; and the reason text when present.
- **Paste**: reads the clipboard's plain text. When that text is not blank and
  `isEnormousPaste` holds, it calls `notifyWarning` with 014's paste identifier
  synchronously and first. Then it calls the paste hook if one is given. The core never
  prevents the default itself: a host that wants to stop the insertion does it in its hook.

**`app/Composer.tsx`** (changed; 013 `006`, edited by 014 `003` and 017 `011`)

- **`Composer`**: props unchanged (`state`, `signal?`, `sendBlockedReason?`). It renders
  `ComposerCore` with: the draft bound to `state.draft` / `setDraft`; Send enabled iff
  `canSend(state)` and calling `sendComposer`; the reason passed **only when the effective
  position is *my turn***, null otherwise (017 D17); a paste hook that, on *partner*,
  prevents the default and hands the text to `filePastedPartner`, and on *my turn* does
  nothing; the preview line in the under-area slot; "Settle" and, when shown, "Discard
  empty zone" in the beside-Send slot. Behaviour is exactly 013 `006` + 014 `003` +
  017 `011`.

## Definition of done

1. `[test]` `ComposerCore` with draft "Hello" renders a textbox "Composer" holding "Hello"
   and an enabled "Send". Typing calls the draft-change callback with the new text.
   Pressing "Send" calls the send callback once. With Send not enabled, "Send" is disabled
   and pressing it calls nothing. (D4; `ui-conventions.md` labelled Send)
2. `[test]` `ComposerCore` with a send-blocked reason "Cannot send: no model is enabled on
   this instance." shows that sentence and disables "Send" even when Send is enabled. With
   the reason null or omitted, no reason text is shown. (D4, 017 D17 — mechanism lives in
   the core)
3. `[test]` `ComposerCore`: pasting a 128,001-character non-blank text calls
   `notifyWarning` once with the paste identifier **before** the paste hook runs, and then
   calls the hook with that text. The paste is not default-prevented by the core. A short
   paste and a 128,001-character whitespace-only paste call no `notifyWarning`, and the hook
   is still called. With no hook given, a paste neither throws nor is prevented. (US-035.AC-1,
   US-035.AC-2, D4)
4. `[test]` `ComposerCore` renders the under-area slot's content after the text area and
   the beside-Send slot's content after "Send" in document order, and nothing when they are
   omitted. It renders no "Settle", no "Entry kind" group and no "Discard empty zone" of its
   own. (D4, US-117.AC-4 — the core carries no kind switch)
5. `[test]` 013 `006`'s and 017 `011`'s assertions in `tests/app/Composer.test.tsx` and
   014 `003`'s in `tests/app/ComposerPasteWarning.test.tsx` keep passing against the
   rebuilt `Composer`. An assertion is amended only where it pins internal structure
   rather than behaviour, and each amendment is named in `## Tests`. (D4 — public
   behaviour unchanged)
6. `[test]` `Composer.tsx`'s source (read from disk) renders `ComposerCore` and contains no
   `Textarea` of its own, and `ComposerCore.tsx` is the only `src/app` module that imports
   `notifyWarning`. (D4 — one composer, one paste-warning site)
7. `[manual/live]` In a browser on a session: the composer looks and behaves as before (≈42px
   start, grows with no scrollbar, no handle, 720px / 18px column, preview line, Settle,
   Discard, partner paste filing, the enormous-paste warning). (D4)
