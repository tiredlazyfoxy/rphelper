## Id-minting order (what DoD-3 leans on)

Session id first, message id second. Both come from the injected generator, which is the
test seam: a generator whose second `next_id()` raises fails the message insert after the
session insert has run inside the same transaction. A failure after the insert is the case
that proves the rollback. A failure before it would prove nothing.
