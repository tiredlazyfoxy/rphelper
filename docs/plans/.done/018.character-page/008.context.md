## Why `submitStatus` is not the save flag

`submitStatus` disables Archive / Restore and gates the create. A blur-save must not
disable Archive, and a name save must not block a persona save. So the two commits track
their own in-flight markers, and `submitStatus` keeps its 009 meaning: create, archive,
restore.

## Server trimming

The server strips `name` (009 D8). A commit that sent "  Aria " gets "Aria" back. The
draft still equals what was sent, so it adopts "Aria". A later commit then compares "Aria"
with "Aria" and sends nothing.
