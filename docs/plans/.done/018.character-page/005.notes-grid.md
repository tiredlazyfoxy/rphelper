# Step 005 — The character's notes as a reorderable grid

## Goal

Factor `MemoChainSection`'s drag sensors and announcements into `app/memoDnd.ts`. Give
`MemoLevelGroup` an opt-in grid layout, using the rect sorting strategy when reorderable.
Make `CharacterNotesSection` render its one level as a reorderable grid inside its own
drag context, wired to 016's drop effect. The note card itself is not touched (D8).

## Interface intent

**`app/memoDnd.ts`** (new)

- **Sensors hook**: returns the sensor set 016 D8 fixes: a `PointerSensor` with an
  activation distance of **6px**, and a `KeyboardSensor` using
  `sortableKeyboardCoordinates`.
- **Announcements builder** (pure): takes the groups on screen as an ordered list, each
  with its title and its saved note ids in order. It returns dnd-kit announcements that
  name a note by **its position in its group and the group's title**, never by its id
  (016 D8). An id it cannot place yields a generic message that still contains no id.

**`app/MemoChainSection.tsx`** (changed; 015 `008`, edited by 016 `004`)

- Its `DndContext` takes its sensors from the hook and its announcements from the builder,
  fed from its level groups and their titles. Its drag-end handling, its groups, their
  order and `reorderable` are unchanged.

**`app/MemoLevelGroup.tsx`** (changed; 015 `007`, edited by 016 `003`)

- New optional **layout** prop, list or grid, defaulting to list. **List** is exactly
  today's rendering. **Grid** renders the **same** list and listitems (the new note first,
  then the saved notes, with identical card content, flags, reach line and failures) laid
  out as a responsive multi-column grid through Mantine props or inline style only. With
  `reorderable`, the per-level `SortableContext` uses the **rect** sorting strategy in
  grid and the vertical strategy in list. Every other prop and behaviour is unchanged.

**`app/CharacterNotesSection.tsx`** (changed; 015 `009`)

- Still creates and loads its one `MemoLevelState("character", id)` and retries as
  before. It now renders its `MemoLevelGroup` titled "Notes" with layout **grid** and
  **`reorderable`**, inside its **own** `DndContext` configured with the hook's sensors and
  the builder's announcements (one group, "Notes"). Its drag-end calls 016's drop effect
  with its one level state, the active id and the over id (as strings or absent).
