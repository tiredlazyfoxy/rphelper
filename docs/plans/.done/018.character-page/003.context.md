# Step 003 — step-specific context

Feature-wide facts are in `context.md`: **D4**, "Build prerequisites" (013 / 014 / 017 are
declared, B), "Test conventions". Only what is narrow to this step is below.

## The composer as declared (B — re-verify at build time)

- 013 `006`: `Composer` is an `observer` with props `state` (`StreamState`) and `signal?`.
  It renders the `Textarea` "Composer" (`autosize`, `minRows` ≈ 42px, no `maxRows`), the
  preview line from `settlePreviewOf` (three fixed sentences, 013 `context.md` strings
  table), the secondary "Send" (`canSend`, `sendComposer`), the primary "Settle"
  (`canSettle`, `settleComposer`, disabled not hidden on *partner*) and the "Discard empty
  zone" `IconButton` (`IconX`, present only when `showsDiscard`). On *partner* a paste is
  default-prevented and filed with `filePastedPartner`, read at paste time through
  `effectiveKind`. `KindSwitch` is a **sibling**, not inside the composer (013 `006`
  context "Placement of the switch").
- 014 `003`: the paste handler runs on both positions. It reads
  `event.clipboardData.getData("text/plain")` and calls `notifyWarning(<paste id>)` first
  when the text is non-blank and `isEnormousPaste(text)` holds. `pasteCost.ts` exports
  `isEnormousPaste` and the two constants. `shared/notifyWarning.ts` exports
  `notifyWarning` and the closed identifier set.
- 017 `011`: optional `sendBlockedReason` (string or null, default null). On *my turn* a
  non-null reason disables Send and shows the reason. On *partner* nothing changes, and
  Settle is never affected.

## What moves where

| Concern | Lives in |
|---|---|
| `Textarea`, `autosize`, `minRows`, no handle, `maw` / `px` | core |
| "Send" button | core |
| enormous-paste warning | core |
| reason text + Send disable | core (the host decides whether to pass a reason) |
| partner-paste prevent + filing | stream `Composer` (paste hook) |
| preview line | stream `Composer` (under-area slot) |
| "Settle", "Discard empty zone" | stream `Composer` (beside-Send slot) |

The core is the one place the composer's look and conventions are written. The hosts add
only what is theirs.

## Notes for the skeleton

- Prop names are the skeleton's to freeze. The core must not import `streamState.ts`, any
  API module or the router. Its `notifyWarning` import is its only effect.
- Order inside the paste handler is load-bearing: warning first (014 D5: synchronous,
  never blocking), hook second, default never prevented by the core.
