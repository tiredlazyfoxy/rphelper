# Step 007 — step-specific context

## Built touch sites (013 `004`, 014)

- `StreamRecord.tsx` renders `ul[aria-label="Settled record"]`, one `observer` `StreamEntry`
  `li` per entry. Each entry has:
  - a kind label ("Partner" / "My turn" / "Decision");
  - an actions `Group` revealed on hover, `focus-within` or `(hover:none)`, holding "Edit
    entry", "Copy as plain text" (turns only), and "Re-open last entry" (`IconArrowBackUp`)
    when it is the last entry and `showsReopen`;
  - a body through `MessageBody` (plain / decision variants).
- `StreamRecord` receives the `StreamState`. Pass it to `DiscussionGroup` so `ZoneMessage`
  gets the props it requires. With `editable` false, `ZoneMessage` never calls an effect.

## Nesting

- The discussion list is a `ul[aria-label="Discussion messages"]` **inside** the entry's
  `li`.
- Tests that count "Settled record" items must use direct children or scope by list label.
  The nested items are only present while a group is open, so collapsed groups add no
  `listitem`s.

## 013 / 014 test amendment rule

The collapsed header adds one button ("Show discussion") and two texts ("Discussion",
"Read-only") per non-partner entry. If an existing `StreamRecord.test.tsx` assertion counts
all buttons in an entry, or matches text that now also matches "Discussion", rewrite only
that expectation. Keep its title and append ` — DoD-9 (022 007)`. Otherwise the file is not
touched.

## Test wiring for DoD-8

- `settleComposer` is 013 `003`'s effect, with 019 D16's prefix. With no compose in flight it
  issues `POST /api/sessions/<id>/settle`, then re-reads `GET …/entries` and `GET …/zone`.
- Render `StreamRecord` and `ZoneList` side by side inside one `<AppProviders>` with the same
  state. That is enough to observe the collapse. `SessionStream` constructs its own state and
  cannot be seeded.

## Loader

- Mantine `Loader` with no text. Tests wait for the list or for the empty / failure line with
  `findBy…`, and do not assert the loader.
- Count text: "Discussion (N)" uses the number of rows served, with N = 0 for an empty list.
  Before any successful load the header reads exactly "Discussion".
