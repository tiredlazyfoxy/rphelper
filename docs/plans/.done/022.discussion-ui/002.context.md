## Seeding

Tests seed rows raw through the file-local `RAW_MESSAGES_INSERT` / `_raw_message(...,
related_to, settled_at)` pattern.

- **Settled entry:** `settled_at` set, `related_to` NULL, `kind` set.
- **Buried row:** `related_to` = entry id, `settled_at` NULL, `kind` NULL.
- **Zone row:** both NULL.
- **Tool rows:** use `001.context.md` row 3's `tool_name` / `tool_payload`.

## Why not reuse PATCH's 404 for a missing group

A settled entry with nothing buried is a valid entry with an empty discussion. It answers 200
with an empty list, not 404. The client renders "No discussion behind this entry." (`007`).
