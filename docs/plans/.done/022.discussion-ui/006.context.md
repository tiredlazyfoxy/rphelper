# Step 006 — step-specific context

## Built touch sites (013 `005`)

- `ZoneList` is an `observer` with props `state` and an optional `signal`. It renders
  `ul[aria-label="Zone messages"]`, one item per zone row, and **renders nothing** when the
  zone is empty.
  - This step keeps the list's empty-zone absence.
  - The component now returns a fragment, so `LiveMessage` and "Regenerate" render even with
    an empty zone. A compose's live reply can start before `accepted` re-reads the user row.
- `ZoneMessage` is an exported `observer` `li` with:
  - an `AUTHOR_LABELS` map;
  - an "Edit message" `IconButton` (`IconEdit`) on every row today;
  - a body of `MessageBody variant="painted"`, or a `Textarea` "Edit message text" while
    editing;
  - commits on blur through `editZoneMessage(state, id, text, signal)` (013 `003`).

  The `editable` prop gates the button and therefore the editor. With `editable` false the
  editor can never open.
- **`SessionStream.tsx` is not modified.** 013 `007` creates the mount `AbortController` and is
  expected to pass its signal to `ZoneList`. If it does not, "Regenerate" passes the
  `undefined` it receives. `regenerate` then still works, just without the unmount link. The
  coder records that in `status.md` "Notes & Issues" rather than widening scope.

## Live reply placement

- The live reply is a sibling **after** the `ul`, not an `li` inside it. 013's tests count
  the "Zone messages" items, and a transient item would perturb them.
- Region semantics: a Mantine `Box component="section"` with `aria-label="Live reply"`
  exposes role `region`.
- Tests scope "Assistant" lookups to the region or to a list item, because both the zone row
  and the live reply carry that label.

## Regenerate placement

"Regenerate" is the last element of the zone region. Because it renders only when not
streaming, it never sits beside the live reply.
