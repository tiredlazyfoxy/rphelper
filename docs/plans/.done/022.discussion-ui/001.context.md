## Touch sites

- `StreamMessage` today has the eight 012 fields. 021 `001` appends `tool_name` and
  `tool_payload` with defaults. This step appends `tool_status` and `tool_args` after them,
  with defaults.
- `_to_message` is the shared row → `StreamMessage` mapper. Where 021's
  `append_tool_message` and 019's `append_assistant_message` build their result is the
  coder's to find. DoD-6 pins the tool path.
- The router's `_message_to_response` uses `MessageResponse.model_validate(...,
  from_attributes=True)`. It needs no change: adding the three fields to the model is enough,
  and **not** adding `tool_payload` is what keeps it off the wire. `routers/stream.py` is not
  in this step's scope.
- `tool_args` on the model must serialise as a JSON object. Its values are arbitrary JSON.
