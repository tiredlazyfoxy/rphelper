# Step 004 — The workspace shell component and the in-entry routes

## Goal

Add `WorkspaceShell` — the `.app` grid element whose left column renders the expanded
column or the rail (search, new character, expand), with the user menu as its footer in
both, the collapse persisted on the toggle and the narrow-width overlay — and `App`, the
flat in-entry route table rendering every route inside that one shell (D3, D4, D5, D11).

## Interface intent

**`app/WorkspaceShell.tsx`** (new)

- **`WorkspaceShell`** — `observer` component; props: the signed-in `user`
  (`CurrentUser`), the `storage` (`LayoutStorage` or `null`) and `children` (the centre
  column's content). It:
  - creates its `ShellState` once with `useState(() => createShellState(storage))`;
  - reads narrow from Mantine's `useMediaQuery` with `NARROW_VIEWPORT_QUERY`, configured so
    the first render already uses the real match (no effect-deferred initial value);
  - renders one element with class `shellClassName(state, narrow)` containing exactly two
    children: a `nav` element with class `app-nav` and accessible name **"Workspace
    navigation"**, and a `main` element with class `app-main` holding `children`;
  - in the nav element, when `showsRail(state, narrow)`: the **rail** — `IconButton`s
    **"Search"** (`IconSearch`, router navigation to `/search`), **"New character"**
    (`IconPlus`, router navigation to `/characters/new`) and **"Expand tree"** (`IconMenu2`,
    `expandTree`), then `UserMenu` with `compact` true at the foot;
  - otherwise the **expanded column** — an `IconButton` **"Collapse tree"** (D10's
    provisional `IconChevronLeft`, `collapseTree`) at the top, an empty body, then `UserMenu`
    with `compact` false at the foot;
  - closes the overlay (`closeOverlay`) whenever the router location changes and whenever
    narrow changes value;
  - gives both columns the body background through Mantine style props, so the `.app`
    background shows only through the `1px` gap.

**`app/App.tsx`** (new)

- **`App`** — component; props: `user` and `storage`. Renders `WorkspaceShell` (passing
  both) around a flat `<Routes>`:
  `/`, `/sessions/:id`, `/characters/new`, `/characters/:id`, `/settings`, `/search` — each
  an **empty** centre (no text, no placeholder); and `*` — a centre showing the text
  **"Page not found"**. No layout route, no `<Outlet/>`, no `basename`, no router of its own
  (the caller supplies the router).

## Definition of done

1. `[test]` With an empty storage at wide width, the shell renders a "Workspace navigation"
   nav and a main region; the grid element's class is `app` without `nav-collapsed`; the
   nav shows the "Collapse tree" control and the "User menu" trigger with the username as
   visible text. (UC-070)
2. `[test]` Clicking "Collapse tree" (wide) gives the grid element the `nav-collapsed` class
   and replaces the expanded column with the rail: "Search", "New character", "Expand
   tree" and "User menu" are each present, "Collapse tree" is not. (US-090.AC-1)
3. `[test]` On the rail, "User menu" opens the menu with "Settings" and "Log out" items.
   (US-090.AC-1)
4. `[test]` On the rail, "New character" navigates the in-entry router to `/characters/new`
   and "Search" to `/search`, with no document navigation. (US-090.AC-1)
5. `[test]` The collapse survives a remount: after "Collapse tree", the storage holds a
   record with `navCollapsed: true`, and a fresh shell mounted over that storage starts
   collapsed (rail shown, `nav-collapsed` present). "Expand tree" restores the expanded
   column and stores `navCollapsed: false`. (UC-070)
6. `[test]` Narrow (the media query matching) with a stored `navCollapsed: false`: the rail
   is shown; "Expand tree" shows the expanded column and adds `nav-overlay-open` to the grid
   element, and the storage's `setItem` is not called. (UC-070, US-090.AC-1)
7. `[test]` Narrow, overlay open: "Collapse tree" closes it (rail shown, no
   `nav-overlay-open`) without a storage write; and with the overlay open, an in-entry
   navigation (e.g. choosing "Settings" from the user menu) closes it.
8. `[test]` The overlay is not persisted: after opening it at narrow width, a fresh shell
   over the same storage starts with the overlay closed.
9. `[test]` The grid element has exactly two child elements — no wall column or wall control
   is rendered.
10. `[test]` `App` at each of `/`, `/sessions/1`, `/characters/1`, `/characters/new`,
    `/settings` and `/search` renders the shell (the "Workspace navigation" nav is present)
    with a main region that has no text content and no "Page not found".
11. `[test]` `App` at an undeclared path (e.g. `/nope`) renders the shell with "Page not
    found" inside the main region.
12. `[manual/live]` In a browser below 820px, the overlay sits above the centre column at
    252px, the centre does not shift, and resizing past 820px in either direction closes it.
13. `[manual/live]` Reloading the page after collapsing the tree at wide width shows the rail
    with no flash of the expanded column.
