# Step 002 — `shell.css` and the shell state

## Goal

Fill `shell.css` with the workspace's layout rules — the two-track grid with its `1px`
divider gap, `--navw` and the collapse class that re-points it, and the `(width < 820px)`
media query with the overlay lift — and add `app/shellState.ts`, the MobX data class plus
free functions that decide what collapse / expand mean at each width and write the record
on the toggle (D3, D9, D11, D12).

## Interface intent

**`src/shell.css`** — layout only (`frontend-structure.md`, "The two stylesheets"). Holds,
and holds nothing else:

- **`.app`** — the grid element: `display: grid`, `gap: 1px`,
  `grid-template-columns: var(--navw, 252px) minmax(0, 1fr)`, full viewport height, a
  background that is a **Mantine CSS variable** for the divider line colour (so the gap
  draws the dividers), and a `transition` on `grid-template-columns`.
- **`.app.nav-collapsed`** — sets `--navw: 48px` and nothing else.
- **`.app-nav`** and **`.app-main`** — the two column elements' layout: each scrolls on its
  own; `.app-main` is placed **explicitly in the second track** (so it keeps its track when
  the nav column is lifted out of flow) with a zero minimum width.
- **`@media (width < 820px)`** — sets `--navw: 48px` on `.app` regardless of class; and
  **`.app.nav-overlay-open .app-nav`** positions the nav column out of flow above the centre
  column at the 252px expanded width, anchored to the left edge, full height, stacked above
  the centre.

Column backgrounds, padding, typography, shadow and every colour other than the divider
variable are **Mantine** (style props in `004`), not `shell.css`.

**`src/app/shellState.ts`** (new)

- **`NARROW_VIEWPORT_QUERY`** — the constant `"(width < 820px)"`, the exact `@media`
  condition in `shell.css`; the one string `004` hands to `useMediaQuery`.
- **`ShellState`** — data class, observable fields only: `navCollapsed` (boolean, from the
  record) and `overlayOpen` (boolean, starts `false`, never persisted). Constructed from an
  initial `navCollapsed`.
- **`createShellState`** — takes a `LayoutStorage` or `null`; returns a `ShellState` whose
  `navCollapsed` is the record's (`readWorkspaceLayout`) and whose overlay is closed.
- **`showsRail`** — pure; takes the state and whether the viewport is narrow; true when the
  left column should render the rail: when narrow, exactly when the overlay is closed; when
  wide, exactly when `navCollapsed`.
- **`shellClassName`** — pure; takes the state and narrow; returns the `.app` element's class
  string: always `app`, plus `nav-collapsed` when `navCollapsed` is true, plus
  `nav-overlay-open` when narrow **and** the overlay is open.
- **`expandTree`** — effect; takes the state, narrow and the storage. Narrow: opens the
  overlay, writes nothing. Wide: sets `navCollapsed` false and writes `{ navCollapsed: false }`.
- **`collapseTree`** — effect; takes the state, narrow and the storage. Narrow: closes the
  overlay, writes nothing. Wide: sets `navCollapsed` true and writes `{ navCollapsed: true }`.
- **`closeOverlay`** — effect; takes the state; closes the overlay; writes nothing.
- **`browserLayoutStorage`** — takes nothing; returns `window.localStorage` as a
  `LayoutStorage`, or `null` if merely accessing it throws. The one place in the feature
  that touches `window.localStorage`.

Every observable write is inside a MobX action (`runInAction`).

## Definition of done

1. `[test]` `shell.css` declares the `.app` grid with `display: grid`, `gap: 1px` and
   `grid-template-columns: var(--navw, 252px) minmax(0, 1fr)`. (UC-070)
2. `[test]` `shell.css` declares `.app.nav-collapsed` setting `--navw: 48px`. (UC-070)
3. `[test]` `shell.css` contains the media query `@media (width < 820px)`, and inside it
   `--navw: 48px` for `.app` and a rule for `.app.nav-overlay-open .app-nav`.
4. `[test]` `shell.css` contains no literal colour (no `#` hex, `rgb(`, `rgba(`, `hsl(`,
   `hsla(` or named colour value); its only colour reference is a `var(--mantine-…)` variable.
5. `[test]` `shell.css` contains no `@import`, no `@font-face`, no font or typography
   property and no selector other than `.app`, `.app.nav-collapsed`, `.app-nav`, `.app-main`
   and `.app.nav-overlay-open .app-nav` (with `>` child combinators permitted). The
   existing clause asserting `shell.css` is empty is replaced by DoD-1..5; the clause that
   `global.css` and `shell.css` are the only two `.css` files is kept, and `global.css`
   still carries no colour.
6. `[test]` `NARROW_VIEWPORT_QUERY` equals `"(width < 820px)"` and that exact string occurs
   in `shell.css`.
7. `[test]` `createShellState` over a storage holding `navCollapsed: true` yields
   `navCollapsed` true; over a `null` storage yields `navCollapsed` false; both start with
   the overlay closed. (UC-070)
8. `[test]` `showsRail` — wide: true iff `navCollapsed`; narrow: true iff the overlay is
   closed, whatever `navCollapsed` is. (UC-070, US-090.AC-1)
9. `[test]` `shellClassName` returns `app`; `app nav-collapsed` when collapsed; adds
   `nav-overlay-open` only when narrow and the overlay is open, never when wide.
10. `[test]` Wide: `collapseTree` sets `navCollapsed` true and writes a record with
    `navCollapsed: true`; `expandTree` sets it false and writes `navCollapsed: false`;
    `wallPinned` in storage is preserved across both writes. (UC-070)
11. `[test]` Narrow: `expandTree` opens the overlay and `collapseTree` / `closeOverlay`
    close it, and none of the three changes `navCollapsed` or calls the storage's `setItem`.
12. `[test]` The toggles are reactive: an `autorun` reading `showsRail` re-runs after
    `collapseTree` (the writes are MobX actions on observable fields).
13. `[test]` `browserLayoutStorage` returns jsdom's `localStorage`, and returns `null` when
    accessing `window.localStorage` throws.
14. `[manual/live]` In a browser, collapsing and expanding visibly transitions the column
    between 252px and 48px; a long unbroken line in the centre column does not push the left
    column off-screen; the divider lines are the `1px` gap in both colour schemes.
15. `[manual/live]` Below 820px the left track is 48px regardless of the stored collapse,
    and the overlay sits above the centre column at 252px without shifting it.
