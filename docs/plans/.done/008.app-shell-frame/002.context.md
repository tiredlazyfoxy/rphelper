## The divider variable — `--mantine-color-default-border`

`workspace-shell.md` draws the dividers as the `1px` gap over "a line-coloured background".
Both stylesheets carry no literal colour; the line colour must also follow the light/dark
scheme (`shared/colorScheme.ts`, `ColorSchemeToggle`). The `.app` background is
**`var(--mantine-color-default-border)`** — verified present in the installed
`@mantine/core/styles.css` for both schemes (dark at `:346`, light at `:474`). That is a
reference to a theme token, not a colour decision, and it keeps "everything else is
Mantine" true.

## The overlay lift — a gotcha

A grid child with `position: fixed` / `absolute` leaves the grid's auto-placement. Without
an explicit track for `.app-main`, the centre column would slide into the first (48px)
track the moment the overlay opens. That is why `.app-main` is placed in track 2
explicitly (Interface intent). The overlay's width is the expanded `252px`; `--navw` is
not reused for it, because inside the media query `--navw` is 48px.

## Range media-query syntax

`(width < 820px)` is Media Queries Level 4 range syntax, supported by every evergreen
browser and by `window.matchMedia`. It is chosen so the literal `820px` appears verbatim
(D12). Do not rewrite it as `max-width: 819.98px` or a Mantine breakpoint.

## MobX in free functions

`ShellState` is built with `makeAutoObservable(this, {}, { autoBind: true })` and has no
methods. The free functions are plain module functions, so their writes are wrapped in
`runInAction` — under MobX's default `enforceActions: "observed"` an observed field written
outside an action warns, and DoD-12 observes the field through `autorun`.

## `browserLayoutStorage`

Accessing the `localStorage` getter throws a `SecurityError` in some browsers when site
data is blocked. The guard is around the **access**, not just later calls — later calls are
already guarded inside `workspaceLayout.ts`. DoD-13's throwing case is produced by
redefining the `window.localStorage` getter in the test.
