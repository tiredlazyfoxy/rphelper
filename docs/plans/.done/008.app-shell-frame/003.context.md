# Step 003 — step-specific context

Feature-wide facts are in `context.md` (**D6** the menu, **D7** the logout failure posture,
"Cross-cutting constraints" for cross-entry navigation and notifications). Only what is
narrow to this step is below.

## Borrowed interfaces

- `shared/api.ts` — `apiPost(path, body?, signal?)`; `documentNavigation.assign(url)` is the
  only way this step navigates the document. **Do not call `window.location` directly** —
  the seam is what makes DoD-6 testable.
- `shared/notifyFailure.ts` — the only notification call site this feature adds. Do not
  import `@mantine/notifications` here; `tests/conventions.test.ts` would fail.
- `shared/currentUser.ts` (step `001`) — the `CurrentUser` type.
- `react-router-dom` — `useNavigate` for Settings. The component therefore renders inside a
  router; tests wrap it in a `MemoryRouter` (plus `AppProviders`).

## 204 with no body — verified

`POST /api/auth/logout` answers **204 with an empty body**. Verified from source
(`shared/api.ts:90-106`): `apiRequest` resolves to `undefined` on a 204 — the body text is
forced to `""` and the `response.ok` branch returns before any `JSON.parse`. So
`apiPost("/api/auth/logout")` resolves cleanly; `logout.ts` uses it as-is and never calls
`fetch` directly (that would bypass the 401 handling and the `ApiError` wrapping).

## Mantine `Menu` notes (7.17)

- The dropdown renders in a portal and only while open; tests open it by clicking the
  trigger, then query the document.
- `Menu.Item` accepts `component="a"` with `href`; that is how the admin item is a real
  anchor while still being a menu item. `leftSection` carries the item icon at the inline
  size (`size={16} stroke={1.5}`, `ui-conventions.md`).
- `position="top-start"` opens upward, aligned to the trigger's left edge — the expected
  choice; any `top-*` satisfies D6.
- Mantine's `Avatar` is fine for the trigger's avatar; the initial is the username's first
  character, upper-cased. Colour is Mantine's default — no literal colour.

## Why the trigger is not an `IconButton`

`IconButton` wraps a Tabler icon in an `ActionIcon` with a tooltip, and its props type is
deliberately not widened (`ui-conventions.md`). The trigger is an avatar (and, expanded, a
username) — not a Tabler icon — and its accessible name is fixed at "User menu". A Mantine
`UnstyledButton` (or equivalent) carrying `aria-label="User menu"` is the shape. This is
not a bare `ActionIcon` wrapping a Tabler icon, which is what the convention forbids.
