# Step 005 — step-specific context

Feature-wide facts are in `context.md`: the **Wire contract** (shapes, paths), **D5**
(mutations take no signal), **D7** (the reach helper), the UI strings table (the three
reach statements), the **ids-are-strings** constraint, and frontend **Test conventions**
(stubs by exact path, query and method; payload builders). `src/app/setupsApi.ts` is the
pattern reference (not imported). Only what is narrow to this step is below.

## Borrowed interfaces

- `src/shared/api.ts`: `apiGet`, `apiPost`, `apiPatch`, `apiDelete` (path, optional body,
  optional signal; non-2xx → `ApiError`; 204 → `undefined`).
- `src/shared/apiError.ts`: `ApiError` (rethrown unchanged; nothing here catches).

## Query strings

Build the listing path in a fixed order — `scope` first, then `scope_id` only when the
scope id is non-null — so the exact-path stubs in every later test match
(`/api/memos?scope=character&scope_id=<id>`). The values are a fixed word and a decimal
string; no encoding concerns, but `URLSearchParams` is fine if it keeps that order.

## Request bodies

- `createMemo` always sends `scope_id`, as `null` for the user level: the server ignores it
  there (`context.md` request rules), and one body shape for all four levels keeps the
  `006` / `007` / `008` stubs uniform.
- `updateMemo` sends the patch as given. Callers (`006`) build a patch with exactly one of
  the three keys; this module neither adds nor fills keys. `JSON.stringify` drops a key
  whose value is `undefined`, which is the intended effect if a caller ever passes one.

## Why `memoReach` takes the flags, not the scope

Reach depends on the two flags only (R3's table). It accepts any object with the two
booleans so `007` can call it with a `Memo` and a future wall card with whatever it holds.

## Where the statements live

The three sentences live in `memoReach.ts` only. `007` renders `reachStatement(...)`; no
component spells a statement itself. Tests compare against the literal strings from
`context.md`, never against a call to `reachStatement` (Test conventions).
