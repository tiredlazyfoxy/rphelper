# Step 001 — step-specific context

Feature-wide facts are in `context.md`: **D10** (columns, CHECK choice, index), **D12**
(the error), **D15** (body validation), the **Wire contract** (`Memo` shape, request
rules), and backend **Test conventions**. 011's `001.context.md` ("Applying the patterns
here", "Gotcha — the nullable inbound snowflake", "The delta") holds the patterns this step
follows; it is cited, not restated. Only what is narrow to this step is below.

## Registry patterns, as harvested

- Snowflake PK: `Column("id", BigInteger().with_variant(Integer(), "sqlite"),
  primary_key=True, autoincrement=False)`. `scope_id` uses the same
  `BigInteger`-with-SQLite-`Integer` type, `nullable=False`, and **no** `ForeignKey`.
- `user_id`: a bare FK to `users.id`, NOT NULL, no `ondelete`.
- Booleans: `Boolean, nullable=False` with a Python `default` and a `server_default` of
  `true()` / `false()` (the existing boolean-with-default form in `schema.py`).
- Timestamps: `Text`, NOT NULL. The services mint them; the table has no default for them.
- Each Table carries a comment block citing `data-model.md` and the feature's decisions;
  write one for `memos` (D2 delete-as-removal, D4 allocation and no unique constraint,
  D10 the CHECK reasoning, "no title / archived_at / state").
- Both registry-literal guard tests (`test_every_registry_table_is_a_literal_in_the_schema_module`,
  `test_no_other_app_module_defines_its_own_table`) must keep passing unchanged: `memos`
  is a `Table(...)` literal in `schema.py` itself.

## The scope CHECK

The `users.role` precedent is a non-native `Enum(..., create_constraint=True)`, which
SQLite stores as a short `VARCHAR` plus a CHECK. Use the same form with the four literal
strings, `native_enum=False`, and an explicit constraint name. `db/schema.py` must not
import `models/` (`backend-structure.md` "two leaf modules"), so the four strings are
written in both files; DoD-6 is the guard that keeps them equal. The test-coder may read
the permitted values off the column type (its `enums`) or prove them by inserts (DoD-5
already does the latter).

## The nullable inbound snowflake

`CreateMemoRequest.scope_id` is optional and nullable, like 011's
`StartSessionRequest.setup_id`. 011 `001.context.md` records the pydantic v2 gotcha (a
`None` reaching `SnowflakeIn`'s `int()` validator raises a `TypeError`, which is not
converted to a 422). The skeleton chooses the form; DoD-9 pins the behaviour. `models/ids.py`
and `models/sessions.py` are not edited; if 011 exposes a reusable nullable alias, importing
it is allowed, otherwise the form lives in `models/memos.py`.

## Non-blank, not stripped

The setups precedent uses a stripped `min_length=1` string alias, which would **store** the
stripped value. `body` must be validated as non-blank **without** being changed (D15:
markdown whitespace is content). An after-validator that checks `value.strip()` and
returns `value` unchanged is the shape; the skeleton decides. The same check applies to
`UpdateMemoRequest.body` when it is a string.

## Non-user scope requires `scope_id`

A model-level validator on `CreateMemoRequest` (after field validation) raising a
`ValueError` gives FastAPI's 422. The list route's query has the same rule; that is
`004`'s (its context).

## Names

`MemoResponse`, `MemoListResponse`, `MemoChainLevelResponse`, `MemoChainResponse`,
`CreateMemoRequest`, `UpdateMemoRequest`, `MemoNotFoundError`. If the skeleton finds a
collision inside `models/`, it records the rename in `## Skeleton`; the wire shape does
not change.

## The delta (DoD-1, DoD-11)

Same two-shape rule as 011 `001.context.md` "The delta": if the file asserts membership
plus absence, assert `"memos"` membership and that nothing beyond the tables declared
through 015 could be 015's; if it subtracts a "declared by later features" set, add
`"memos"` to that set for the earlier deltas and write 015's own delta against a set that
starts empty. If 012's `messages` delta has landed by the time this step is built, treat it
as one more earlier delta. The test-coder reads the file to see which shape it has.

## Gotcha — `/api/health` on existing databases

As 009 / 010 / 011: registering `memos` makes an existing database report `schema:
"missing"` until an administrator presses Create. This is designed behaviour; tests build
the schema with `create_all`.
