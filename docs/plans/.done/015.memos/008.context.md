## Building the level states

`loadMemoChain` constructs each `MemoLevelState` with the level's `scope` and `scope_id`
from the response, verbatim (the user level's `scope_id` is `null`), and calls
`populateMemoLevel` with the level's `memos` inside the same action. It does not inspect
which scopes came back: the server decides whether the setup level exists (R2), and the
section renders whatever levels the state holds.

## Titles and headings

The scope-to-title map is private to `MemoChainSection.tsx`. Heading orders: the "Notes"
heading is one level below the session header's heading (011 `009` renders the start-time
label as a heading; read its `order` there), and each group's heading one level below
"Notes". Keys: the group's `scope` is unique within a chain.
