# Step 002 — step-specific context

Feature-wide facts are in `context.md`; the decision this step implements is D3 (the
minimal token set) and the constraint it holds is the both-colour-schemes rule. Neither
is repeated here.

## The division this step is enforcing

`docs/architecture/frontend-structure.md` § "The two stylesheets — the whole division"
is the authority. Its table is the contract: `global.css` holds resets and is reached
by every entry; `shell.css` holds the `app` workspace's layout only and is imported by
the `app` entry alone. Everything else is Mantine.

The doc's own words for the boundary, which DoD-2 makes checkable: *"A rule that is
neither a reset nor workspace layout belongs in neither file; reaching for a third
file, or for a `.css` beside a component, is the signal that a Mantine theme token was
the right answer."*

## Why `shell.css` ships with zero rules rather than not existing

Three reasons, all about the seam with `008`:

- the import wiring (step `006`, `src/app/main.tsx` alone) is decided and tested now,
  so `008` adds rules and nothing else;
- a declared empty file is the visible statement that there are exactly two
  stylesheets, which a missing file is not;
- a later feature reaching for a component-local `.css` has an obvious place to be
  redirected to.

DoD-3's "no CSS rule at all" is checkable as: the file's content, with comments
stripped, contains no `{`.

## Where the imports go — this step writes none

This step **creates** the two stylesheets but wires **neither** import. `global.css` is
imported by `shared/AppProviders.tsx` in step `005` (so the cascade order relative to
Mantine's own sheet is decided in one file — `context.md` D9); `shell.css` is imported
by `src/app/main.tsx` in step `006`. A test for this step therefore reads the files
from disk rather than importing them.

## Gotcha — testing the theme under both schemes

Mantine 7 resolves colour-scheme-dependent values through CSS custom properties that
its provider writes onto the document, and through a `data-mantine-color-scheme`
attribute. A test for DoD-8 renders a Mantine component inside a bare `MantineProvider`
from `@mantine/core` carrying this theme, once with each `forceColorScheme` value, and
asserts the rendered result is styled in both. `shared/AppProviders` does not exist
yet at this step.

## Gotcha — the system font stack

A system font stack contains commas and quoted family names. DoD-7's check is that no
`url(` and no `@font-face` appears in this step's files, not that the stack has a
particular membership.
