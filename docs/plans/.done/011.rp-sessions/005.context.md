# Step 005 — step-specific context

Feature-wide facts are in `context.md`: **D4** (the label and its shape; why the zone is a
parameter), **D7** (the separate key, why not a field in 008's record, component-local
use), and frontend **Test conventions** ("Start-time labels"). Only what is narrow to this
step is below.

## The formatter

- Parse with `new Date(createdAt)`: the fixed-width form with its explicit `+00:00` offset
  is valid ISO-8601 for `Date`. Microseconds beyond milliseconds are simply truncated by
  `Date`, which is fine at minute resolution (DoD-3's `23:59:59.999999` must not round up).
- Build the string from `Intl.DateTimeFormat(…, { timeZone, year: "numeric", month:
  "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", hourCycle: "h23" })
  .formatToParts(...)`, assembling the parts yourself. Do **not** rely on a locale's own
  separators or ordering (`en-CA` and similar tricks change between ICU versions), and
  use `hourCycle: "h23"` rather than `hour12: false` (some engines render midnight as
  `24` with the latter).
- Passing `timeZone: undefined` makes `Intl` use the runtime's zone, which is what
  DoD-4 compares against.
- Node ships full ICU, so the `Asia/Tokyo` / `America/New_York` cases in DoD-2 run under
  Vitest as they do in a browser.

## The collapsed-characters record

- Mirror `app/workspaceLayout.ts` (008 `001`): import the `LayoutStorage` type from it
  (type-only import), wrap `getItem`, `JSON.parse` and `setItem` in `try` / `catch`, return
  totals, swallow write failures.
- The record is the **whole** collapsed set, so a write replaces it; there is no patch /
  merge as in 008's two-field record. The tree computes the next set with
  `toggleCollapsedCharacter` and writes it (`006`).
- No pruning: an id for a character that is archived or gone stays harmlessly. Restoring
  an archived character should bring back its collapse state, and pruning would need the
  character list, which this module must not know about.
- Ids stay strings: no numeric check, no `parseInt` (`tests/ids-are-strings.test.ts`).
  Non-string entries are dropped, not converted.

## Why both live under `src/app/`

Both are used only by the `app` entry (the tree, the section, the session screen), so they
sit beside their consumers (`frontend-structure.md` "Where a store's file lives"), like
`workspaceLayout.ts`.
