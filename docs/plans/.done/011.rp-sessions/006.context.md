## Where the session level sits

- Each character row stays a list item of 009's "Characters" `ul`. The chevron goes
  before 009's link inside that item; the nested "Sessions of <name>" `ul` (an `ul` with
  `aria-label` gives role `list` with that name) goes after the link, inside the same item.
- The session row's active mark: `useMatch("/sessions/:id")`, as 009 reads
  `/characters/:id` (the tree is outside `<Routes>`). Set `aria-current="page"` explicitly
  if Mantine's `NavLink` is used, or use `react-router-dom`'s `NavLink`.
- The tree re-mounts on every expand of the column (009 `008.context.md`), so the sessions
  load and the collapsed set's initial read both re-run then. That is why the set is
  persisted: a collapsed character stays collapsed across a rail round-trip and a reload.

## Two effects, not one

009's effect reloads characters whenever `showArchived` changes. The sessions load is a
**separate** effect with no dependency on `showArchived` (DoD-7): folding it into 009's
effect would refetch sessions on every switch toggle. Abort it on unmount like 009's.

## Ordering inputs

`orderCharactersByUse` receives `characters.characters` (whatever 009's switch made
visible) and `sessions.sessions`. While sessions are loading or failed, the sessions array
is whatever it last held (empty on first mount), so the order falls back to 009's.
