# Step 005 — The start-time label formatter and the collapsed-characters record

## Goal

Add two small, pure, DOM-free modules the session displays need: `app/sessionLabel.ts`,
the one formatter turning a session's `created_at` into its start-time label (D4), and
`app/treeCollapse.ts`, the localStorage record of which characters the tree shows
collapsed, under its own key with 008's total-read / best-effort-write posture (D7).
Grouped in one step because each alone is below the size floor and neither depends on
the other.

## Interface intent

**`app/sessionLabel.ts`** (new — pure; no DOM, React or MobX)

- **`formatSessionStart`**: takes a fixed-width timestamp string (a session's
  `created_at`) and an optional IANA time-zone name. Returns the instant as
  `YYYY-MM-DD HH:MM` (24-hour, zero-padded, a single space between date and time) in the
  given zone, or in the runtime's own local zone when none is given. Never includes
  seconds, a zone suffix or locale-dependent text.

**`app/treeCollapse.ts`** (new — pure; imports nothing from the DOM, React or MobX)

- **`TREE_COLLAPSED_KEY`**: the constant `"rphelper.tree-collapsed"`.
- **`readCollapsedCharacters`**: takes a `LayoutStorage` (008 `001`'s type) or `null`;
  returns an array of character id strings. Never throws. Returns an empty array for:
  null storage, a throwing `getItem`, an absent key, unparseable JSON, or a stored value
  that is not a JSON array. From an array it keeps only string entries, drops duplicates,
  and preserves first-seen order.
- **`writeCollapsedCharacters`**: takes a `LayoutStorage` or `null` and an array of
  character id strings; stores the JSON array under `TREE_COLLAPSED_KEY`. Best-effort: any
  throw is swallowed; null storage is a no-op. Writes no other key.
- **`toggleCollapsedCharacter`**: pure. Takes the current array and one character id;
  returns a **new** array with that id added (at the end) when absent, or removed when
  present. Does not mutate its input.

## Definition of done

1. `[test]` `formatSessionStart("2026-10-01T18:05:09.123456+00:00", "UTC")` returns
   `"2026-10-01 18:05"`. (D4)
2. `[test]` The same instant with `"Asia/Tokyo"` returns `"2026-10-02 03:05"` (the date
   rolls over), and with `"America/New_York"` returns `"2026-10-01 14:05"`. (D4)
3. `[test]` Zero-padding and 24-hour form:
   `formatSessionStart("2026-01-05T03:04:00.000000+00:00", "UTC")` returns
   `"2026-01-05 03:04"`, and `"2026-01-05T23:59:59.999999+00:00"` returns
   `"2026-01-05 23:59"` (no rounding up to the next minute).
4. `[test]` With no zone argument the result matches `/^\d{4}-\d{2}-\d{2} \d{2}:\d{2}$/`
   and equals the result for the runtime's resolved time zone
   (`Intl.DateTimeFormat().resolvedOptions().timeZone`). (D4)
5. `[test]` `TREE_COLLAPSED_KEY` equals `"rphelper.tree-collapsed"`.
   `readCollapsedCharacters` returns `[]` for a `null` storage, a storage with no value
   under the key, and a storage whose `getItem` throws. (D7)
6. `[test]` `readCollapsedCharacters` returns `[]` for unparseable JSON and for a stored
   JSON value that is not an array (an object, a string, a number, `null`). For a stored
   `["7250000000000000001", 5, "7250000000000000002", "7250000000000000001", null]` it
   returns exactly `["7250000000000000001", "7250000000000000002"]`. It reads only the key
   `rphelper.tree-collapsed`. (D7)
7. `[test]` `writeCollapsedCharacters(storage, ["a", "b"])` stores the JSON array
   `["a","b"]` under `rphelper.tree-collapsed`, a following read returns `["a", "b"]`, and
   it never calls `setItem` with `rphelper.workspace-layout` or any other key. (D7)
8. `[test]` `writeCollapsedCharacters` never throws: a storage whose `setItem` throws and a
   `null` storage both return normally.
9. `[test]` `toggleCollapsedCharacter(["a"], "b")` returns `["a", "b"]`;
   `toggleCollapsedCharacter(["a", "b"], "a")` returns `["b"]`; the input arrays are
   unchanged afterwards.
10. `[test]` Both modules are DOM-free: their source references no `window`, `document`,
    `localStorage` global, React or MobX import (a source scan of the two files). (D7)

## Dependencies

none within 011. Imports only the `LayoutStorage` **type** from 008 `001`'s
`app/workspaceLayout.ts` (built in skeleton form; the type is all that is needed).
