## The patch rule

Compare each editor text, trimmed with `""` as null, against `saved`'s value. Send only
the keys that differ. If nothing differs, Save is disabled, so `saveSettings` is never
called with an empty patch from the UI. If it is called anyway, it sends nothing and
leaves the state as it is.
