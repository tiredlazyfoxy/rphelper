# Step 010 — step-specific context

Feature-wide facts are in `context.md`: **D18**, **D19**, the UI strings table (every
modal label and line), the frontend **Test conventions** (`SegmentedControl` radios,
portals). Only what is narrow to this step is below.

## Pattern

`app/SetupModal.tsx` (010) is the precedent: a Mantine `Modal` whose body is a separate
`observer` component mounted only while `opened`, creating its draft with
`useState(() => new …)`. Who opens it (the open flag) is the host's component-local
`useState` (`ui-conventions.md`), here the bar's (`011`).

## Inherited line inputs

Each line reads the setting's `inherited` and `inherited_level` from the `configuration`
prop:

- system prompt: `inherited_level === "character"` → "Inherited from the character:" plus
  `inherited` rendered as plain text (not markdown), else the "Nothing to inherit…"
  sentence;
- tools: `inherited_level === "character"` → "Inherited from the character: on|off" from
  `inherited`, else (`"default"`) "Inherited: on (default)";
- languages: `inherited_level === "user"` → "Inherited from your settings: " + value, else
  "Nothing to inherit: no default in your settings.".

The lines describe the **loaded** configuration, not the draft. They do not change while
typing.

## Scoping in tests

Mantine `Modal` renders in a portal: query with `screen` and scope to the dialog (`role
"dialog"`, name "Session configuration"). Each `SegmentedControl` is a radio group. Find
its radios inside the group named by its label (e.g. the "Web search" group's "Off"
radio), because "Inherit" appears six times.
