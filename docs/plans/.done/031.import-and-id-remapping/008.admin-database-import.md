# Step 008 — admin Database page: Import with confirm and sign-out redirect

## Goal

Add an **Import** button (`IconUpload`) to the admin Database page's page-level
action group, beside 030's Export.

- Choosing a file opens a `ConfirmModal` that states the replace-and-sign-out
  consequence.
- Confirming posts the file to the database import route. On success the browser
  goes to `/login`.
- Failures render in the page's own inline red `Alert`.

## Interface intent

- **`DatabasePageState` gains three observable fields, and no methods:**
  - the **pending import file** (the chosen file, or null). Non-null means the
    confirm is open;
  - the **import status** (`idle` or `importing`);
  - the **import error message** (string or null). It is separate from the drift
    `errorMessage` and from 030's export error, so no failure overwrites another's
    message.
- **Free functions** in `databasePageState.ts`:
  - **`chooseImportFile(state, file)`** stores the pending file and clears the
    previous import error.
  - **`cancelImport(state)`** clears the pending file.
  - **`importDatabase(state, signal?)`** runs these steps:
    1. sets the status to importing;
    2. posts the pending file with `postExportFile("/api/admin/database/import",
       file, signal)`;
    3. on success calls `documentNavigation.assign("/login")`;
    4. on failure stores the error's message as the import error, clears the
       pending file and returns the status to idle.

    It writes inside `runInAction`, writes nothing once its signal is aborted, and
    never raises a notification.
- **`DatabasePage`:**
  - The action group gains a `Button` labelled **"Import"** with `leftSection`
    `IconUpload`, wrapped in Mantine `FileButton` accepting `.json` /
    `application/json` and reset after each choice. It is loading while importing.
  - A `ConfirmModal` is opened while a pending file exists:
    - title, consequence sentence and confirm label as pinned in
      `008.context.md`;
    - `confirmColor="red"`;
    - `loading` while importing;
    - `onCancel` → `cancelImport`, `onConfirm` → `importDatabase`.
  - An import failure renders in its own inline red `Alert`.
  - The page renders nothing about the file's contents, before or after.

## Definition of done

1. **DoD-1 [test]:** The page shows an "Import" button beside "Export", rendered
   with the Tabler upload icon. It is present whatever the drift state is (in sync,
   drifted, missing) and is not disabled by it.
2. **DoD-2 [test]:** Choosing a file opens a dialog with the pinned title,
   consequence sentence and confirm label. No `POST` has been made yet.
3. **DoD-3 [test]:** Cancelling closes the dialog, makes no `POST`, and leaves
   the page as it was.
4. **DoD-4 [test]:** Confirming posts the file's object to `POST
   /api/admin/database/import`. On a 204 it calls
   `documentNavigation.assign("/login")` exactly once. (US-077.AC-2, UC-061)
5. **DoD-5 [test]:** A 409 `database_not_empty` answer:
   - closes the dialog;
   - renders the server's message in an inline red `Alert`;
   - raises no notification;
   - does not navigate.

   Any drift `errorMessage` and any export error or size line already on the page
   are left as they were.
6. **DoD-6 [test]:** A 400 `export_invalid` answer, and a non-JSON file, each
   render their message inline: the server's message, or exactly "The chosen file
   is not a readable export.". Neither raises a notification or navigates. The
   non-JSON case makes no `POST`.
7. **DoD-7 [test]:** Before and after choosing a file whose JSON contains sentinel
   usernames, character names, memo text and table names, none of that content
   appears anywhere in the rendered page or the dialog, and no row count or table
   listing of the file appears. (US-078.AC-1, US-078.AC-3, R5)
8. **DoD-8 [test]:** `importDatabase` writes nothing when its signal is already
   aborted. `chooseImportFile` clears a previous import error.
9. **DoD-9 [test]:** `DatabasePageState` still declares no methods: its prototype
   carries only the constructor.
10. **DoD-10 [test]:** 030's export behaviour is unchanged. One regression case:
    Export still requests `/api/admin/database/export` and shows its size line.
11. **DoD-11 [manual/live]:** In a browser on an instance holding only the admin,
    import a database export from another instance. You land on `/login`, and a
    restored user can sign in.
12. **DoD-12 [manual/live]:** `npm run typecheck` passes.
