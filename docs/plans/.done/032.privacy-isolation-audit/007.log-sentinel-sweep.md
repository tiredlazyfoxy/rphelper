# Step 007 — Log sentinel sweep

## Goal

Prove that no log record at any level carries forbidden text
(`docs/architecture/deployment.md` "The redaction rule") by driving every
surface — happy paths and failure paths — under the real logging configuration
with a level-0 capture sink, and asserting that no record contains any
sentinel. Audit step: no source change planned beyond what a finding needs.

## Source files

None planned. Fix-allowance if a `[test]` item fails against built code:

- `backend/app/logging.py`
- the module holding the offending `logger.*` call or exception-formatting
  site, under `backend/app/` (compose/streaming, tool loop, translation,
  import/export, web search, auth) — only to replace logged content with ids,
  codes, counts or the exception class

Anything larger is handed back per `context.md` "Leak-fix policy".

## Test files

- `backend/tests/test_privacy_audit_logs.py`

## Interface intent

None (audit).

## Definition of done

1. DoD-1 [test] — With the real `configure_logging` (console at `DEBUG`) and a
   level-0 capture sink, building the full audit world and driving every
   `self`, `owner` and `registry` route's success path emits no record whose
   message, extra or exception text contains any sentinel. (US-084.AC-1)
2. DoD-2 [test] — Refusal paths emit no sentinel: every foreign-id 404 of
   step 003, 409 `memo_order_mismatch`, `zone_empty`, `nothing_to_reopen`,
   `already_configured`, `database_not_empty`, and a 422 whose invalid body
   carries a sentinel. (US-084.AC-1)
3. DoD-3 [test] — A compose whose fake model raises an exception whose message
   contains a sentinel (and whose prompt carries sentinels) emits no record
   containing any sentinel. (US-084.AC-1)
4. DoD-4 [test] — A tool call (each of memo_search, session_search,
   web_search) that fails with an exception whose message contains a sentinel
   emits no record containing it. (US-084.AC-1)
5. DoD-5 [test] — A translation whose fake model fails with a sentinel-bearing
   exception emits no record containing it. (US-084.AC-1)
6. DoD-6 [test] — An import rejected as `export_invalid` whose payload carries
   sentinels emits no record containing them. (US-084.AC-1)
7. DoD-7 [test] — A failed login with a sentinel password, and an LLM-server
   probe (test / available-models) failing against a server whose API key is a
   sentinel, emit no record containing either sentinel. (US-084.AC-1)
8. DoD-8 [test] — My-search with a sentinel query emits no record containing
   it. (US-084.AC-1)
9. DoD-9 [test] — After `configure_logging`, the `sqlalchemy` and
   `sqlalchemy.engine` loggers' effective level is WARNING or higher.
   (US-084.AC-1)
10. DoD-10 [manual/live] — In the production container, after composing,
    settling, searching with a sentinel and translating, neither the
    supervisord/console output nor `data/logs/` contains the sentinel
    (nginx's own access log is outside this item — see `outcome.md`).
