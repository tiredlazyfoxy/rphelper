## Guard mechanics

- Iterate API routes only (FastAPI's `APIRoute`); FastAPI's documentation
  routes are not API routes and are outside the table. Ignore `HEAD`.
- Normalize every `{param}` / `{param:type}` segment to `{}` before comparing.
- Path-parameter substitution for DoD-2/3: unknown id `"7250000000000000002"`
  for id params, any existing table name (e.g. `characters`) for the database
  table param.
- `require_user` sits at router level on every user-content router, so anon is
  refused before path resolution matters; `require_role` guards admin_users,
  admin_llm, admin_db (`app/roles.py:26` ladder `{ROLEPLAYER: 0, ADMIN: 1}`).
- `POST /api/auth/logout` and `POST /api/auth/login` are `public`; DoD-2 skips
  every `public` row.
