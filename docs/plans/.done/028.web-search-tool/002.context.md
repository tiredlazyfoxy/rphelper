## What the model receives

| Part | Exact form |
|---|---|
| block | `<title>` `\n` `<url>` `\n` `<snippet>`. When the snippet is blank, the block is `<title>` `\n` `<url>` |
| title / snippet normalisation | every whitespace run (spaces, tabs, newlines) collapsed to one space, ends trimmed |
| url | trimmed, otherwise verbatim |
| blank title | `(untitled)` |
| block separator | `\n\n`, results in provider order |
| zero results | `No web results.` |
| summary | `<N> results`, N the number of results (`0 results`, `1 results`, `5 results`) |

- No numbering, no headers, no ids, no query echo. The summary never contains content
  (021 D6).
- "Blank" means empty after the whitespace normalisation above.
- A result whose url is blank cannot occur: step `001` skips items without a string
  `link`. If one did occur, it would render as an empty url line. The formatter does not
  special-case it.

## Query rule

`query` must be a string that is non-blank after trimming. It is **passed to the
provider untrimmed** (verbatim). A blank query fails before any request, which saves a
pointless outbound call and treats an empty search as a bad argument. In 026 / 027 the
port returned `[]` for a blank query; here there is no port, and an outbound call is not
free.
