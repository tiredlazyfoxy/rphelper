# Step 003 — The translate route

## Goal

Mount `POST /api/messages/{message_id}/translation` in a new `routers/translation.py` as an
`async def` handler. It has router-level `require_user`, its own overridable chat-client
factory dependency, and a disconnect probe bound to the request. Register it in `main.py`
(D12).

## Source files

backend/app/routers/translation.py
backend/app/main.py

## Test files

backend/tests/test_translation_router.py

## Interface intent

**`app/routers/translation.py`** (new)

- **A router** with `dependencies=[Depends(require_user)]`.
- **A chat-client factory dependency**: a function returning the real `LlmClient` class as
  the factory (021 `006`'s pattern). Tests override it with `dependency_overrides`.
- **`POST /api/messages/{message_id}/translation`**: an `async def` handler. Its inputs are:
  - the path id (`SnowflakeIn`);
  - the caller;
  - settings through `Depends(get_settings)`;
  - the factory dependency;
  - the Starlette `Request`;
  - the id generator dependency, if `002`'s frozen signature takes one.

  It awaits `translate_message` with:
  - `get_engine(settings)`;
  - the caller's id;
  - the message id;
  - `settings.llm_request_timeout_seconds`;
  - the factory;
  - a probe that awaits `request.is_disconnected()`.

  It answers 200 with `TranslationResponse` built from the result. Domain errors answer
  through the one registered handler. The router holds no SQL.
- A module docstring names the route, its non-streamed posture (D1) and the best-effort
  probe (D4).

**`app/main.py`** (changed)

- Includes the translation router **after every router already present**, and the module's
  router docstring / list gains it.

## Definition of done

1. `[test]` Logged in as the owner, `POST /api/messages/<partner id>/translation` with a
   fake factory whose client yields "Привет" answers 200 with JSON exactly
   `{"message_id":"<id>","target_language":"Russian","text":"Привет","cached":false}`, where
   `message_id` is a **string**. A second POST answers the same text with `"cached":true`,
   and the fake client was called once in total. (US-045.AC-1, US-046.AC-1, wire contract)
2. `[test]` A fake raising `LlmUnreachableError` → 502 with body
   `{"error":{"code":"translation_failed","message":<non-empty string>,"detail":{"message_id":"<id>"}}}`.
   A following POST with a succeeding fake answers 200 `"cached":false`.
   (US-048.AC-1, US-048.AC-2, D5)
3. `[test]` Another user's partner row, a settled turn, a zone row and an unknown id each
   answer 404 `message_not_found`, and the factory was never called. A non-numeric id
   answers 422. No cookie answers 401. (D6, R5)
4. `[test]` No enabled model on the instance → 409 `no_model_enabled`; a disabled captured
   model → 409 `model_not_enabled`. (D5)
5. `[test]` With the factory dependency **not** overridden, the route resolves the real
   `LlmClient` factory. The test asserts this by overriding nothing but `get_settings`,
   pointing the server's base URL at an unroutable address with a tiny timeout, and getting
   502 `translation_failed`. (D12)
6. `[test]` The app's routes contain path `/api/messages/{message_id}/translation` exactly
   once, with method POST. (D12)
7. `[manual/live]` With a real model: flick a partner block and stop it mid-call from the
   browser (step `005`'s cancel). The server log shows either
   `translate cached=false … written=false` (disconnect seen) or a normal write. Either is
   acceptable: the stop is best-effort (US-133.AC-2, D4). A later flick then answers
   instantly or re-translates accordingly.
