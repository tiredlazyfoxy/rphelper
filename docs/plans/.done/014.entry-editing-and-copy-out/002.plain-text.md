# Step 002 — The pure markdown-to-plain-text module

## Goal

Add `app/plainText.ts`, a pure, DOM-free, dependency-free function that turns a settled
text into plain text by removing CommonMark syntax and keeping the author's words and line
structure, exactly per `002.context.md` "The stripping rules, as spec" (D8, US-124.AC-1).

## Source files

frontend/src/app/plainText.ts

## Test files

frontend/tests/app/plainText.test.ts

## Interface intent

**`app/plainText.ts`** (new) — pure functions only; no DOM, React, MobX, network or
`shared/` import.

- **`toPlainText`**: takes a text (string); returns its plain-text form (string) by the
  three stages of the spec — line rules (line endings, fences, blockquotes, dropped
  lines, headings, list bullets, hard breaks), inline rules per paragraph (code spans,
  escapes, images, links, autolinks, emphasis), and the whitespace tidy-up. Never throws;
  never alters `(( ))`; returns `""` for `""`.
- Module-private helpers are the coder's choice. No other export is required.

## Definition of done

1. `[test]` Emphasis: `toPlainText` returns exactly the outputs of `002.context.md`
   examples E1–E11 (strong, emphasis, both, nesting, across a single line break, not
   across a paragraph break, intraword `_` and spaced `*` left alone, escapes, an
   unclosed delimiter, intraword `*`). (US-124.AC-1, D8)
2. `[test]` Blocks: exactly the outputs of examples B1–B10 (ATX headings including
   closing hashes and a non-heading `#hashtag`, a setext underline, blockquotes including
   nested and a quoted list item, unordered bullets → `• ` with indentation kept, ordered
   numbers kept, a thematic break, a heading and a list item holding emphasis).
   (US-124.AC-1, D8)
3. `[test]` Code and links: exactly the outputs of examples C1–C8 (inline code, a
   double-backtick span holding a backtick, a backtick fence kept verbatim with its fence
   lines dropped, a tilde fence, an inline link with a title, an image, an autolink, a
   reference link with its definition dropped). (US-124.AC-1, D8)
4. `[test]` Whitespace: exactly the outputs of examples W1–W5 (hard breaks by trailing
   spaces and by trailing backslash, `\r\n` / `\r` normalised, blank-line runs collapsed
   and outer blank lines removed, the empty string, a final backslash kept). (D8)
5. `[test]` Left as typed: every input in examples L1–L6 (GFM strikethrough and table
   pipes, `(( ))`, raw HTML and an entity, an indented block, prose with `*` arithmetic, a
   no-syntax multi-paragraph text) is returned **byte-for-byte unchanged**. (D8, R12)
6. `[test]` `plainText.ts` imports nothing — checked by reading the module's source text
   from disk. (D8)
