# Step 003 — The enormous-paste warning

## Goal

Add the pure paste-size estimate (`app/pasteCost.ts`, D3), the second sanctioned
notification outlet (`shared/notifyWarning.ts`, D4) with the convention test amended to
allow it, and make 013's composer raise the context-cost warning on an enormous paste in
both positions without ever blocking, delaying or altering the paste or the partner filing

## Interface intent

**`app/pasteCost.ts`** (new) — pure; imports nothing.

- **Characters-per-token constant** (value 4) and **warning-threshold constant** (value
  32,000 tokens), both exported and named.
- **`estimateTokens`**: takes a text; returns the token estimate — the text's `length`
  divided by the characters-per-token constant, rounded **up**.
- **`isEnormousPaste`**: takes a text; true iff its estimate is **strictly greater**
  than the threshold. Does not trim or test blankness (the caller does).

**`shared/notifyWarning.ts`** (new)

- **Warning identifier type**: a closed set of warning identifiers with exactly one
  member today — the paste context-cost warning.
- **`notifyWarning`**: takes one identifier from that set (no free text, no colour, no
  timeout parameter); raises one Mantine notification whose message is the fixed sentence
  the module maps that identifier to (UI strings table) and whose colour is **yellow**.
  The outlet's `autoClose` (5s) applies. Returns nothing.

**`app/Composer.tsx`** (edited — 013 `006`)

- The composer's paste handler now runs on **both** positions. It reads the pasted plain
  text; when that text is **not blank** and `isEnormousPaste` is true, it calls
  `notifyWarning` with the paste identifier — synchronously, not awaited, before
  anything else.
- Then, unchanged from 013: on *partner* it prevents the default insertion and hands the
  text to `filePastedPartner`; on *my turn* it does **not** prevent the default, so the
  browser inserts the paste into the composer as usual.
- Nothing else in the composer changes; 013 `006`'s `Composer.test.tsx` must keep passing
  unedited.

## Definition of done

1. `[test]` The two constants are 4 and 32,000. `estimateTokens`: `""` → 0; `"abcd"` → 1;
   `"abcde"` → 2; a 128,000-character text → 32,000. (D3)
2. `[test]` `isEnormousPaste`: a 128,000-character text → false; 128,001 characters →
   true; 500,000 characters → true; `""` → false. (D3, US-035.AC-1)
3. `[test]` `pasteCost.ts` imports nothing — read from disk. (D3)
4. `[test]` `notifyWarning` with the paste identifier calls Mantine's
   `notifications.show` exactly once with message **exactly** "This paste is very large
   and will take up a lot of the assistant's context." and colour `"yellow"` — never
   `"red"`. (D4, US-035.AC-1)
5. `[test]` (amends the convention test "Mantine's notification API is imported by
   shared/notifyFailure.ts alone") Exactly two source files import
   `@mantine/notifications`: `shared/notifyFailure.ts` and `shared/notifyWarning.ts`; a
   third importer would fail the test. (D4)
6. `[test]` On *partner*, pasting a 128,001-character non-blank text calls `notifyWarning`
   once with the paste identifier **and** still POSTs `/api/sessions/<id>/entries` with
   exactly `{"kind":"partner","text": <that text>}`; the composer's value is unchanged and
   the paste's default is prevented. (US-035.AC-1, US-035.AC-2, D5)
7. `[test]` On *partner*, pasting a 128,000-character text makes the same POST and does
   **not** call `notifyWarning`. (D3, D5)
8. `[test]` On *my turn*, pasting a 128,001-character text calls `notifyWarning` once,
   makes no request, and does **not** prevent the default (the paste event reports not
   default-prevented). (US-035.AC-1, US-035.AC-2, D5)
9. `[test]` On *my turn*, a short paste calls no `notifyWarning`, makes no request and is
   not default-prevented. A 128,001-character paste of only whitespace calls no
   `notifyWarning` in either position. (D5)
10. `[manual/live]` In a browser with the stream mounted: pasting ~150,000 characters on
    *partner* shows a yellow notification with the sentence, which disappears after about
    five seconds, while the partner entry is filed and appears in the record; on *my turn*
    the same paste lands in the composer with the same notification; a short paste shows
    nothing. (US-035.AC-1, US-035.AC-2)
