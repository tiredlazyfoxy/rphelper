# Step 005 — admin Database page: Export action and size line

## Goal

Give the admin Database page a page-level action group beside its title, holding an
Export button that downloads the whole-database export. After a successful export
the page shows only the downloaded file's size, inline. Failures render in the
page's inline red Alert.

## Source files

- `frontend/src/admin/databasePageState.ts`
- `frontend/src/admin/DatabasePage.tsx`

## Test files

- `frontend/tests/admin/databasePageExport.test.ts`
- `frontend/tests/admin/DatabasePage.export.test.tsx`

## Interface intent

- **`DatabasePageState` gains three observable fields, and no methods:**
  - an export status (`idle` or `exporting`);
  - the last export's byte size (a number, or null when there is none);
  - an export error message (a string, or null).

  The export error is separate from the drift report's `errorMessage`, so that one
  failure never overwrites the other's message.
- **`exportDatabase(state, signal?)`.** A free function. It sets the status to
  exporting, then clears the previous size and export error. It calls
  `apiDownload("/api/admin/database/export", signal)`. On success it stores the
  returned `size`. On failure it stores the error's message for inline rendering.
  It returns the status to idle. It writes inside `runInAction` and early-returns
  on an aborted signal before writing. It raises no notification.
- **`formatByteSize(bytes)`.** A pure function rendering a byte count as short
  human text, e.g. `"512 B"`, `"12.3 KB"`, `"4.0 MB"` (1024-based, one decimal
  above bytes).
- **`DatabasePage`:**
  - The `Title` "Database" now sits in a page-level `Group` together with an
    action group. The action group holds one `Button` labelled "Export" with
    `leftSection` `IconDownload`, in a loading state while exporting. Later
    features add Import and Rebuild index to this same group.
  - After a successful export, the page renders one inline `Text` line stating the
    file's size, e.g. "Export downloaded — 12.3 KB".
  - An export failure renders in an inline red `Alert` above the table.
  - The page renders nothing else about the export.

## Definition of done

1. **DoD-1 [test]:** Clicking Export calls `fetch` for
   `/api/admin/database/export`, and after it resolves the page shows the
   downloaded size formatted by `formatByteSize`. (US-077.AC-1)
2. **DoD-2 [test]:** After a successful export whose response body contains
   sentinel content (a username, a character name, memo text, and table names such
   as `"characters"` and `"memos"`), none of that content, no table name and no row
   count appears anywhere in the rendered page. (US-078.AC-3)
3. **DoD-3 [test]:** Before and after an export, the page offers no control to
   view, open, preview or browse the export. The only export-related control is the
   Export button. (US-078.AC-1)
4. **DoD-4 [test]:** Before and after an export, the page offers no search or
   filter input over the export: there is no text input or searchbox tied to it.
   (US-078.AC-2)
5. **DoD-5 [test]:** A successful export raises no notification. Nothing renders
   in the notifications outlet. (`ui-conventions.md`, no success toasts)
6. **DoD-6 [test]:** A failed export (an error envelope, e.g. 500) renders its
   message in an inline red `Alert` on the page and raises no notification. The
   drift table and any drift `errorMessage` are left as they were.
7. **DoD-7 [test]:** The Export button carries an accessible name of "Export". It
   is rendered whatever the drift report's state is (in sync, drifted, or missing
   rows) and is not disabled by it.
8. **DoD-8 [test]:** `exportDatabase` sets the size on success and the export
   error on failure. It clears both at the start of a new export, and it writes
   nothing when its signal is already aborted.
9. **DoD-9 [test]:** `formatByteSize` renders 0 and values under 1024 in `B`,
   values under 1024² in `KB` with one decimal, and larger values in `MB` with one
   decimal.
10. **DoD-10 [test]:** `DatabasePageState` declares no methods. Its prototype
    carries only the constructor, so the pure-data-contract rule holds.
11. **DoD-11 [manual/live]:** In a browser, an admin clicks Export, a
    `rphelper-database-….json` file downloads, and the page shows only its size.
12. **DoD-12 [manual/live]:** `npm run typecheck` passes.
