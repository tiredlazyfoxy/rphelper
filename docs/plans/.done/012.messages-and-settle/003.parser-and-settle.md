# Step 003 — The `(( ))` parser and the settle service

## Goal

Add `services/parens.py`, the pure classify-and-strip parser (D8), and
`services/settle.py`, settle and re-open as one transaction each — the only writers of the
burial and settle columns (R11, D16). The parser shares this step because it is below the
50-line floor alone and settle is its only caller.

## Interface intent

**`services/parens.py`** (new) — two pure functions, no I/O, no connection, no `user_id`,
no imports from `app`, `sqlalchemy` or `fastapi`:

- **`classify`**: takes a message text; returns `"decision"` when the text, after
  trimming outer whitespace, starts with `((` and ends with `))`, else `"turn"`
  (`003.context.md` "The parser, as spec").
- **`strip_fragments`**: takes a message text; returns it with every fragment removed and
  the stated whitespace tidy-up applied, or **unchanged** when it contains no fragment.

**`services/settle.py`** (new) — every operation takes the Core `Connection` first and
`user_id` (int) as a **required positional** argument; imports nothing HTTP-shaped and,
from `app.services.`, only `parens`.

- **`SettleResult`**: frozen dataclass value: `entry_id` (int, the settled head),
  `kind` (`"turn"` or `"decision"`), `buried_ids` (the ids now buried under the head,
  ascending; empty when the zone held one row).
- **`ReopenResult`**: frozen dataclass value: `reopened_id` (int, the former head),
  `restored_ids` (the former group's ids, ascending; never empty).
- **`settle`**: takes the connection, `user_id` and a session id. In one write
  transaction: session check (`SessionNotFoundError`); read the session's zone through
  `current_zone` in id order; empty → `ZoneEmptyError`; head = the last row by id,
  whoever wrote it; classify the head's text — a decision keeps its text verbatim, a turn
  has its fragments stripped; bury every other zone row under the head (`related_to`,
  `updated_at`) **before** stamping the head (`settled_at`, `kind`, `text`, `updated_at`);
  bump the session. Returns a `SettleResult`. No assistant-answer precondition (US-135).
- **`reopen`**: takes the connection, `user_id` and a session id. In one write
  transaction: session check; zone non-empty → `ZoneNotEmptyError`; take the last row of
  `settled_entries` for the session by id; none, or no row buried under it →
  `NothingToReopenError` (D10); otherwise clear `related_to` (and bump `updated_at`) on
  the group and clear `settled_at` and `kind` (and bump `updated_at`) on the head; bump
  the session. The head's text is left as it is. Returns a `ReopenResult`.

Neither operation takes a target message id.

## Definition of done

**Parser** (`tests/test_parens.py`; expected values are the spec's, `003.context.md`)

1. `[test]` `classify` returns `"decision"` for `"((I need to step away for a bit))"`,
   `"  ((ooc))  \n"` (outer whitespace), `"((first line\nsecond line))"`,
   `"((one)) ((two))"`, `"((a)) prose ((b))"` and `"(())"`. (US-129.AC-1, D8)
2. `[test]` `classify` returns `"turn"` for `"She walks in."`,
   `"She walks. ((be dramatic)) Then sits."`, `"((hint)) She walks."` (does not end with
   `))`), `"She walks. ((x))"` (does not start with `((`), `"(( never closed"`,
   `"a single (paren) pair"` and `""`. (D8)
3. `[test]` `strip_fragments` returns the text **unchanged** — including leading and
   trailing whitespace, internal double spaces and runs of blank lines — when it holds no
   fragment: `"  She  walks.\n\n\n\nShe sits.  "` and `"(( never closed"` come back
   identical. (US-135.AC-1 "as-is", D8)
4. `[test]` `strip_fragments` examples: `"She walks. ((be dramatic)) Then sits."` →
   `"She walks. Then sits."`; `"((hint)) She walks."` → `"She walks."`;
   `"She walks ((x)), then sits."` → `"She walks, then sits."`;
   `"She walks. ((x))"` → `"She walks."`; `"Text ((note\nspanning)) more"` →
   `"Text more"`; `"Para one.\n\n((instruction))\n\nPara two."` →
   `"Para one.\n\nPara two."`. (US-130.AC-1, D8)
5. `[test]` Malformed turns never strip to empty (D8's edge case): `strip_fragments`
   maps `"((a)) (("` → `"(("` and `"x ((a))"` → `"x"`, and `classify` returns `"turn"`
   for both. (D8)
6. `[test]` The source of `app/services/parens.py` imports nothing from `app`,
   `sqlalchemy` or `fastapi`. (`backend-structure.md` "The `(( ))` seam")
