`'partner'`.

## Settle and re-open take no body

Declare no body parameter. A client that sends a JSON body anyway is not refused (FastAPI
ignores an undeclared body); nothing in the request can name a target row
(`backend-structure.md`: "Session-addressed, the request cannot express an illegal target
at all").

## Path coexistence

`/api/sessions/{session_id}/entries`, `…/zone`, `…/zone/messages`, `…/settle`, `…/reopen`
sit beside 011's `/api/sessions/{session_id}`, `…/archive`, `…/restore`: distinct literal
segments, no overlap. `/api/messages/{message_id}` has no other owner. Registering after
the sessions router keeps 011's routes matched first (DoD-20).

## 405 for DELETE (DoD-17)

No `DELETE` handler is declared. Starlette answers 405 for `DELETE /api/messages/{id}`
because the path matches the `PATCH` route. DoD-17's route-table check walks
`app.routes` (path strings and methods); it covers the whole application, not only this
router, so it also guards against a later feature adding a discard route elsewhere.

## Test seeding

Users A and B (role `roleplayer`) through the file-local `_insert_user`, each logged in on
its own client. A character through `POST /api/characters`, sessions through
`POST /api/characters/{id}/sessions` with `{}` (no setup — DoD-16's US-024.AC-2 half
relies on it). DoD-5's assistant row is a raw insert into `messages` through the test
engine (`role='assistant'`, the session's id and owner, an id larger than the appended
rows' — e.g. the largest appended id plus one — and NULL `related_to` / `settled_at` /
`kind`). Message ids for PATCH come from the append / partner responses; a buried
message's id is an appended id that a later settle reported in `buried_ids`. DoD-15
reads `last_used_at` through `GET /api/sessions/{id}` and the order through
`GET /api/sessions`. "Nobody's" ids are large decimal strings no row holds.

## Gotcha — the 500 000-character body (DoD-8)

The test client posts directly to the application, so nginx's `client_max_body_size`
(`deployment.md`) is not in the path; DoD-8 proves only that no application layer refuses
an enormous text. The nginx half stays `deployment.md`'s.
