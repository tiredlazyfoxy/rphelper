  transport=None)`; `probe()`, `embed()`; `_url()` composes the `/v1` path (tolerates a
  trailing slash and an already-present `/v1`); `_http()` builds a fresh

  `chat_stream` is absent. **Delete exactly those two.** The structural tests in the same file
  (client.py imports no `fastapi` / secrets / DB) stay and must pass.

  level) -> EnabledChatModel(server: LlmServer, model_name)`; `LlmServer` has `id` and

## Gotchas local to this step

- `chat_stream` must be an **async generator method** (or return one) whose httpx
  `stream(...)` context is entered inside the generator, so `aclose()` unwinds it — that
  closure is the whole upstream-cancel mechanism (019 D6).
- A non-2xx check happens after the response headers arrive and **before** reading any line.
- Do not log provider bodies or message content; the existing unreachable helper's `detail`
  convention (`reason`) applies.
- `open_chat_client` lives beside `probe_server`; it is a sync read and must not hold the
  connection beyond the read (no transaction left open — use the same read posture as
  `probe_server`).
