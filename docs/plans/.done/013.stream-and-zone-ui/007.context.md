## The controller's lifetime

One `AbortController` per mount, created inside the mount effect (so a StrictMode
double-mount aborts the first and creates a second), held where the children can reach
its signal (e.g. a ref read at render, or state set by the effect). Every effect a child
calls receives it, so a response arriving after navigation away writes nothing (`003`
"Abort posture").
