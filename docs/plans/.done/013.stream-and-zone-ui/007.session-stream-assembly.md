## Interface intent

**`app/SessionStream.tsx`** (new)

- **`SessionStream`**: `observer` component. Props: `sessionId` (string). Creates its
  `StreamState` once with `useState`; on mount runs `loadStream` with an `AbortController`
  that is aborted on unmount, and hands that controller's signal to every child that calls
  an effect. Renders by `state.status`:
  - `"idle"` / `"loading"`: a centred `Loader`;
  - `"failed"`: the text **"Could not load the stream"** and a button **"Retry"** that
    re-runs the load — rendered in place, never a notification;
  - `"ready"`: in one column (`maw={720}`, centred, `px={18}` — style props), in this
    order: `StreamRecord` (`004`); the **ruler** — a Mantine `Divider` with the visible
    label **"Current zone"**, exposed as role `separator` with accessible name "Current
    zone", the stream's only separator (D12); `KindSwitch` (`006`); `ZoneList` (`005`);
    `Composer` (`006`).
  - Archived sessions are not distinguished: the stream renders and works the same (R6).

**`app/SessionScreen.tsx`** (edited — 011 `009`)

- The ready render keeps 011's header (character link, start-time heading, setup label,
  "Archived" badge) and replaces the **"No entries yet."** line with `SessionStream` for
  the screen's `sessionId`. Nothing else changes: the loading, not-found and failed
  renders, `SessionRoute` and its keying by id are untouched. "No entries yet." is now
  `StreamRecord`'s empty-record line (`004`).
