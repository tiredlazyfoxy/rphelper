# Step 002 — The stream state: data class, derivations, load and the synchronous actions

## Goal

Add `app/streamState.ts` with `StreamState` (observable fields only), the pure derivations
the stream components read (kind default, effective position, Settle / Send / Discard /
Re-open availability, settle target and preview), the abort-aware load of both lists, and
the three synchronous actions (set the draft, choose a position, discard).

## Source files

frontend/src/app/streamState.ts

## Test files

frontend/tests/app/streamState.test.ts

## Interface intent

**`StreamKind`**: the two switch positions, `"partner"` and `"turn"`.

**`StreamState`** — data class, observable fields only (`makeAutoObservable`, no methods,
no getters), constructed from a `sessionId` (string):

- `sessionId`;
- `entries` — the record (`Message` array), starts empty;
- `zone` — the zone (`Message` array), starts empty;
- `status` — `"idle"`, `"loading"`, `"ready"` or `"failed"`, starts `"idle"`;
- `draft` — the composer text, starts empty;
- `kindOverride` — a `StreamKind` or null (null = follow the default), starts null;
- `busy` — whether a send / file / settle / re-open is in flight, starts false
  (written by `003`).

**Derivations** — pure free functions; none mutates its input:

- **`isBlank`**: takes a string; true when it is empty or whitespace only (D16).
- **`defaultKind`**: takes an entries list; scans from the end for the last entry whose
  kind is `partner` or `turn`; returns `"turn"` after a partner, `"partner"` after a turn,
  and `"turn"` when there is none (D8).
- **`effectiveKind`**: takes the state; the override when set, else the default of its
  entries.
- **`canSend`**: takes the state; true when the draft is not blank and not busy.
- **`canSettle`**: takes the state; true only when the effective position is *my turn*,
  not busy, and the zone has at least one row **or** the draft is not blank. Never
  consults any row's role (US-135).
- **`showsDiscard`**: takes the state; true when the zone has no rows and the draft is
  blank (D3).
- **`showsReopen`**: takes the state; true when the zone has no rows, the record has at
  least one entry, and the **last** entry's kind is not `partner` (D4). Does not consult
  the draft.
- **`settleTargetText`**: takes the state; the draft when it is not blank, else the last
  zone row's text, else null (D1, D2, US-126).
- **`settlePreviewOf`**: takes the state; null unless the effective position is *my turn*
  and there is a settle target; otherwise `previewSettle` (from `001`) of the target.

**Effect and actions:**

- **`loadStream`**: takes the state and an optional signal. Sets `"loading"`, requests the
  entries and the zone (both), and on success writes both lists **in the order received**
  with `"ready"`, applying the override rule below. Any failure writes `"failed"` and
  leaves the lists as they were. Writes nothing once aborted; never rejects.
- **`applyEntries`**: takes the state and a freshly read entries list; writes it, and
  clears `kindOverride` **iff** the new list's id sequence differs from the held one (D8).
  Shared by the load here and by `003`'s re-reads.
- **`setDraft`**: takes the state and a string; writes `draft`.
- **`chooseKind`**: takes the state and a `StreamKind`; writes `kindOverride`.
- **`discardZone`**: takes the state; clears `draft` (only ever whitespace when the
  control is offered) and clears `kindOverride`. Makes no request (R11, D3).

All writes happen inside MobX actions (`runInAction` after an `await`).

## Definition of done

1. `[test]` A fresh `StreamState("s1")` has `sessionId` "s1", empty `entries` and `zone`,
   `status` `"idle"`, `draft` `""`, `kindOverride` null and `busy` false.
2. `[test]` `loadStream` sets `"loading"` while pending, requests exactly
   `GET /api/sessions/s1/entries` and `GET /api/sessions/s1/zone`, then `"ready"` with both
   lists exactly as served, in served order, ids the identical strings. (D13)
3. `[test]` `loadStream`: a failure of either GET (500 envelope, or transport failure)
   writes `"failed"`, keeps the previous lists and resolves without throwing; with its
   signal aborted before the responses settle it writes nothing. (D15)
4. `[test]` `defaultKind`: last partner-or-turn entry a turn → `"partner"`
   (US-120.AC-1); a partner → `"turn"` (US-120.AC-2); `[partner, turn, decision,
   decision]` → `"partner"` and `[turn, partner, decision]` → `"turn"` (US-120.AC-3);
   empty list → `"turn"`; `[decision]` only → `"turn"`. (D8, US-034.AC-1)
5. `[test]` `effectiveKind` follows the default with no override and returns the override
   once `chooseKind` sets one. `applyEntries` with the same id sequence keeps the
   override; with a different one (an entry added or removed) clears it. (D8)
6. `[test]` `canSettle`: on *my turn* with one zone row whose role is `user` and a blank
   draft → true (US-135.AC-1); with an empty zone and a non-blank draft → true (D2); with
   an empty zone and a blank (`"  \n"`) draft → false; on *partner* with zone rows and a
   draft → false (D2); while `busy` → false. A zone holding only an `assistant` row also
   → true (US-126.AC-1).
7. `[test]` `canSend` is true for a non-blank draft on either position and false for a
   blank draft or while `busy`. (D6, D7)
8. `[test]` `showsDiscard`: empty zone + `""` draft → true; empty zone + whitespace-only
   draft → true; empty zone + `"x"` draft → false; one zone row + `""` draft → false.
   (US-134.AC-1, US-134.AC-2, D3)
9. `[test]` `discardZone` with an override set and a whitespace-only draft clears both,
   leaves `entries` and `zone` unchanged, and makes no request. (UC-086, D3)
10. `[test]` `showsReopen`: empty zone, last entry a `turn` → true; last entry a
    `decision` → true; last entry a `partner` (even with an earlier turn) → false; one
    zone row → false; no entries → false; a non-blank draft with an empty zone does not
    change the answer. (US-128.AC-1, US-128.AC-2, D4)
11. `[test]` `settleTargetText`: non-blank draft → the draft; blank draft with zone rows
    → the **last** zone row's text (whoever wrote it); blank draft and empty zone → null.
    `settlePreviewOf`: on *my turn* with target `"((x))"` → decision / no strip; with
    target `"She walks. ((x)) On."` → turn / strips; on *partner* → null; with no target
    → null. (US-126.AC-1, US-126.AC-2, D1)
12. `[test]` An `autorun` reading `effectiveKind` re-runs after `chooseKind`, one reading
    `canSettle` re-runs after `setDraft`, and one reading `status` re-runs after
    `loadStream` settles (the writes are MobX actions on observable fields).
