# Step 004 — `react-markdown`, the message renderer with paren painting, and the settled record

## Goal

Add `react-markdown` as a frontend dependency, `app/MessageBody.tsx` (one renderer with
three variants — painted, decision, plain — D5), and `app/StreamRecord.tsx` (the settled
record list with per-kind rendering and the re-open control on the last entry, D4, D11).

## Interface intent

**`frontend/package.json` / `package-lock.json`** (edited)

- `react-markdown` added to `dependencies` at its current major release, installed with
  `npm install react-markdown` from `frontend/` so the lockfile is regenerated, not
  hand-edited. No other dependency changes.

**`app/MessageBody.tsx`** (new)

- **`MessageBodyVariant`**: `"painted"`, `"decision"` or `"plain"`.
- **`MessageBody`**: component. Props: `text` (string) and `variant`. Not an observer (it
  reads no observable; callers pass plain values).
  - `"plain"`: the text rendered as markdown through `react-markdown`. No painting.
  - `"decision"`: the **out-of-character card** — a Mantine surface with a **dashed,
    accent-coloured border** (style props only), the label **"Out of character"**, and the
    text rendered as markdown inside it. The card element carries the attribute
    `data-paren="ooc"`.
  - `"painted"`: when `isWhollyParenthesised(text)` (`001`) the same card as
    `"decision"`; otherwise the text's segments from `splitParenSegments` (`001`) in
    order — prose segments rendered as markdown, each fragment as an **inline chip**
    (a small Mantine element, e.g. a `Badge` with text transform off, or a `Text` span
    with a background) whose text content is the fragment verbatim (parentheses included)
    and which carries `data-paren="fragment"`. With no fragment, identical to `"plain"`.
  - Never alters the text it is given; raw HTML in the text is not rendered as HTML
    (`react-markdown`'s default).

**`app/StreamRecord.tsx`** (new)

- **`StreamRecord`**: `observer` component. Props: `state` (`StreamState`) and an
  optional `signal` (`AbortSignal`) passed on to the effect it calls. Renders a list
  labelled **"Settled record"**, one list item per entry in the order of `state.entries`,
  each with a header holding its kind label — **"Partner"**, **"My turn"** or
  **"Decision"** — and a body:
  - `partner`: `MessageBody` `"plain"` inside a `blockquote` (Mantine `Blockquote`, the
    "quoted surface");
  - `turn`: `MessageBody` `"plain"`;
  - `decision`: `MessageBody` `"decision"` (the card by kind, never by re-parsing).
  - The **last** entry's header also holds the `IconButton` (`IconArrowBackUp`) labelled
    **"Re-open last entry"** when `showsReopen(state)` (`002`) is true, absent otherwise;
    disabled while `state.busy`; pressing it calls `reopenLast` (`003`) with the state and
    the signal.
  - No copy control and no edit control on any entry (D11).
  - With no entries: the text **"No entries yet."** in place of the list items.

## Definition of done

1. `[test]` `frontend/package.json` lists `react-markdown` under `dependencies`.
   `tests/build-config.test.ts` passes: if it pins the dependency set, it is amended to
   include `react-markdown` and nothing else changes in it. (D5)
2. `[test]` `MessageBody` `"plain"` with `"Some **bold** text"` renders a `strong`
   element containing "bold"; with `"She said ((hi))"` it renders no `data-paren`
   element and the text "((hi))" as ordinary text. (D5, US-121.AC-2)
3. `[test]` `MessageBody` `"painted"` with `"She walks. ((make it tense)) He waits."`
   renders exactly one `data-paren="fragment"` element whose text is
   `((make it tense))`, positioned in the DOM after the text "She walks." and before
   "He waits." (D5)
4. `[test]` `MessageBody` `"painted"` with `"((one)) and ((two))"` renders the
   out-of-character card (`data-paren="ooc"`, label "Out of character") containing the
   text, and no fragment chips. (D5, D1)
5. `[test]` `MessageBody` `"painted"` with `"(( never closed"` renders no `data-paren`
   element and shows the text as is. (D1)
6. `[test]` `MessageBody` `"decision"` with `"plain words"` (no parentheses) renders the
   out-of-character card with "Out of character" and "plain words". (D5, R12)
7. `[test]` `StreamRecord` with entries `[partner "P1", turn "T1", decision "((D1))"]`
   renders the "Settled record" list with three items in that order whose headers read
   "Partner", "My turn", "Decision"; the partner body is inside a `blockquote`; the
   decision item contains the `data-paren="ooc"` card. (US-030.AC-1, US-031.AC-1)
8. `[test]` A settled partner entry whose text is `"((wholly parenthesised))"` renders
   **no** `data-paren` element. (US-121.AC-2, D5)
9. `[test]` No settled entry of any kind offers a control whose accessible name contains
   "Copy" — in particular none inside the decision item. (US-123.AC-1, D11)
10. `[test]` With an empty zone and the last entry a `turn` (and again a `decision`),
    "Re-open last entry" is present inside the **last** list item only; pressing it POSTs
    `/api/sessions/<id>/reopen`. With the last entry a `partner` it is absent. (D4,
    US-128.AC-1)
11. `[test]` With one zone row, "Re-open last entry" is absent — not disabled.
    (US-128.AC-2, D4)
12. `[test]` With no entries, "No entries yet." is shown and no list item is rendered.
