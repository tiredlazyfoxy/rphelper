## Why the editor is keyed to the row, not the index

The zone is re-read after a failed edit and could change length (a row settled from
another tab). Rendering each item keyed by the message's id string keeps an open editor
attached to its own row, and makes DoD-6's disappearance automatic.

## Tool rows

`role='tool'` rows have no writer before `021`; they render here as ordinary editable
messages labelled "Tool". The collapsible tool / thinking blocks (US-114) are `021` /
`022`'s and are not designed here.
