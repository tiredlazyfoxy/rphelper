## Paste details

- Read the pasted text with `event.clipboardData.getData("text/plain")`. Call
  `preventDefault()` **only** on the *partner* position.
- The effective position is read at paste time (`effectiveKind(state)`), not cached.
- Blank pastes are filtered by `filePastedPartner` itself (`003`); the handler still
  prevents the insertion on *partner* so nothing lands in the composer.

## Placement of the switch

`workspace-shell.md` puts the switch **above the zone**, not inside the composer, so it is
its own component; `007` places it between the ruler and the zone list. The composer
reads the same state, so both always agree.

## Mantine `Textarea` `minRows`

Mantine's default `sm` textarea line height makes `minRows={2}` land close to 42px; the
exact value is the `[manual/live]` item. `autosize` uses `react-textarea-autosize`, which
is already a dependency of `@mantine/core` — no new package.

## What "disabled, not hidden" means for Settle on *partner*

The "Settle" button is in the DOM with the `disabled` attribute. Discard and re-open are
the opposite case — absent when unavailable — because their actions do not exist at that
moment (`workspace-shell.md`), whereas Settle exists and is merely not applicable on that
position.
