# Step 001 — The two tables, the four error codes, the timeout setting, and write-time `"$ENV_VAR"` validation

## Goal

Put everything this feature needs at the infrastructure layer in place before any service
exists: the `llm_servers` and `models` tables in the one registry, the four new
`DomainError` subclasses, the single outbound-call timeout setting, and the annotated
pydantic field type that rejects a pasted raw credential on write.

## Interface intent

**`backend/app/db/schema.py`** — two new `Table(...)` literals appended to the one
`metadata` already in the file. No per-feature table module, no builder callable, no
import-side-effect registration; the file's own docstring binds this.

- **An `llm_servers` table** with exactly the columns `data-model.md` names: the
  snowflake primary key (big integer, **not** autoincrementing), an admin-facing name, the
  provider kind, the base URL, the nullable API-key **pointer**, the three nullable
  last-test columns (an instant, a boolean outcome flag, and the typed outcome value), and
  the two `*_at` bookkeeping columns. Timestamps are UTC ISO-8601 **text**, matching the
  file's existing convention. `kind` is plain text with **no `CHECK`** — its two allowed
  values are enforced at the pydantic boundary (`context.md` D5). **No `active` column**
  (`context.md` D1).
- **A `models` table** with the columns `data-model.md` names: the snowflake primary key,
  the owning server id as a **foreign key** to `llm_servers.id` declared
  `ON DELETE CASCADE`, the model name as the server names it, the enabled flag, the
  embedding-designation flag, the nullable embedding dimension, and the two `*_at`
  columns. A **unique constraint on the (server id, model name) pair**. The enabled and
  designation flags are non-nullable booleans defaulting to false; the dimension is
  nullable and meaningful only on the designated row.

  The cascade is declared even though step `003`'s delete also removes the child rows
  explicitly inside its own transaction: the declaration is the schema's structural truth
  and is what `db/drift.py` (feature `007`) will introspect, while the explicit delete
  keeps the behaviour independent of whether a given connection happened to have
  `PRAGMA foreign_keys` set.

**`backend/app/errors.py`** — four new `DomainError` subclasses and **nothing else**. No
handler is added, no handler is edited, `register_exception_handlers` is untouched: a new
code is a new subclass and that is all.

- **An unreachable-provider error** — code `llm_unreachable`, status **502**.
- **A no-embedding-model error** — code `no_embedding_model`, status **409**.
- **A model-not-enabled error** — code `model_not_enabled`, status **409**.
- **A server-not-found error** — code `llm_server_not_found`, status **404**; the sibling
  of `005`'s account-not-found, needed by every id-addressed route here.

Each keeps the base class's `message` / `detail` constructor unchanged. Callers supply
`detail`; the classes hard-code nothing into it.

**`backend/app/config.py`** — one new field on `Settings`: the **outbound-call timeout in
seconds**, a float defaulting to **30.0**, with an explicit
`RPHELPER_LLM_REQUEST_TIMEOUT_SECONDS` validation alias like every other field. No
`env_prefix`, no other field changed, `get_settings`'s `lru_cache` untouched.
`context.md` D13 carries the reason for the value.

**`backend/app/models/secret_ref.py`** — a new module holding this feature's write-time
half of the `"$ENV_VAR"` pattern, mirroring `models/ids.py` as the home for an annotated
wire-boundary type. `app/secrets.py` is **not** edited.

- **A pure predicate** over a candidate pointer string, usable with no pydantic at all:
  the empty string is valid and means "no pointer"; a value starting with `$` **and
  carrying at least one character after it** is valid; everything else — a raw key, a bare
  `$`, leading whitespace before the `$` — is invalid. No trimming, no case folding, no
  normalisation: the value is stored exactly as received.
- **An annotated `str` alias** that applies the predicate as a field validator and raises
  a validation error for an invalid value, so a request model that uses it answers
  FastAPI's own **422** and adds no domain error code (`context.md` D8). Naming follows
  `models/ids.py`'s inbound/outbound aliases.

## Definition of done

1. `[test]` `metadata` gains an `llm_servers` table whose columns are exactly the set
   `data-model.md` names and whose primary key is a big integer that is **not**
   autoincrementing. (UC-010; `data-model.md`'s `llm_servers`)
2. `[test]` `llm_servers` declares **no `active` / `is_active` / `enabled` column** — the
   deliberate deviation from `admin-surfaces.md` recorded as `context.md` D1. (**no
   product id**)
3. `[test]` `metadata` gains a `models` table with the columns `data-model.md` names,
   including the nullable `embedding_dim`, and its `server_id` is a foreign key to
   `llm_servers.id` declared `ON DELETE CASCADE`. (UC-012, UC-013)
4. `[test]` `models` carries a **unique constraint on (server id, model name)**, and the
   enabled and designation flags are non-nullable and default to false. (UC-012,
   `context.md` D10)
5. `[test]` `create_all` against a fresh file database creates both tables and no other
   new table, and inserting two rows with the same (server id, model name) pair is
   refused while the same model name under two different servers is accepted. (UC-012)
6. `[test]` Deleting an `llm_servers` row on a connection with `PRAGMA foreign_keys = ON`
   removes that server's `models` rows and leaves every other server's rows untouched.
   (`context.md` D10)
7. `[test]` Every table in the registry still uses the one shared `metadata` object, and
   no new module registers a table by import side effect. (`db/schema.py`'s docstring —
   **no product id**)
8. `[test]` Each of the four new classes is a `DomainError` subclass carrying its code and
   status — `llm_unreachable` **502**, `no_embedding_model` **409**, `model_not_enabled`
   **409**, `llm_server_not_found` **404** — and each renders through the base wire shape
   `{"error": {"code", "message", "detail"}}` with a caller-supplied `detail` preserved
   intact. (`context.md` D7; `backend-structure.md`'s error model)
9. `[test]` `errors.py` registers **no additional exception handler**: the set of handlers
   `register_exception_handlers` installs is unchanged from before this step.
   (`backend-structure.md` — **no product id**)
10. `[test]` `Settings` exposes the outbound-call timeout with default **30.0**, reads it
    from `RPHELPER_LLM_REQUEST_TIMEOUT_SECONDS`, and ignores any unprefixed variable of a
    similar name. No other field's default or alias changed. (`context.md` D13;
    `backend-structure.md`'s Configuration section — **no product id**)
11. `[test]` The pointer predicate accepts the empty string and any value of the form
    `$` followed by at least one character, and rejects a raw key, a bare `$`, and a value
    with anything before the `$`. The value is never trimmed or altered. (UC-010;
    `backend-structure.md`'s secret-pointer pattern)
12. `[test]` A pydantic model using the annotated alias rejects an invalid pointer with a
    **validation error**, not a `DomainError`, and accepts the empty string — the state
    that means "clear" in `context.md` D9. (`context.md` D8 — **no product id**)
13. `[test]` `app/secrets.py` is unchanged: `resolve_secret` still maps `'$NAME'` to the
    environment variable, `None` to `None`, and anything else to `secret_ref_missing`,
    and the new module does not import from it at module scope for its predicate.
    (`backend-structure.md`; `secrets.py`'s own docstring — **no product id**)
14. `[manual/live]` `mypy app`, `ruff check .` and `pytest` all pass from `backend/`.
15. `[manual/live]` `main.py`'s lifespan still runs **no DDL**, and no startup path was
    added for either new table. Verifier confirms by reading `main.py`.
