# Step 008 — The shared probe-on-open picker and the enabled-models modal

## Goal

Build the picker both model modals share — probe on open, render the
`available ∪ already-enabled` union, survive a failed probe without disturbing the
selection — and the multi-select modal on top of it that saves a server's enabled set.

## Source files

```
frontend/src/admin/modelPicker.ts

frontend/src/admin/EnabledModelsModal.tsx
frontend/src/admin/LlmServersPage.tsx
```

## Interface intent

**`frontend/src/admin/modelPicker.ts`** — the shared half of both modals: what the server
offers, how it is loaded, and how it combines with what is already enabled. Step `009`
imports it unchanged.

- **A picker class** holding observable fields only: the available model names, an explicit
  idle/loading/ready/failed probe status, and a nullable probe-error message.
  `makeAutoObservable(this, {}, { autoBind: true })`; no methods, no computed getters.
- **A load-available free function** taking the picker, a server id and an optional
  `AbortSignal`. It `GET`s the available-models route, `runInAction`s its writes, and
  early-returns on an aborted signal before writing. **On failure it sets the status to
  failed, records the error's message, and sets the available list to empty — and it
  touches nothing else** (`context.md` D11).
- **A pure union function** taking the available names and the already-enabled names and
  returning the option list the modal renders: every name from either source, deduplicated,
  in a stable order, each marked with whether the server currently offers it — so a stale
  enablement renders and is still un-checkable. It is a pure function of two arrays,
  testable with no render and no network.

**`frontend/src/admin/enabledModelsDraft.ts`** — the multi-select half.

- **A draft class** holding observable fields only: the selected model names, the
  already-enabled names it was constructed from, a server-errors map with a general key,
  and an idle/submitting/done status. Constructed from the row's enabled names, so **the
  initial selection comes from the page's list payload and never from the probe**.
- **Pure derivations** taking the draft: whether the selection differs from what was
  loaded, and a can-submit predicate.
- **A submit free function** taking the draft, the server id, a re-load callback and an
  optional `AbortSignal`. It `POST`s the **complete** selected set to the enabled-models
  route, maps a failure onto the general key by status or code, and on success invokes the
  callback.

**`frontend/src/admin/EnabledModelsModal.tsx`** — an `observer` Mantine `Modal` taking the
picker, the draft and the callbacks as props. It renders a **`Loader`** while the probe is
in flight, an inline `Alert` when the probe failed — with the **checkbox list still
rendered from the union, selection intact** — and the checkbox list itself, each row
labelled with the model name and marked when the server no longer offers it. A general-key
error renders above the list. The save button is disabled while submitting. **No confirm
step** (`context.md` D18).

**`frontend/src/admin/LlmServersPage.tsx`** — one addition: a **Select Models** item in the
existing row menu, opening the modal for that row. Open flag and target row are
component-local `useState`; the modal body is conditionally mounted so a fresh picker and a
fresh draft are constructed per open. On success the modal closes and the page **re-loads**
— no success toast.

## Definition of done

1. `[test]` Opening the modal probes that server's available models exactly once and
   renders one checkbox per offered model. (UC-012)
2. `[test]` A model already enabled on that server is **checked on open**, and the initial
   selection comes from the page's list payload rather than from the probe response.
   (US-014.AC-1; `context.md` D11)
3. `[test]` **The union rule.** A model that is enabled but is **no longer offered** by the
   server still renders, still shows as checked, and can still be **unchecked and saved** —
   the state that would otherwise be unclearable. (`admin-surfaces.md`'s Models modal;
   `context.md` D10 — **no product id**)
4. `[test]` A model offered by the server and not enabled renders unchecked; checking it
   and saving `POST`s a set containing it, after which the page's re-loaded row reports it
   enabled. (US-014.AC-1)
5. `[test]` Unchecking an enabled model and saving `POST`s a set **without** it, after
   which the row no longer reports it enabled. (US-014.AC-2)
6. `[test]` The payload is the **complete** selected set, not a delta — saving after no
   change sends the same set that was loaded. (`context.md` D17 — **no product id**)
7. `[test]` Saving the empty selection is legal and disables every model on that server.
   (US-014.AC-2)
8. `[test]` **Failed-probe resilience.** When the probe fails, the modal shows an error,
   the available list is empty, **and the checkbox list still renders the already-enabled
   models with their selection intact** — saving at that point does **not** submit an empty
   set. (`admin-surfaces.md`'s "Failed-probe resilience"; `context.md` D11 — **no product
   id**)
9. `[test]` The union function is pure: given an available array and an enabled array it
   returns the deduplicated union in a stable order with each entry marked as offered or
   not, with no render, no store and no network. (`admin-surfaces.md`'s union rule — **no
   product id**)
10. `[test]` **Disabling is never refused and the modal offers no place to refuse it**: no
    warning, no count, no badge and no confirm appears between unchecking a model and
    saving, and nothing rendered in this modal names a session, a user or a number derived
    from either. (US-016.AC-1, UC-012, R5, UC-065, UC-066)
11. `[test]` A save failure renders on the **general key** above the list, mapped by status
    or code and never by parsing prose, and leaves the selection as the administrator left
    it. (`ui-conventions.md`'s draft convention, rule 3 — **no product id**)
12. `[test]` On success the modal closes and the list **re-loads**, and **no success
    notification is raised**. (`ui-conventions.md`, no success toasts and never optimistic
    — **no product id**)
13. `[test]` A `Loader` renders while the probe is in flight, gated on the explicit probe
    status rather than on "available is empty". (`ui-conventions.md`, loading states — **no
    product id**)
14. `[test]` Neither class declares a method or a computed getter; every effect is a free
    function that `runInAction`s its writes and early-returns on an aborted signal, and
    closing the modal mid-probe writes nothing afterwards. (`context.md` D16 — **no product
    id**)
15. `[test]` A **fresh picker and a fresh draft per open**: reopening after an unsaved
    change shows the stored state, not the abandoned one. (`ui-conventions.md`, draft
    lifetime — **no product id**)
16. `[test]` Every id handled here is a `string`, and no file added in this step imports a
    stylesheet. (`frontend-structure.md` — **no product id**)
17. `[manual/live]` Against a real server, opening the modal lists its real models,
    enabling two and saving is reflected in the row's enabled count, and pointing the
    registration at a dead host then reopening shows the error with the two still checked
    and still saveable.
18. `[manual/live]` `npm run typecheck`, `npm test` and `npm run build` all pass from
    `frontend/`.
