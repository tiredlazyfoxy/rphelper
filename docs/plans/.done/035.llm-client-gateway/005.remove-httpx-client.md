# Step 005 — Remove the httpx client; port the live tests

## Goal

This step deletes `services/llm/client.py` (and with it `ChatDelta`,
`ToolCallDelta` and `chat_stream`) and its `httpx`-transport tests. It ports the
opt-in live tests to the gateway, and adds a test that pins the gateway as the
only module that imports the library.

This step is below 50 lines of source change because it is almost entirely a
deletion. It cannot merge into step 004: the deletion is only safe once step
004 has removed the last importer, and folding it in would push step 004 past
the size budget.

## Source files

backend/app/services/llm/client.py

## Test files

backend/tests/test_llm_client.py
backend/tests/test_llm_chat_stream.py
backend/tests/test_live_llm.py
backend/tests/test_llm_gateway_boundary.py

## Interface intent

- **`app/services/llm/client.py`** is deleted. Its probe types already live in
  the gateway (DEC-035-2), and nothing else of it survives
  (`DEC-arch-llm-client-library-1`).
- **`test_llm_client.py`** and **`test_llm_chat_stream.py`** are deleted with
  the module they test (`DEC-arch-llm-client-library-11`).
- **`test_live_llm.py`** is ported per DEC-035-12.
- **`test_llm_gateway_boundary.py`** is new. It holds source-level checks over
  `backend/app/`.

## Definition of done

1. DoD-1 `[test]` — `app/services/llm/client.py` does not exist, and no module
   under `backend/app/` imports `app.services.llm.client`.
2. DoD-2 `[test]` — Under `backend/app/`, only `app/services/llm/gateway.py`
   imports the library package `llm` or any `llm.` submodule.
   (`DEC-arch-llm-client-library-1`)
3. DoD-3 `[test]` — Under `backend/app/`, `httpx` is imported only by the
   `web_search` provider package (`app/services/web_search/`).
   (`llm-and-streaming.md` § The LLM gateway over `llm-client`)
4. DoD-4 `[manual/live]` — With `LLAMA_SWITCH_URL` set:
   - the gateway (`kind` `'llamaswap'`) probes the server as `reachable` with a
     non-empty model list;
   - it embeds a text into a non-empty vector;
   - probing a closed local port reports `unreachable`.

   (UC-011, UC-013)
5. DoD-5 `[manual/live]` — With `LLAMA_SWITCH_URL` set, `complete` returns
   non-empty text for a short prompt. `compose` with no tool offered streams at
   least one `ComposeText` and ends without error, which confirms that the
   server accepts an empty `tools` list (DEC-035-10's flip check). (UC-034,
   UC-039)
6. DoD-6 `[manual/live]` — The default suite (`pytest`, no `-m live`) collects
   no test from the deleted modules, and the live tests are skipped without the
   variable.
