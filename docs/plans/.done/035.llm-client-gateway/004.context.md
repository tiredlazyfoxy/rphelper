  `"".join(exchange_parts)`, then `DoneFrame`.

  harness closes with a shielded `aclose()`. The inner gateway stream is closed
  only if it is iterated inside `contextlib.aclosing` (or an equivalent
  `try/finally` with `aclose`), and that close is what cancels the library task
  (DEC-035-7).
