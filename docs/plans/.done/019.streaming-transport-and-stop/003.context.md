## Touch site, as harvested: `src/shared/api.ts`

- **Exports.** `apiRequest<T>(path, method, body?, signal?)`, `apiGet`, `apiPost`,
  `apiPatch`, `apiDelete`, and `documentNavigation` (an object whose `assign` is the
  401-redirect seam tests spy on).
- **The path rule.** The path must start with `/api/`.
- **Fetch rejection.** On an aborted signal the rejection is rethrown raw. Otherwise it
  becomes `ApiError(CLIENT_TRANSPORT_FAILED, "The server could not be reached.", 0)`.
- **Non-2xx.** It goes through the private `decodeEnvelope(text, status)`, with the
  private `malformed(status)` as the fallback. The envelope is
  `{error:{code,message,detail?}}`. A 401 calls `documentNavigation.assign("/login")`
  first.
- **`src/shared/apiError.ts`** (not touched):
  - `class ApiError extends Error { code; status; detail }`, constructed as
    `(code, message, status, detail?)`;
  - constants `CLIENT_MALFORMED_ERROR` and `CLIENT_TRANSPORT_FAILED`;
  - the type guard `isApiError`.

**Existing tests.** `tests/shared/api.test.ts` stays untouched and must still pass;

## Parsing a frame

A frame is the text between two `"\n\n"` separators.

- Within it, each line starting `data:` contributes its remainder, with one leading space
  stripped. Several `data:` lines are joined with `"\n"`.
- A frame with no `data:` line, such as a comment-only frame (`: keepalive`), produces
  nothing.
- The joined data is `JSON.parse`d. JSON numbers would only appear where the server
  breaks the ids rule, and **no field is ever converted with `Number()` or `parseInt`**.
- Ids stay whatever string the server sent.

Treat `"\r\n"` as out of scope: the backend emits `\n` only (002).
