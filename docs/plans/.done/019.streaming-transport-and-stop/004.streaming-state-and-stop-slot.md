# Step 004 — Streaming state, the stop action, and Stop in Send's slot

## Goal

This step adds four things:

- **The compose call.** `app/streamApi.ts` gets a call to
  `POST /api/sessions/{id}/zone/compose`.
- **The streaming surface.** `StreamState` gets the streaming text (D11), the
  non-observable compose handle (D12), the `isStreaming` derivation, and the updated
  `canSend` and `showsDiscard` (D13).
- **The stop action.**
- **The Stop control.** While streaming, `Composer` renders Stop in Send's slot, with
  Send absent and Settle untouched.

## Interface intent

**`app/streamApi.ts`** (changed)

- **`composeZone`** (name final at skeleton). Inputs: session id (string), the text, the
  frame callback, the signal. It calls `003`'s consumer with path
  `/api/sessions/<encodeURIComponent(id)>/zone/compose`, built with the existing private
  `sessionPath`, and body `{text}`. It resolves to `003`'s outcome unchanged. No other
  call changes.

**`app/streamState.ts`** (changed)

- **`StreamState`** gains two fields:
  - **streaming text**: observable, `null` initially; `null` means not streaming.
  - **compose handle**: **not observable** (annotation `false` in `makeAutoObservable`),
    `null` initially. When set, it holds the compose's own `AbortController` and the
    promise that settles when that compose has wound down (D12).
- **`isStreaming`** (new derivation): true iff the streaming text is not `null`.
- **`canSend`** (changed): its existing rule **and** not streaming.
- **`canSettle`** (unchanged): explicitly **does not** consult streaming (D13,
  `workspace-shell.md` "The stop control").
- **`showsDiscard`** (changed): its existing rule **and** not streaming.
- **`stopCompose`** (new sync action): aborts the compose handle's controller if a handle
  exists; otherwise does nothing. It writes no field itself: the compose effect (`005`)
  reacts to the abort, re-reads and clears. It makes no request and sends no
  notification.

**`app/Composer.tsx`** (changed)

- **The Send slot.** When `isStreaming(state)`, the slot renders an `IconButton` with
  `icon={IconPlayerStop}` (from `@tabler/icons-react`), label **"Stop"**,
  `sizeVariant` `"main"`, calling `stopCompose(state)`. The "Send" button is **absent**,
  not disabled. When not streaming, Send renders exactly as before.
- **Unchanged.** The order of the Discard, slot and Settle controls, and Settle itself,
  which still renders on `canSettle` and still calls `settleComposer`.

## Definition of done

1. `[test]` `composeZone("7250000000000000042", "Hi ((short))", cb, signal)` issues one
   `fetch` POST to exactly `/api/sessions/7250000000000000042/zone/compose` with body
   exactly `{"text":"Hi ((short))"}`, and resolves to the consumer's outcome, e.g. done
   with messageId `"7250000000000000099"`. A session id containing `/` is
   percent-encoded in the path. (D9, 013 D14)
2. `[test]` A fresh `StreamState` has streaming text `null`, compose handle `null`, and
   `isStreaming` false. With streaming text `""`, `isStreaming` is true. (D11, D12)
3. `[test]` With a non-blank draft and `busy` false, `canSend` is true when not streaming
   and false while streaming. (D13)
4. `[test]` With one zone row on *my turn*, `canSettle` is true **both** when not
   streaming and while streaming. With an empty zone and a blank draft it is false in
   both cases. (D13, `workspace-shell.md` "The stop control", US-135.AC-1)
5. `[test]` With an empty zone and a blank draft, `showsDiscard` is true when not
   streaming and false while streaming. (D13)
6. `[test]` With a compose handle whose controller is fresh, `stopCompose` aborts that
   controller. The streaming text, `zone`, `entries`, `draft` and `busy` are unchanged by
   the call itself, no `fetch` is made, and `notifyFailure` is not called. With no handle,
   `stopCompose` does nothing and does not throw. (D12, UC-085)
7. `[test]` `Composer` while streaming (streaming text set, a handle present): a button
   with accessible name **"Stop"** is present, and **no** button named "Send" exists
   (absent, not disabled). Pressing "Stop" aborts the handle's controller. (UC-085,
   `workspace-shell.md`, `ui-conventions.md` icon table)
8. `[test]` `Composer` while streaming, on *my turn* with one zone row: "Settle" is
   present and **enabled**. (D13, `workspace-shell.md` "The stop control")
9. `[test]` `Composer` when not streaming: "Send" is present, and no "Stop" button exists.
   (D13)
10. `[manual/live]` In a browser, Stop renders as the `IconPlayerStop` glyph at the main
    size (18 / stroke 1.5) in exactly the place Send occupied, with a "Stop" tooltip.
    (`ui-conventions.md`)
