# Step 001 — tabbed shell

## Goal

Turn the ready character page into a header plus five Mantine tabs (D1, D2), move
Archive/Restore and Export into the header as icon-only buttons (D3), put Name and
a taller Persona in "Main info" (D4), move Configuration as-is (D5), and place the
Notes, Setups and Sessions sections into their tabs unchanged — composer above a
divider above the sessions list in the Sessions tab.

## Interface intent

- **`CharacterScreen` (ready mode)** — renders, in order: a **page header**
  (saved-name Title, "Archived" badge when archived, and the icon-only actions),
  the existing page-level error `Alert`, then a Mantine **`Tabs`** whose list holds
  five tabs labelled exactly **"Sessions"**, **"Main info"**, **"Configuration"**,
  **"Notes"**, **"Setups"** in that order. Default value is the Sessions tab;
  `keepMounted` is left at its default (true). The tabs are keyed by the character
  id so opening a different character starts on Sessions. Panels:
  - **Sessions:** `CharacterComposer`, then a Mantine `Divider`, then
    `SessionsSection` (both components unchanged in behaviour in this step).
  - **Main info:** the Name `TextInput` and the Persona `MarkdownEditor` (with its
    existing blur-save wrapper), the persona given a substantially larger minimum
    height.
  - **Configuration:** `CharacterConfigSection`, unchanged props.
  - **Notes:** `CharacterNotesSection`, unchanged.
  - **Setups:** `SetupsSection`, unchanged.
  Each section keeps its own distinct key prefix per character id.
- **Header icon actions** — `IconButton`s replacing the labelled buttons, keeping
  the current accessible names: **"Archive"** (`IconArchive`) or **"Restore"**
  (`IconArchiveOff`), and **"Export"** (`IconDownload`), rendered under the same
  conditions as today. Export is disabled while an export is in flight.
- **`MarkdownEditor`** (shared wrapper) — gains an **optional minimum-height
  input** for its editable content area; omitted, the editor renders exactly as
  today, so every other caller is unaffected.
- **`CharacterComposer`** — its section heading text becomes **"New session"**
  (was "Start a session"); nothing else changes in this step.
