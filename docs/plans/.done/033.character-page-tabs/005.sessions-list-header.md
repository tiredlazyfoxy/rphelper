# Step 005 — sessions list: drop the message-less start, icon Import in the header

## Goal

Remove the Sessions section's inline Setup select, "Start session" button and
`startSessionFromSection` path (D9), and move "Import session" into the list
header as an icon button beside the "Show archived sessions" switch (D8).

## Interface intent

- **`SessionsSection`** — header Group: "Sessions" Title, the unchanged
  "Show archived sessions" switch, and an **"Import session"** `IconButton`
  (`IconUpload`) driven by the existing `FileButton` (the render-prop's `onClick`
  feeds the `IconButton`'s `onClick`), **disabled while an import is in flight**.
  Below the header: the existing alerts and the sessions table / "No sessions
  yet." line, unchanged. The Setup select, the "Start session" button, the
  labelled "Import session" button row and the "Could not load setups to choose
  from." line are removed.
- **`sessionsSectionState.ts`** — `startSessionFromSection`, `selectSetup` and the
  selected-setup field are removed. Only `setupOptions` reads `setups` (the
  per-row setup label uses `session.setup_name`), so the setup-choices field
  (`setups`, `setupsStatus`) and `loadSetupChoices` are removed too, along with
  `startStatus`, `startError`, the `SessionStartStatus` type and the
  `START_FAILED` message.

## Definition of done

1. DoD-1 [test] The Sessions section renders no Setup select and no
   "Start session" button, and never shows "Could not load setups to choose
   from.". (D9)
2. DoD-2 [test] The Sessions section header holds the "Sessions" heading, the
   "Show archived sessions" switch and an "Import session" icon button. (D8)
3. DoD-3 [test] Choosing a file through "Import session" imports it as before
   (the session appears under this character, the coverage warning is raised),
   and the button is disabled while the import is in flight. (D8, US-082)
4. DoD-4 [test] Opening the page issues no message-less session create; the only
   way the page creates a session is the composer's send. (D9)
5. DoD-5 [test] The archived toggle, row menu (Archive / Restore / Export) and the
   "No sessions yet." line behave as before. (D8, US-027, US-028)
6. DoD-6 [manual/live] The Import tooltip shows on hover; the Sessions tab reads
   top to bottom as "New session" composer, divider, sessions list.

## Dependencies

001 (placement in the Sessions tab), 004 (the setup choice must exist in the
composer before the setup-bearing start control is removed).
