## Gotcha — Cancel versus blur

In opt-in mode a click on Cancel or Save moves focus out of the editor first. If
the blur-save stayed active, Cancel would save before discarding. That is why
opt-in mode has no blur-save (DoD-7) and Save is the only path to create.
