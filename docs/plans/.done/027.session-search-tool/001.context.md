## Test seeding notes

- **"Would match" construction.** Every excluded session in DoD-4..7 has a composed text
  identical to P's: the same persona text on its character, the same setup description (or
  none), and the same settled entries in the same order. Its fake vector is therefore
  identical, at distance zero from the query. Give each session's vector through the real
  024 path (`context.md` Test conventions).
- Ties: P and an excluded twin both sit at distance zero. DoD-4..7 assert presence and
  absence, never P's rank against a twin. DoD-3 asserts rank only where P is the sole
  zero-distance session in scope.
- DoD-10: Q's composed text is the persona alone. Give R entries whose text differs from
  the persona, and no setup, so R's vector differs from the query's. Q must not be the only
  in-scope session; otherwise "ranks ahead" is vacuous.
- DoD-7 clears `archived_at` with a raw update. No re-embed is needed because 024 embeds
  archived sessions too. If a test needs to refresh vectors anyway, it goes through 024's
  path.
- DoD-2 compiles against SQLite's dialect with `literal_binds` and inspects the text.
- DoD-12's "no designated model" means the `models` rows exist but none is designated (or
  there are none). Seed the vectors first, while a designated model exists, then remove the
  designation, so the index holds a match that cannot be reached.
- DoD-13 reads the module source as text, as earlier plans' import tests do.
