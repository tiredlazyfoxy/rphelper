## Touch sites (frontend harvest §7, §8)

- `sessionsState.ts`:
  - `class SessionsState { sessions: Session[]; status }` uses `makeAutoObservable` with autoBind.
  - `applySession(state, session): void` removes by id, drops archived sessions and re-inserts by `last_used_at` descending. **Today a session with the same `last_used_at` is inserted after equal rows, so the order can shift.** That is the defect DEC-034-12 fixes.
  - Ids are decimal strings (frontend-structure.md, "Ids are strings"). Compare them numerically: by length, then lexically, or through `BigInt`. Never compare them as plain strings of unequal length, and never through `Number`.
- **No in-place editor exists in `src/app` yet.** The closest precedents:
  - `CharacterScreen.tsx:~332` saves `onBlur` through `commitName(state, characters)` (`characterScreenState.ts:97`). It trims, skips when the value is unchanged or a request is in flight, and holds `nameSaving` / `error`.
  - The tree's search `TextInput` handles `onKeyDown` for Enter.

  Use a Mantine `TextInput`. Its `error` prop is the inline error line.
- **Effect shape** (frontend-structure.md's four rules): the in-flight guard, the pre-request status write, an abort check before every post-await write, `runInAction` around writes, and a `finally` that clears pending only when not aborted.
- `renameSession` comes from step 004. The workspace store type is `SessionsState`.
- The editor gets no `IconButton` of its own. The open affordance (`IconEdit`, "Rename session") belongs to the hosts in step 006.
