# Step 003 — `GET /api/search`: response models, router, registration

## Goal

Expose `run_my_search` as `GET /api/search?q=<text>` behind `require_user`: the response
models of the wire contract (five fixed groups, ids as strings), a sync route passing the
shared client factory and the configured timeout, and the router registered last in
`main.py` (`context.md` D1, U1, wire contract).

backend/app/models/search.py
backend/app/routers/search.py
backend/app/main.py

## Test files

backend/tests/test_search_router.py

## Interface intent

**`app/models/search.py`** (new)

- One response model per hit kind — character, setup, session, entry, memo — with exactly
  the wire contract's fields and names (`context.md`); every id field is `SnowflakeOut`
  (nullable where the contract says null).
- **`MySearchResponse`** — the five lists, declared in the order `characters`, `setups`,
  `sessions`, `entries`, `memos`.
- A conversion from the service's `MySearchResults` to the response (a classmethod or a
  module function; the skeleton freezes which).

**`app/routers/search.py`** (new)

- `router` — tags `["search"]`, `dependencies=[Depends(require_user)]`.
- **`my_search`** route — `GET /api/search`, **sync `def`** (the port embeds through an
  `asyncio.run` bridge and must not run on the event loop). Query parameter `q`, a string,
  optional, default empty. Takes the current user, the connection, the shared client
  factory (`get_llm_client_factory`) and the settings (`get_settings`). Calls
  `run_my_search(connection, user.id, q, client_factory=…, timeout_seconds=settings'
  LLM request timeout)` and returns `MySearchResponse`. Errors are not caught: the single
  `DomainError` handler renders them.

**`app/main.py`** (changed)

- Imports the search router and includes it **after whatever router is included last at
  build time** (memos today; 017 / 023 may have appended theirs). Every docstring passage
  that enumerates router order is updated to name it.

## Definition of done

1. `[test]` Without a session cookie, `GET /api/search?q=x` answers 401 with the standard
   envelope. (`context.md` wire contract)
2. `[test]` **Five groups, in order, strings.** With A's data matching in every kind, the
   200 body's top-level keys are exactly `characters`, `setups`, `sessions`, `entries`,
   `memos`, in that order; each group holds the seeded hit; every id field (`id`,
   `character_id`, `session_id`, `scope_id`) is a JSON **string** equal to the decimal of
   the seeded snowflake (> 2^60). (US-074.AC-1, US-075.AC-1, wire contract)
3. `[test]` **Field shapes.** A character hit has exactly `id`, `name`, `archived`; a setup
   hit exactly `id`, `name`, `character_id`, `character_name`, `archived`; a session hit
   exactly `id`, `character_name`, `setup_name`, `created_at`, `archived` (`setup_name`
   null for a no-setup session); an entry hit exactly `id`, `session_id`, `snippet`,
   `character_name`, `session_created_at`; a memo hit exactly `id`, `scope`, `scope_id`,
   `character_id`, `snippet`, `is_enabled`. No `title`, `body` or `is_forced` key anywhere.
   (wire contract, US-119)
4. `[test]` **Disabled memo on the wire.** A disabled matching memo is returned with
   `is_enabled` false beside an enabled one with `is_enabled` true. A user-level memo has
   `scope` `"user"` and `scope_id` null. (US-137.AC-1, US-137.AC-2, wire contract)
5. `[test]` **Owner isolation (absence).** Signed in as A, none of B's matching ids appears
   anywhere in the body; signed in as B, none of A's. (US-076.AC-1, UC-065)
6. `[test]` **Archived on the wire.** An archived matching character, setup and session
   each carry `archived: true`. (U3)
7. `[test]` **Blank query.** `GET /api/search`, `?q=` and `?q=%20%20` each answer 200 with
   the five keys present and every list empty, and the overridden fake factory records zero
   constructions. (D1)
8. `[test]` **Embedding failure fails the request.** No designated model (vector tables
   present) → 409 with envelope code `no_embedding_model` and no result keys; a vector
   table dimension mismatch → 409 `no_embedding_model` with detail `{"reason":
   "dimension_mismatch"}`; the fake scripted to raise → 502 `llm_unreachable`. (U1)
9. `[test]` The application's route table holds `GET /api/search` exactly once. (D1)
10. `[manual/live]` `main.py` includes the search router after every router that preceded
    it at build time, and its docstrings name it in the enumerated order. (Review item: an
    ordering assertion would break each time a later feature appends a router.)
