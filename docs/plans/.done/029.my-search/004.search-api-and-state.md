# Step 004 — `searchApi.ts` and `searchState.ts`: wire types, load, URL and target helpers

## Goal

Add the frontend half of the wire contract — typed results and one fetch — and the results
page's state: a data class, a load effect that skips blank queries and records failures,
and pure helpers for the results-page URL and each hit's landing target (`context.md` U4,
D1, D8, wire contract).

## Interface intent

**`app/searchApi.ts`** (new)

- One type per hit kind and **`MySearchResults`**, mirroring the wire contract field for
  field; every id is `string`; nullable fields are `string | null`; `archived` and
  `is_enabled` are `boolean`; memo `scope` is the four-literal union.
- **`fetchMySearch`** — takes the query text and an optional abort signal; GETs
  `/api/search` with the query as the `q` search parameter (URL-encoded); resolves to
  `MySearchResults`. Errors come from the shared client unchanged (`ApiError`; an abort
  rejects as the abort).

**`app/searchState.ts`** (new)

- **`SearchState`** — data class, observable fields only: `status` (`"idle"`, `"loading"`,
  `"ready"`, `"failed"`; starts `"idle"`), `query` (the query last loaded, starts `""`),
  `results` (`MySearchResults` or null), `failure` (the failure's message, or null).
- **`isBlankQuery`** — pure; true for empty or whitespace-only text.
- **`loadSearch`** — takes the state, the query text and an optional signal. Blank query →
  status `"idle"`, `results` null, `failure` null, **no request**. Otherwise status
  `"loading"`, then `"ready"` with the results, or `"failed"` with the `ApiError`'s message
  (any other rejection: a generic message). Writes nothing once the signal is aborted;
  never rejects.
- **`hasNoHits`** — pure; true when ready and all five groups are empty.
- **`searchHref`** — pure; the results-page path for a query: `/search` when blank,
  otherwise `/search?q=` + the URL-encoded text (untrimmed text is encoded as given).
- **Target helpers** — pure, one per hit kind (or one per kind behind a single function;
  the skeleton freezes which), returning the in-entry path a hit's row links to, exactly as
  `004.context.md` "Targets" lists.

## Definition of done

1. `[test]` `fetchMySearch("Mira & co")` requests pathname `/api/search` with search
   parameter `q` equal to `Mira & co` (decoded), method GET, and resolves to the stubbed
   body with every id still the exact string sent (ids above 2^53 unchanged).
   (wire contract, "Ids are strings")
2. `[test]` A stubbed 409 `no_embedding_model` envelope makes `fetchMySearch` reject with an
   `ApiError` whose code is `no_embedding_model`. (U1)
3. `[test]` `loadSearch` with `""` or `"   "` makes no request, leaves status `"idle"` and
   `results` null — also when the state previously held ready results. (D1, U4)
4. `[test]` `loadSearch` with a query: status `"loading"` while pending, then `"ready"`
   with the stubbed results and `query` set. A 502 `llm_unreachable` envelope instead gives
   `"failed"` with `failure` equal to the envelope's message and `results` null; the
   promise resolves. (U1)
5. `[test]` A load aborted before the response writes nothing after the abort (status stays
   `"loading"`, `results` unchanged) and does not reject. (`context.md` constraints)
6. `[test]` `hasNoHits` is true for a ready state with five empty groups and false when any
   group has a hit or the state is not ready. (`context.md` literals — `Nothing found.`)
7. `[test]` `searchHref("")` and `searchHref("  ")` are `/search`; `searchHref("a b&c")`
   is `/search?q=a%20b%26c` (or the `+`-for-space form — the test decodes the `q` parameter
   and compares it to `a b&c`). (U4, D8)
8. `[test]` **Targets per kind.** Character hit → `/characters/<id>`; setup hit →
   `/characters/<character_id>`; session hit → `/sessions/<id>`; entry hit →
   `/sessions/<session_id>?entry=<id>`; memo hits: user → `/settings`, character →
   `/characters/<character_id>`, setup → `/characters/<character_id>`, session →
   `/sessions/<scope_id>?notes=open`. Every id appears in the path exactly as the string
   given. (UC-060, U4, D8)
