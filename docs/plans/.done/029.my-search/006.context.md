## The tree header (built source)

- `CharacterTree.tsx` ~L297-322: header with `IconButton` "Search" (~L298-304, navigates
  to `SEARCH_PATH` = `"/search"`, declared ~L30), `IconButton` "New character", `Switch`
  "Show archived".
- The tree **remounts on expand** (~L121-123), so the input's local text does not survive a
  collapse/expand. That is why the query lives in the URL; the input is not synced from the
  URL.
- `shared/IconButton.tsx`: label = tooltip + aria-label (the rail's button keeps using it).

## The stream (built source)

- `SessionScreen.tsx` → `SessionStream.tsx` → `StreamRecord.tsx`.
- `StreamRecord.tsx` ~L155-185 renders `<ul aria-label="Settled record">`; `StreamEntry`
  ~L64-152 renders `<Box component="li" ref={itemRef}>` (~L99) with no id or data
  attribute today. `itemRef` is `useMergedRef(hoverRef, focusRef)` (~L71-73) — merge a
  third ref (or reuse one) for the scroll; do not replace the existing two.
- `streamApi.fetchEntries` loads the whole record (no pagination), so the focus entry is
  either in the loaded list or not in the session's record at all.
- The scroll container is `.app-main` (`overflow: auto`); `scrollIntoView` on the `<li>`
  scrolls it. No scroll-to, highlight or `useSearchParams` exists anywhere yet.
- 022 `007` (planned) adds a discussion group under each entry inside the same `<li>`;
  attributes on the `<li>` coexist with it.

## The wall (built source)

- `noteWallState.ts`: `openWall`, `isWallVisible`. The wall's `open` starts false on each
  `SessionScreen` mount (~L81-83). Opening on `notes=open` happens at that point (initial
  value or a mount effect); the pin preference is untouched.
