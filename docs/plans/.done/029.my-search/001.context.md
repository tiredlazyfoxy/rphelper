the file and reads only the columns above.

## Escaping

- Escape the needle's escape character first, then `%` and `_`, and declare the escape
  character on the `LIKE`. SQLAlchemy's `contains(..., autoescape=True)` does exactly this
  and is an acceptable mechanism; a hand-written equivalent is too. Either way the needle
  reaches SQL as a bound parameter, never interpolated.
- `PRAGMA case_sensitive_like` is left at SQLite's default (off), which is what makes
  `LIKE` ASCII-case-insensitive (D3). Do not change it.

## Shape of each query

- Characters: `SELECT id, name, archived_at FROM characters WHERE user_id = :u AND (name
  LIKE … OR sheet LIKE …) ORDER BY name, id LIMIT :n`. One row per character by
  construction (no join).
- Setups: `setups JOIN characters ON characters.id = setups.character_id AND
  characters.user_id = :u WHERE setups.user_id = :u AND (setups.name LIKE … OR
  setups.description LIKE …) ORDER BY setups.name, setups.id LIMIT :n`.
- A `NULL` `sheet` / `description` (if the column is nullable) simply does not match on
  that column.
