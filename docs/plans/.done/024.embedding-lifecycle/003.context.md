Feature-wide facts are in `context.md`: **D5** (archived included, N > 0), **D6** (the

## Built state at the touch sites (harvest)

- `db/schema.py`:
  - `settled_entries` is a **Core selectable** (~L384–401), not a SQL view. Select from it
    with a `session_id` and `user_id` predicate, ordered by `id` ascending (as
    `services/messages.py` `_list_session_rows` does).
  - `characters.sheet` is Text NOT NULL and may be `""`.
  - `setups.description` is Text NOT NULL.
  - `sessions` columns: `id, user_id, character_id, setup_id (nullable), last_used_at,
    archived_at, created_at, updated_at`. **No title / partner_label.**
- Services own a private read helper and `_now_text`. This module needs no timestamps. Its
  reads run on the caller's connection: inside the caller's transaction for a refresh, and
  with no transaction requirement for `compose_session_text` / the id listers.

## Implementation notes

- **Order inside a refresh:** ensure FTS, compose all, delete the rows of empty texts, then
  (only if anything is non-empty) open the model, ensure the vector tables at its
  dimension, embed once, and write.
  - Opening the model **before** ensuring the vector tables is what lets a missing model
    fail before any DDL.
  - Ensuring before writing is what makes a dimension mismatch fail before any vector
    write.
- Deleting the rows of empty texts uses `002`'s `delete_vector`, which tolerates an absent
  table.
- **Degraded catch:** catch exactly `NoEmbeddingModelError` and `LlmUnreachableError`
  around the strict call.
  - Nothing has been written to `session_vec` before the raise points. The only possible
    prior effect is the FTS ensure plus deletes for empty texts. For a single session,
    "empty" and "unavailable" are exclusive, because unavailable needs non-empty text.
  - **No savepoint is needed.** A Python-level catch leaves the SQLite transaction intact,
    because no SQL statement failed.
- A `secret_ref_missing` raised while opening the model is **not** caught. That follows
  U3's list. `outcome.md` flags it as an open item.
- `compose_session_text` for a foreign session returns `""`. It reads the session row with
  `user_id = :user` and finds nothing, so the persona, setup and entries are not read
  either.

## Test shape

`test_session_index.py` raw-inserts users, characters, setups, sessions (one with
`archived_at` set) and messages in all three states, with ids above 2^60. It uses
`llm_fakes.py` and a designated model at dim 8. Pre-existing vectors are written with
`002`'s `write_vector` after `001`'s `ensure_vector_tables`.
