# Step 003 — `services/session_index.py`: session text, strict and degraded refresh, fan-out ids

## Goal

Add the session-side index service:

- it composes a session's text exactly per D6;
- it refreshes one or more sessions' `session_vec` rows in one embed call, in a **strict**
  form that propagates "unavailable" and a **degraded** form that catches it and reports
  incomplete coverage;
- it lists the sessions a persona or setup feeds (archived included).

It also ensures the FTS half on every refresh.

## Interface intent

**`app/services/session_index.py`** (new)

- **`compose_session_text`**: takes a connection, the caller's user id and a session id.
  It returns the session text (D6), reading through `settled_entries` with every read
  scoped to the user. A session that is not the caller's yields the empty string. It
  writes nothing.
- **`refresh_session_vectors`** (strict): takes a connection already inside a transaction,
  the user id, a collection of session ids, and keyword-only the client factory and the
  timeout (D9 defaults). It returns nothing. It:
  1. calls `001`'s `ensure_fts_tables`;
  2. composes each session's text;
  3. deletes the `session_vec` row of every session whose text is empty (D6);
  4. only when at least one text is non-empty, opens the designated model (`002`) and calls
     `001`'s `ensure_vector_tables` with its dimension;
  5. embeds **all** non-empty texts in **one** `embed_texts` call, and writes each
     session's vector.

  `NoEmbeddingModelError` (including mismatch) and `LlmUnreachableError` propagate. An
  empty id collection does nothing beyond the FTS ensure and needs no model (N = 0).
- **`refresh_session_vector_degraded`**: takes the same inputs, but for **one** session id.
  It returns a boolean, **true when coverage is incomplete**. It runs the strict refresh
  for that one session:
  - if the refresh raises `NoEmbeddingModelError` or `LlmUnreachableError`, it catches the
    error, writes no vector and leaves any existing row as it was, then returns true;
  - otherwise it returns false.

  Every other exception propagates. The caller's transaction stays usable after a caught
  failure.
- **`session_ids_for_character`**: takes a connection, user id and character id. It
  returns the ids of every session of that character owned by the user, archived ones
  included (U4).
- **`session_ids_for_setup`**: takes a connection, user id and setup id. It returns the ids
  of every session of the user whose `setup_id` is that setup, archived ones included.
- The module imports no `fastapi`, and among the services it imports only
  `services/embedding.py`.

## Definition of done

1. `[test]` **Composition (D6).** The session belongs to a character with sheet "Persona
   P." and to a setup with description "Setup S.". It has, in ascending id:
   - a settled partner "Alpha";
   - a buried zone message "Buried";
   - a settled turn "Beta";
   - a settled decision "((Gamma))";
   - a zone message "Draft".

   `compose_session_text` returns exactly `"Persona P.\n\nSetup S.\n\nAlpha\n\nBeta\n\n((Gamma))"`.
   (US-138.AC-1, US-122.AC-2, US-115, UC-038, R11)
2. `[test]` A session with `setup_id` null composes without a setup part, for example
   `"Persona P.\n\nAlpha"`. A character with an empty sheet and no setup composes from
   entries alone. A whitespace-only settled entry contributes no part. (D6)
3. `[test]` `compose_session_text` for another user's session id returns `""`, and a
   strict refresh of it writes no row for that id. (R5)
4. `[test]` **Strict, success.** With a designated model (dim 8) and three sessions with
   non-empty texts, `refresh_session_vectors` leaves one `session_vec` row per session,
   each equal to the fake's vector for that session's composed text. The fake recorded
   **exactly one** `embed` call whose texts are the three composed texts, and the factory
   was called once. (D1, US-138.AC-1)
5. `[test]` **Strict, unavailable.** Inside a transaction, each of these is raised by
   `refresh_session_vectors`:
   - no designated model → `NoEmbeddingModelError`;
   - a fake raising `LlmUnreachableError` → that error;
   - an existing `session_vec` at dim 16 while the designation says 8 →
     `NoEmbeddingModelError` with `detail` `{"reason": "dimension_mismatch"}`.

   A pre-existing `session_vec` row for the session is unchanged afterwards. (D8)
6. `[test]` **Degraded.** A pre-existing `session_vec` row holds vector V for the session.
   In each of DoD-5's three conditions, `refresh_session_vector_degraded` raises nothing
   and returns true. A relational write made earlier in the same transaction commits, and
   the row still holds V (stale, U5). (US-112.AC-1, D8)
7. `[test]` Degraded success returns false and leaves the row equal to the fake's vector
   for the current composed text. (D5)
8. `[test]` **Empty text.** A session whose character sheet is empty, with no setup and no
   settled entries, has a pre-existing row. A degraded refresh with **no** model
   designated returns false, and the row is gone. A strict refresh of it with no model
   raises nothing. In both cases the factory was called zero times. (D6)
9. `[test]` **N = 0.** `refresh_session_vectors` with an empty id collection and no model
   designated raises nothing and calls the factory zero times. (U4)
10. `[test]` **Fan-out ids (U4).** User A's character C has these sessions:
    - S1, active, setup X;
    - S2, archived, setup X;
    - S3, active, no setup;
    - S4, setup Y.

    User B has their own sessions.

    - `session_ids_for_character(A, C)` returns exactly {S1, S2, S3, S4};
    - `session_ids_for_setup(A, X)` returns exactly {S1, S2};
    - both return an empty set when called with user B's id for A's character or setup.

    (R5)
11. `[test]` On a database where the FTS tables were never created, a degraded refresh with
    no model leaves `message_fts` present and back-filled: a settled entry's token is found
    by `MATCH`. (D2)
12. `[test]` The source of `services/session_index.py` imports no `fastapi`.
