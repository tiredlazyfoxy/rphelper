## The four visible columns, and why not seven

`admin-surfaces.md` asks for "one row per table, a coloured status badge, and a summary of
missing and extra columns". Five separate difference lists as five separate columns makes
a table that is mostly empty cells and that collapses on any narrow viewport, so the five
collapse into **two summary cells** — Columns and Indexes — produced by one pure helper.
The helper is where the wording lives so that a test can assert the rendered text without
reaching into the component, and so the same wording cannot drift between the table and
step `006`'s confirm.

## What the trailing action column holds in this step

**Nothing.** The `w={60}` column exists so step `006` does not have to restructure the
table, and it renders empty here. Do **not** put a disabled `IconDots` in it as a
placeholder — an in-sync row will have no actions at all even after step `006`
(`006.context.md`), so a permanently disabled trigger would be wrong on the majority of
rows.

## What must not appear on this page

- **no Import control** — `031`'s;

## Gotchas

- **The status union is the backend's closed three-value set, spelled out as a union type,
  not `string`.** Widening it is how step `006`'s "offer Create only when missing" rule
  loses its exhaustiveness check.
- **Colour is not the status.** DoD-2 requires the badge's **text** to carry the word; a
  colour-only column fails `ui-conventions.md`'s accessibility floor and is unreadable in
  a screenshot pasted into an issue.
- **`notifyFailure` is not imported here.** `frontend/tests/conventions.test.ts` asserts
  the notification-import list equals exactly `["src/shared/notifyFailure.ts"]` and will
  fail if this page imports Mantine's notification API. That test file is **not** in any
  step's Source or Test files and is not edited.
- **Vitest runs with `globals: false`** — `describe` / `it` / `expect` are explicit imports
  from `"vitest"`, and each `it` title ends **`— DoD-N`**.
- **`fetch` is stubbed per test with no mocking library.**
- **No success toast, ever** — but there is no mutation in this step at all, so the only
  thing to get wrong here is importing the channel.
