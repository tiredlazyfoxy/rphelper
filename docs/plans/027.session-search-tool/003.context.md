## The one worker-thread call

Both the search and the excerpt read run inside the **same** `asyncio.to_thread` call, as
one small sync callable that calls `search_sessions` and then the excerpt read. This avoids
handing the connection back and forth between the loop thread and a worker. The callable
may be a private function of the adapter module; skeleton decides.
