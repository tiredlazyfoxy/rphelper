## Touch sites, as harvested

- `app/streamApi.ts`:
  - The `Message` type has `id: string`, `session_id`, `role: "user"|"assistant"|"tool"`,
    `kind`, `text`, `settled_at`, `created_at` and `updated_at`.
  - There is a private `sessionPath(sessionId, suffix)` that `encodeURIComponent`s the id.
  - It holds seven calls, each taking `signal?` last.
  - The compose call's signal is **required**, not optional: the caller always holds a
    compose controller.
- `app/streamState.ts`:
  - `class StreamState { sessionId; entries; zone; status; draft; kindOverride; busy }`
    with `makeAutoObservable(this, {}, { autoBind: true })`. The new non-observable field
    goes in the overrides argument as `false`.
  - Its derivations are `isBlank`, `defaultKind`, `effectiveKind`, `canSend`
    (`!isBlank(draft) && !busy`), `canSettle`, `showsDiscard`, `showsReopen`,
    `settleTargetText` and `settlePreviewOf`.
- `app/Composer.tsx`:
  - It is an `observer`; its props are `{ state, signal? }`.
  - The `Group justify="flex-end"` holds, in order: the Discard `IconButton` (`IconX`)
    when `showsDiscard`; the `Button variant="default"` "Send"; the
    `Button variant="filled"` "Settle".
  - 019 makes the middle element conditional, and nothing else.
- `src/shared/IconButton.tsx`: props `icon, label, onClick, disabled?, color?,
  sizeVariant?`. `label` is both the tooltip and the `aria-label`.
