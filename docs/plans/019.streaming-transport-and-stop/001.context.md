## Wire field order per event (the encoder's contract)

```
accepted     event, message_id
token        event, text
tool_start   event, tool, call_id, args
tool_result  event, tool, call_id, summary
tool_fail    event, tool, call_id, code
error        event, code, message, detail
done         event, message_id
```

Compact separators `(",", ":")`, `ensure_ascii=False`. `json.dumps` escapes a newline
inside a string as `\n`, so a frame never contains a raw blank line. That is what makes
splitting on `"\n\n"` safe.

## Touch sites, as harvested

- `app/services/messages.py`:
  - `StreamMessage` is a frozen dataclass with fields `id, session_id, role, kind, text,
    settled_at, created_at, updated_at`.
  - `append_message(connection, generator: SnowflakeGenerator, user_id: int, session_id:
    int, text: str) -> StreamMessage` hard-codes `role="user"`.
  - In `with connection.begin():` it runs `_require_session` (raises
    `SessionNotFoundError`), `generator.next_id()`, `_now_text()`, the insert, and
    `_bump_session`.
- The `messages` table (`app/db/schema.py:292`):
  - Columns: `id, user_id, session_id, role, kind, text, related_to, settled_at,
    tool_name, tool_payload, created_at, updated_at`.
  - There is **no CHECK on role**.
  - `current_zone` is `related_to IS NULL AND settled_at IS NULL`.
- `app/errors.py`:
  - `DomainError(Exception)` has class attributes `code` and `http_status`, and instance
    attributes `message` and `detail`.
  - `__init__(message=None, detail=None)`.
  - `to_wire()` returns `{"error": {code, message, detail}}`. The frame uses the **inner**
    fields.
  - `LlmUnreachableError` has code `llm_unreachable`.
- `app/models/ids.py`: `SnowflakeOut = Annotated[int, PlainSerializer(str, …)]`. Frames go
  through no pydantic model, so the encoder uses `str(id)` itself.
