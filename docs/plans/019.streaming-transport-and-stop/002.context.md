## Touch sites, as harvested

- `app/db/engine.py`:
  - `get_engine(settings)` returns a cached `Engine` per database path, with
    `isolation_level=None`.
  - `get_connection(settings)` is a yield dependency with no transaction. The harness

  - The persister uses `engine.connect()` as a context manager.
    `append_assistant_message` opens its own `connection.begin()`.
- The id generator is `SnowflakeGenerator`. In the app it is `request.app.state.id_generator`
  through `get_id_generator` (`app/routers/bootstrap.py:50`). Tests construct one
  directly.
- Logging is `loguru.logger`. Log the session id and `type(exc).__name__` only.
- No `StreamingResponse` exists anywhere in `app/` yet. Import it from
  `fastapi.responses` (or `starlette.responses`).

## Why three disconnect paths

Starlette has changed how a `StreamingResponse` learns of a client disconnect:

- older versions listen for `http.disconnect` in a task group and **cancel** the body
  task;
- newer ASGI spec versions surface it as an `OSError` on send, which **closes** the body
  iterator;
- some servers deliver neither until the next write.

Rather than depend on which one the installed version does, the harness treats "no
terminal frame emitted when the `finally` runs" as the disconnect condition (D6). It also
polls `is_disconnected()` before each write, so a source that is producing tokens
notices the drop at the next frame even when neither of the other paths fires.

## Cleanup details the coder must hold

- The persist is a **plain synchronous call**. Do not `await` anything before it in the
  `finally`, because an await during cancellation can be cancelled again.
- `aclose()` the source only if it has one, since an async iterator need not. Await it
  under `asyncio.shield` and suppress any exception it raises. Always re-raise the
  original `CancelledError`/`GeneratorExit`.
- On the D5 paths, catch `Exception`, never `BaseException`. `CancelledError` is a
  `BaseException` and must reach the `finally` as a disconnect.
- Persist **at most once** per stream: guard it with a flag. The error paths persist
  before yielding the error frame, and the `finally` must not persist a second time.

## Test harness notes

- **No pytest-asyncio.** DoD 7–10 drive the async generator with
  `asyncio.run(main())`, where `main` iterates with `__anext__` and/or `aclose()` and
  creates and cancels a task for DoD-9.
- **Fake request.** A small object with an `async def is_disconnected()` whose answer a
  counter or flag controls.
- **Fake source.** A file-local async generator that records entry to its own `finally`.
  That record is the observable proof of "source closed / upstream cancelled".
- **DoD-1 and DoD-12 use real infrastructure.**
  - DoD-1 mounts a throwaway `FastAPI()` app inside the test module, with one POST route
    returning `sse_response(request, source(), recorder)`. No auth and no
    `create_app()` are needed. The route handler must be `async def` or accept
    `Request`; that is the test's choice.
  - DoD-11 and DoD-12 seed a user and a session through the existing services and
    fixtures (`db_engine`, the `conftest` helpers), then read the zone through the
    `current_zone` view.
