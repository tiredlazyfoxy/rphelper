## Rules in one place (012 D8, for quick reference — 012 is authoritative)

- **Line breaks** are `\n`; `\r` is ordinary text. **Trim** is JavaScript's (D16).
- **Decision** iff trimmed text starts with `((` and ends with `))`.
- **Fragment**: scanning left to right, from a `((` to the first `))` that begins at or
  after the end of that `((` (so `(())` is one fragment with nothing inside); scanning
  resumes after the `))`. Equivalent to `/\(\(([\s\S]*?)\)\)/g`. A `((` with no later
  `))` is prose.
- **Strip**: (1) no fragment → return unchanged; (2) remove each fragment and the run of
  spaces / tabs immediately before it (not line breaks); (3) replace each run of line
  breaks holding three or more `\n` with only spaces / tabs between them by exactly
  `\n\n`; (4) trim.

## Classification examples (DoD-6)

Decisions: `"((x))"`, `"  ((x))  \n"`, `"((first line\nsecond line))"`,
`"((one)) ((two))"`, `"((a)) prose ((b))"`, `"(((x)))"`, `"(())"`.

Turns: `"((hint)) She walks."`, `"She walks. ((x))"`, `"(( never closed"`,
`"a single (paren) pair"`, `""`.

## Segment examples (DoD-7)

`P` = prose, `F` = fragment.

| Input | Segments |
|---|---|
| `"a ((b)) c"` | `P "a "`, `F "((b))"`, `P " c"` |
| `"((b))"` | `F "((b))"` |
| `"plain"` | `P "plain"` |
| `""` | (none) |
| `"x ((a\nb)) y ((c))"` | `P "x "`, `F "((a\nb))"`, `P " y "`, `F "((c))"` |
| `"(( open"` | `P "(( open"` |
| `"((a))((b))"` | `F "((a))"`, `F "((b))"` |
| `"x ((a)) y))"` | `P "x "`, `F "((a))"`, `P " y))"` |

## Strip examples (DoD-8)

| Input | Output |
|---|---|
| `"She walks. ((make it tense)) He waits."` | `"She walks. He waits."` |
| `"((hint)) She walks."` | `"She walks."` |
| `"She walks.\t((x))"` | `"She walks."` |
| `"a  ((x))  b"` | `"a  b"` (only the run **before** the fragment goes) |
| `"Line one.\n\n((note))\n\nLine two."` | `"Line one.\n\nLine two."` |
| `"Para.\n  \n((n))\n\t\nNext."` | `"Para.\n\nNext."` |
| `"A\n((x))\nB"` | `"A\n\nB"` (two `\n` only — not collapsed) |
| `"a ((x\ny)) b"` | `"a b"` |
| `"a ((x)) b ((y)) c"` | `"a b c"` |
| `"((a)) (("` | `"(("` |
| `"x ((a))"` | `"x"` |
| `"x ((a)) y))"` | `"x y))"` |
| `"  She walks.  \n"` | `"  She walks.  \n"` — unchanged, no fragment |
| `"A\n\n\n\nB"` | `"A\n\n\n\nB"` — unchanged, no fragment (step 3 never runs) |
| `"a ((b"` | `"a ((b"` — unchanged |

Not pinned (012's recorded oddity): nested / tripled parentheses inside a turn, e.g.
`"x (((y))) z"`.
