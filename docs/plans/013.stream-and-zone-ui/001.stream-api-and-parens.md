## Interface intent

**`app/streamApi.ts`** (new)

- **`MessageRole`**: the three role strings. **`MessageKind`**: the three kind strings.
- **`Message`**: type mirroring the wire object field for field — `id`, `session_id`
  (strings); `role`; `kind` (a kind or null); `text`; `settled_at` (string or null);
  `created_at`, `updated_at` (strings). No renaming layer, no extra fields.
- **`SettleResult`**: `entry_id` (string), `kind` (a kind), `buried_ids` (array of
  strings). **`ReopenResult`**: `reopened_id` (string), `restored_ids` (array of strings).
- **`fetchEntries`**: takes a session id and an optional signal; GETs the session's
  entries; resolves to the unwrapped `entries` array in the order received.
- **`fetchZone`**: same for the zone; resolves to the unwrapped `messages` array.
- **`filePartnerEntry`**: takes a session id, the text and an optional signal; POSTs the
  entries collection with the body `{ kind: "partner", text }`; resolves to the filed
  `Message`.
- **`appendZoneMessage`**: takes a session id, the text and an optional signal; POSTs the
  zone's messages collection with `{ text }`; resolves to the appended `Message`.
- **`settleZone`**: takes a session id and an optional signal; POSTs settle with no body;
  resolves to a `SettleResult`.
- **`reopenLastEntry`**: takes a session id and an optional signal; POSTs re-open with no
  body; resolves to a `ReopenResult`.
- **`editMessage`**: takes a message id, the text and an optional signal; PATCHes the
  message with `{ text }`; resolves to the edited `Message`.
- All failures are the shared client's `ApiError`s, rethrown unchanged. Text is sent
  verbatim (never trimmed). Ids are never coerced.

**`app/parens.ts`** (new) — pure functions only; no DOM, React, MobX or network.

- **`ParenSegment`**: a segment of text tagged either prose or fragment, carrying its text
  verbatim (a fragment's text includes its `((` and `))`).
- **`isWhollyParenthesised`**: takes a text; returns whether its trimmed form starts with
  `((` and ends with `))` — the decision rule.
- **`splitParenSegments`**: takes a text; returns its segments in order by the fragment
  scan (shortest span, left to right, may cross line breaks; a `((` with no later `))` is
  prose). Never yields an empty prose segment; an empty text yields no segments; the
  segments' texts concatenate to the input exactly. This is the **one** fragment scanner
  the strip and the painter share.
- **`stripFragments`**: takes a text; applies 012's four-step strip (unchanged when there
  is no fragment; else remove each fragment with the spaces / tabs immediately before it,
  collapse line-break runs of three or more to one blank line, trim). Does not consult
  the decision rule.
- **`SettlePreview`**: the kind a settle would file (`"turn"` or `"decision"`) and whether
  fragments would be stripped.
- **`previewSettle`**: takes a text; returns its `SettlePreview` — a decision never
  strips; a turn strips iff it holds at least one fragment.

## Definition of done

1. `[test]` `fetchEntries("7250000000000000001")` requests exactly
   `GET /api/sessions/7250000000000000001/entries` and resolves to the payload's `entries`
   array in order, every `id` / `session_id` the identical string the payload carried and
   `kind` / `settled_at` as carried (including null). `fetchZone` requests exactly
   `GET /api/sessions/<id>/zone` and resolves to the payload's `messages` array likewise.
   (D14)
2. `[test]` `filePartnerEntry(sid, "  Hi ((there))  ")` POSTs
   `/api/sessions/<sid>/entries` with the JSON body exactly
   `{"kind":"partner","text":"  Hi ((there))  "}` (text verbatim);
   `appendZoneMessage(sid, " x ")` POSTs `/api/sessions/<sid>/zone/messages` with exactly
   `{"text":" x "}`; each resolves to the response's `Message`. (US-030.AC-1,
   US-121.AC-2, D14)
3. `[test]` `settleZone(sid)` POSTs `/api/sessions/<sid>/settle` and resolves to
   `{entry_id, kind, buried_ids}` as received (ids strings, order kept);
   `reopenLastEntry(sid)` POSTs `/api/sessions/<sid>/reopen` and resolves to
   `{reopened_id, restored_ids}` as received. Neither sends a JSON body. (012 D11)
4. `[test]` `editMessage("7250000000000000105", "new")` PATCHes
   `/api/messages/7250000000000000105` with exactly `{"text":"new"}` and resolves to the
   response's `Message`. (US-115.AC-1)
5. `[test]` A 409 envelope with code `zone_empty` makes `settleZone` reject with an
   `ApiError` whose `code` is `zone_empty`; a 409 `nothing_to_reopen` does the same for
   `reopenLastEntry`; a 409 `message_not_editable` for `editMessage`. (D15)
6. `[test]` `isWhollyParenthesised` is true for every decision example and false for every
   turn example in `001.context.md` "Classification examples". (US-129.AC-1, D1)
7. `[test]` `splitParenSegments` returns exactly the segment lists in `001.context.md`
   "Segment examples", and for each of those inputs the segments' texts concatenated equal
   the input. (D1, D5)
8. `[test]` `stripFragments` returns exactly the outputs in `001.context.md` "Strip
   examples", including the byte-for-byte unchanged cases. (US-130.AC-1, D1)
9. `[test]` `previewSettle` returns exactly the kind / strips pairs in `001.context.md`
   "Preview examples". (US-129.AC-1, US-130.AC-1, D1)
10. `[test]` `parens.ts` imports nothing (no `react`, `mobx`, `@mantine/*`, no `shared/`
    module) — checked by reading the module's source text from disk. (D1)
