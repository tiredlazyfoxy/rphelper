## Draft binding

The "Name" input writes the draft name and the editor's `onChange` writes the draft sheet.
Both writes go through a MobX action. Since the class has no methods, the component
assigns inside `runInAction`, or the coder adds two tiny setter free functions to
`characterScreenState.ts`. **That module is not in this step's Source files**, so here the
writes are `runInAction(() => { state.name = … })` in the component.

## Layout

The screen lives in the shell's centre column (`main`). Use a Mantine `Container` (or
`Stack` with a max width) for the body. `workspace-shell.md`'s 720px measure belongs to
the stream and composer and does not bind here. No `shell.css` change. The two-column look
of "The character page" is simply the shell with no wall, which 008 already is.
