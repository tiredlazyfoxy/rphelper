## Focus-leave for the persona editor

`MarkdownEditor` exposes no blur hook. 015's group wraps it in an element whose `onBlur`
checks whether the newly focused element (`relatedTarget`) is still inside the wrapper,
and saves only when focus has really left. Clicking the TipTap toolbar moves focus within
the wrapper and must not save (015 `007` DoD-17's manual item). The Name `TextInput` uses a
plain `onBlur`.

## Flush on unmount

The flush runs in the effect cleanup. Blur is unreliable when an element leaves the DOM
(015 D5). After a successful create, the draft screen unmounts because of the replace
navigation. The state is no longer a draft by then, so the flush sends nothing. A create
in flight at unmount is guarded by `submitCreate`'s in-flight check.
