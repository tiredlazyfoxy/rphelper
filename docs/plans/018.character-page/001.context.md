## Notes for the skeleton

- The helper's name is the skeleton's to freeze. It is **public**, because `002` imports it
  from `services/sessions.py` (D3's import exception). Keep it free of `fastapi`.
- Whether the helper also takes the role is not needed. Every caller inserts a user row.
  Do not add parameters for kind or `settled_at`: an insert that could write a settled row
  would be a second door into the record (R11).
- `StartedSessionResponse` may subclass `SessionResponse` or restate its fields. Either
  way its eight session keys must serialise identically. The router converts with
  `model_validate(..., from_attributes=True)`, so the response must be buildable from
  `002`'s started-session value (the session's attributes plus the message value).
- A `models/` module importing `models/stream.py` is allowed: models import neither
  routers nor services.
