## Shaping the eight keys

Both `startSession` and the send effect hand the store a `Session` built from the
response's eight session keys. A spread that keeps `opening_message` would put a ninth key
into `SessionsState`, which 011's tests and the tree never expect. Name the eight fields
explicitly, or use an equivalent that drops the extra key. Doing it in one place, the API
module, keeps the state module simple.

## Unmount guard

The send is a mutation: it is not aborted when the page unmounts, so the session is still
created and still applied to the tree. Only the navigation is skipped once the component is
gone. A mounted-ref check in `CharacterComposer` is sufficient. The state module stays
React-free and takes the navigation as a callback (009 `006`'s `onCreated` precedent).
