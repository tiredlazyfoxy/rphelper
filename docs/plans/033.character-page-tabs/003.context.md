## Why an inline form here

This is a **new exception to "create is always a `Modal`"** (forms-and-lists.md),
chosen by the user (D7). The draft-lifetime half of the modal convention still
applies: conditional mount, fresh draft per open, open flag in component-local
`useState`, failure rendered inside the form, list updated before the form
disappears. `outcome.md` routes the exception to the architect.
