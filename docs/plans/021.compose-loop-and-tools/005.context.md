# Step 005 — step-specific context

Feature-wide facts (D2–D7, D11, D15, the literals) are in `context.md`.

## Interfaces this step composes

- **017 `003`**: `resolve_model_for_use(conn, user_id, session_id)` → `EnabledChatModel`
  (`.server`, `.model_name`), raising in D2's order `NoModelEnabledError`,
  `ModelNotChosenError`, `ModelNotEnabledError` (and `SessionNotFoundError`).
  `get_session_configuration(conn, user_id, session_id)` → `SessionConfiguration`.
- **020 `002`**: `assemble_context(conn, user_id, session_id)` → `AssembledContext` with
  `system_prompt` (string) and `messages` (sequence of `ChatMessage`, tool rows replayed by
  `002`).
- **003**: `open_chat_client(conn, enabled_model, timeout, factory)`; the client's
  `chat_stream(model, messages, tools)` yields `ChatDelta`s (`content`, `reasoning`,
  `tool_calls` of `ToolCallDelta(index, call_id, name, arguments)`).
- **004**: `offered_tools(configuration, registry)`, `build_tool_scope(conn, user_id,
  session_id)`, `tool_start_frame(call)`, `dispatch(call, scope, offered names, registry,
  engine, generator)` → result with `.frame` and `.message`.
- **019 `001`**: frame values accepted / token / done; `append_assistant_message(conn,
  generator, user_id, session_id, text)`.

## Shapes local to this step

- **Accumulating a call:** keep per index the first non-none `call_id`, the first non-none
  `name` (empty string if none ever arrives — dispatch then fails it as unknown), and the
  concatenation of non-none `arguments` fragments in arrival order (empty → `""`, which
  dispatch fails as not-an-object).
- **Round text vs exchange text:** the in-loop assistant message carries the round's
  **content** only; the persisted row carries **every token text** of the exchange (content
  and the `<think>` wrapping, all rounds). They differ on purpose (D11).
- **`<think>` state is per round:** if a round's stream ends while a think run is open, emit
  `</think>` before handling that round's calls or finishing.
- **Closing guarantee:** wrap each `chat_stream(...)` iterator in `contextlib.aclosing` (or an
  equivalent `try/finally: await it.aclose()`), so an `aclose()` of the source — the harness's
  stop path — closes the provider stream immediately rather than at garbage collection.

## Test seam

A file-local fake chat client: constructed with a script (a list of rounds, each a list of
`ChatDelta`s, optionally ending in an exception), records per call the model, a copy of the
messages and the tools, and whether its iterator was closed. A file-local factory returns it
and records its arguments. Fake tools as in `004`. Drive the source with `asyncio.run` of a
coroutine that collects frames (catching the expected exception where a DoD says "raises").
Registry rows (`llm_servers` with `api_key_ref` NULL, `models` enabled) and the session's
`model_server_id` / `model_name` (017 `001` columns) are raw-inserted.

## Gotchas local to this step

- The setup connection is closed **before** the first `chat_stream` call; the final write
  opens a fresh short-lived connection.
- Do not wrap the loop in `try/except Exception` to "clean up": the harness owns failure
  handling and the partial write (019 D4); a broad except here would swallow the very errors
  the client must see.
