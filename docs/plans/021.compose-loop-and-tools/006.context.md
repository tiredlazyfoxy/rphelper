# Step 006 — step-specific context

Feature-wide facts (D1, D2, D8, D14, the termination posture) are in `context.md`.

## Built state at the touch sites (harvest)

- **`app/routers/stream.py`**: every route is a sync `def`; dependencies are `require_user`
  (→ `CurrentUser` with `.id`), `get_connection` (db/engine.py:166) and `get_id_generator`
  (routers/bootstrap.py:50, reads `app.state`). Its docstring says no compose route exists
  (019 left it so). The existing `POST …/zone/messages` handler and its request model in
  `app/models/stream.py` are the pattern for the blank-text refusal (422).
- **`get_engine(settings)`** (db/engine.py:108) is a process-level cache, **not** a FastAPI
  dependency: call it with the settings obtained through `Depends(get_settings)`
  (config.py:37), so tests that override `get_settings` get their own engine.
- **019 `002`**: `sse_response(request, source, on_partial)` returns the
  `StreamingResponse(media_type="text/event-stream")` with `X-Accel-Buffering: no`;
  `own_connection_persister(engine, generator, user_id, session_id)` returns the synchronous
  `on_partial`. `request` is used only for `is_disconnected()`; take it as a Starlette
  `Request` parameter.
- `ZoneEmptyError` (409) and `SessionNotFoundError` (404) exist in `app/errors.py`.
- No `main.py` change: the stream router is already registered.

## Test seam

- `create_app()` with `dependency_overrides` for `get_settings` (file-local DB), the
  chat-client factory dependency (a file-local factory returning a scripted fake client that
  records its calls, as in `005`) and, where a DoD needs tools, the registry dependency.
  DoD-10 deliberately leaves the registry dependency **un**-overridden.
- `TestClient` collects the whole SSE body; split on `"\n\n"`, strip `data: `, `json.loads`.
- DoD-2's probe: the fake's `chat_stream`, on first entry, opens a connection from the test's
  engine and records whether the zone holds the user row.

## Gotchas local to this step

- `begin_compose` runs on the handler connection and must leave it with no open transaction;
  the source never sees that connection.
- The accepted id is the `int` row id; 019's encoder turns it into a string on the wire — do
  not stringify it here.
