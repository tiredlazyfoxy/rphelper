## UI strings — the contract tests bind to

| Where | String | Role / element |
|---|---|---|
| Partner flicker, original showing | **"Show translation"** | `IconButton` (`IconLanguage`) label = tooltip = `aria-label` |
| Partner flicker, request pending | **"Cancel translation"** | same control |
| Partner flicker, translation showing | **"Show original"** | same control |

014's **"Edit entry"** / **"Edit entry text"** and 013's strings are unchanged. Failure
text comes from the server via `notifyFailure` and is never asserted.

Mantine semantic colour through `IconButton`'s `color` prop. It differs between "Show
original" and the other two states, and tests do not assert it.

## Built state at the touch sites (harvest)

- **`StreamRecord.tsx` `StreamEntry`**: it renders the kind label, the body (partner as a
  Mantine `Blockquote` through the shared body renderer), and an actions group revealed by
  014 D6's hooks with `data-revealed` and opacity. The group holds "Edit entry" (absent
  while the editor is open), "Copy as plain text" on turns only, and 013's re-open on the
  last entry. `commit()` hands the draft to `editEntry(state, id, text)` from
  `streamState.ts`. Blank or unchanged drafts make no request. Add the flicker inside the
  **same** actions group so it is revealed with the others. Do not add a second group.
- The invalidate call goes after `commit()`'s `await` of `editEntry`, guarded by
  `entry.kind === "partner"` and the state being present. Calling it when no request was
  made (unchanged draft) is harmless.
- **`SessionStream.tsx`** creates its `StreamState` per mount (`useState(() => new
  StreamState())` or equivalent) and renders `StreamRecord` with it. Add the translation
  state the same way, and a `useEffect` cleanup calling `disposeTranslations`.
- **`shared/IconButton.tsx`** props: `icon`, `label`, `onClick`, `disabled?`, `color?`,
  `sizeVariant?`. It is **not** changed.
- **022 `007`** (if landed) adds `DiscussionGroup` under **non-partner** entries in
  `StreamEntry`. Keep both changes: the branches are disjoint.
