# Step 001 — step-specific context

Feature-wide facts are in `context.md`: **D5** (the error), **D7** (columns), **D11** (the
delete), the **Wire contract** and the backend **Test conventions**. Only what is narrow to
this step is below.

## Built state at the touch sites (harvest)

- **`db/schema.py`**: id columns use `BigInteger().with_variant(Integer(), "sqlite")`.
  Timestamps are Text, fixed-width. Owner columns are `user_id` FKs to `users.id`. Copy the
  form of an existing owned table, such as `messages` or `sessions`. The drift page reads
  `metadata`, so there is nothing to register.
- **`errors.py`**: `DomainError` subclasses set class-level `code` / `http_status` and pass
  a default message from `__init__`. `register_exception_handlers` covers every subclass,
  so no handler change is needed.
- **`models/ids.py`**: `SnowflakeOut` serialises an int id as a decimal string.
- **`services/messages.py` `edit_message_text`**: classifies the row through
  `message_states` and refuses buried / missing rows before any write. For an accepted row
  it runs `messages.update(...)` inside `with connection.begin():` (014 D1), then reads the
  row back through the matching view. **The delete goes right after the update, inside that
  same `with` block.** The module docstring currently says the module does no delete. Amend
  that sentence only.

## Table-set pins in existing tests

- `tests/test_db_schema.py` holds table-set constants near ~L2131, with a comment that
  features after 015 append their tables there (`LATER_THAN_015_TABLES` or a later
  constant if 016–022 added one). Add `translations` to **whichever constant is the latest
  at build time**.
- `tests/test_llm_registry_models.py` and `tests/test_llm_registry_servers.py` may pin the
  full table-name set. If they do, add `translations`. If they do not, leave them
  unmodified.
- If the red-gate run shows **another** test file pinning the table set, that is a
  hand-back (`SPEC`). The file is not in this step's scope.

## Default message

`TranslationFailedError`'s default message is the fixed sentence **"The translation
failed. Showing the original."** Step `002` passes cause-specific sentences.

## Test shape

- `test_translation_schema.py` covers DoD-1, 2, 4 and 5. DoD-1 inspects with SQLAlchemy
  `inspect(engine)` (columns, foreign keys, unique constraints) on a `create_all` database.
- `test_translation_invalidation.py` covers DoD-6 to 9 against `edit_message_text` directly,
  with raw-inserted users, character, session, messages (partner settled, buried, turn,
  zone) and `translations` rows.
