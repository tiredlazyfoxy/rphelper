# Step 002 — `services/translation.py`: the translate flow

## Goal

Add the translation service. It does the eligible-row read, resolves the target language
(with the English fallback), reads the cache, calls the model through 021's `chat_stream`
with the deltas joined, maps failures, writes the cache behind the disconnect probe and
the stale-text guard, and logs (D2–D10).

## Source files

backend/app/services/translation.py

## Test files

backend/tests/test_translation_service.py

## Interface intent

**`app/services/translation.py`** (new)

- **The fallback target-language constant**: one module-level name whose value is the
  literal `"English"` (D3). Its name is frozen in `## Skeleton`.
- **`TranslationResult`**: a frozen value with `message_id` (int), `target_language`
  (string), `text` (string) and `cached` (bool). `001`'s `TranslationResponse` builds from
  its attributes.
- **A disconnect-probe type**: an async callable taking nothing and returning a bool
  (`true` = the client is gone). It is defined here so the service stays FastAPI-free.
- **`get_cached_translation`**: takes a connection, the caller's user id, a message id and
  a target language. It returns the cached text, or none, for that exact pair, scoped to
  the caller. It writes nothing and leaves no transaction open.
- **`translate_message`**: async. It takes:
  - the engine;
  - the caller's user id;
  - the message id;
  - the request timeout in seconds;
  - the chat-client factory (021 `003`'s type);
  - the disconnect probe.

  It runs D8's three phases and returns a `TranslationResult`:
  1. **Read** on a short-lived connection:
     - the eligible-row read (D6; else `MessageNotFoundError`);
     - the target language from `get_session_configuration` for the row's session (D3);
     - the cache lookup. A hit returns `cached` true, with no model resolution and no call.
     - On a miss, `resolve_model_for_use`, then `open_chat_client`. Their errors propagate
       unchanged.

     The connection is closed before the call.
  2. **Call** with no connection held: `chat_stream(model name, [system, user], no
     tools)`. Content deltas are joined, while reasoning and tool-call deltas are
     ignored. The iterator is always closed. The joined text goes through 021 D4's
     `<think>` strip. An `LlmUnreachableError`, or a result that is empty after stripping
     and trimming, raises `TranslationFailedError` with the cause sentence
     (`002.context.md`).
  3. **Write:** the probe is awaited once. A disconnect means no write. Otherwise one short
     transaction inserts the row, but only if the message is still the caller's settled
     partner row with the same text (D9), and ignoring a unique-key conflict (D8). It
     returns `cached` false with the produced text, whether or not a row was written.

  It logs one line per outcome, ids and durations only (`002.context.md`).
- The module imports no `fastapi`. Its `app.services` imports are limited to
  `configuration` (017), `llm_registry` (021 `003`), `llm.chat` (020 / 021) and
  `llm.client` (for `LlmUnreachableError` and the delta type, wherever 021 `003` placed
  them).

## Definition of done

1. `[test]` The user's preferred language is "Russian" and the session sets none. A
   settled partner row has text "She waves.\n\n*smiles*". The fake yields content "При",
   then "вет". The result is text "Привет", target_language "Russian", cached false, with
   the row's id. One `translations` row exists with that message_id, "Russian", "Привет"
   and the caller's user_id. The fake was called with the session's captured model name
   and **no tools**. It received exactly two messages: a `system` message whose content
   contains "Russian", then a `user` message whose content equals the row text exactly. The
   factory received the server's base URL and the given timeout. (US-045.AC-1, D2, D8)
2. `[test]` A second call for the same row returns cached true, the same text and target
   language, and calls neither the factory nor the client. (US-046.AC-1, UC-041)
3. `[test]` After the first call caches the row, the session's model is disabled (and,
   separately, every model is disabled). A call still returns the cached text with cached
   true. (D8)
4. `[test]` A session override of the preferred language, "French", beats the user's
   "Russian". With a "Russian" row already cached, the call is a miss: it calls the model
   with "French" in the system message and stores a second row under "French". Both rows
   remain. (R1, R8 cache key)
5. `[test]` With no preferred language at user or session level, the target language is
   "English": the result and the stored row say "English", and the system message contains
   "English". A second call is a cache hit. (D3)
6. `[test]` Each of the following raises `MessageNotFoundError`: another user's settled
   partner row, a zone row, a buried row, a settled turn, a settled decision, and an id that
   exists for nobody. In each case the factory is never called and no `translations` row is
   written. (D6, R5)
7. `[test]` A fake raising `LlmUnreachableError` before any delta, and one raising it after
   yielding "При", each raise `TranslationFailedError`. Its `code` is `translation_failed`
   and its `detail` is `{"message_id": "<the id as a string>"}`. No `translations` row
   exists afterwards, and the fake's iterator was closed. (US-048.AC-1, D5)
8. `[test]` After DoD-7's failure, a call with a succeeding fake calls the model again and
   caches its result: the failure memoised nothing. (US-048.AC-2)
9. `[test]` Each of these raises `TranslationFailedError` and writes no row: a fake
   yielding no content at all; one yielding only reasoning deltas; one yielding content
   `"   \n"`; one yielding content `"<think>only reasoning</think>"`. (D5, D10)
10. `[test]` A fake yielding a reasoning delta "plan", then content "<think>x</think>\n\n",
    then "Hola" returns and stores "Hola". (D2, D10)
11. `[test]` The 017 / 021 errors propagate unchanged, and none of them writes a row:
    - no enabled model on the instance → `NoModelEnabledError`;
    - no captured model → `ModelNotChosenError`;
    - a disabled captured model → `ModelNotEnabledError` with `detail.level` "session";
    - a server whose `api_key_ref` names an unset variable → `secret_ref_missing`.

    The client is never called. (D5, R4)
12. `[test]` **Best-effort stop, the disconnected-before-write path only.** With a probe
    that reports a disconnect, the call still returns the produced text with cached false,
    and **no** `translations` row is written. The probe was awaited exactly once, after the
    fake's iterator finished: the fake and the probe record into one ordered list. With a
    probe reporting no disconnect, the row is written (DoD-1). This test does not claim
    that a disconnect after the probe is handled. (US-133.AC-2 best-effort half, D4)
13. `[test]` Concurrent first flicks. The fake's `chat_stream` raw-inserts the
    `(message_id, target_language)` row with text "Earlier" on its own connection before
    yielding. The call returns its own produced text with cached false, raises nothing,
    and exactly one row exists for the pair (the "Earlier" one). (D8)
14. `[test]` Concurrent edit. The fake's `chat_stream` raw-updates the message's text
    before yielding. The call returns the produced text and writes **no** row. A following
    call is a miss that sends the **new** text as the user message. (D9, US-111.AC-2)
15. `[test]` Translations never reach context. 020's `assemble_context` for the session
    gives an equal result (system prompt and messages) before and after a successful
    translation is cached. The translated text appears in neither. (US-047.AC-1, R8)
16. `[test]` Source conventions:
    - `services/translation.py` imports no `fastapi`;
    - the sources of `services/context.py` and `services/compose.py` neither import
      `app.services.translation` nor contain the substring `translations`;
    - the fallback constant named in `## Skeleton` equals `"English"`.

    (R8, D3)
17. `[test]` Logging (a loguru sink captures records):
    - a miss logs a line containing `translate cached=false message=<id as decimal>` and
      `ms=`;
    - a hit logs `translate cached=true message=<id>`;
    - no record, on any path in DoD-1/2/7, contains the source text or the translated
      text. The tests use distinctive marker strings.

    (`deployment.md` redaction rule)
18. `[test]` No lock is held across the model call. Inside the fake's `chat_stream`, a
    write transaction on a separate connection (an insert into an unrelated table) commits
    without a "database is locked" error. (D8)
