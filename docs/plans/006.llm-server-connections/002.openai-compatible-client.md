# Step 002 — The one OpenAI-compatible client, and `httpx` promoted to a runtime dependency

## Goal

Build the single piece of code that talks to an OpenAI-compatible server — construction
from a base URL and a resolved credential, the models-listing probe with its four-value
outcome, and `embed` — and promote `httpx` out of the dev dependency group, which this
step must do because it is the first outbound-HTTP code in `app/` (`context.md` D3).

```
backend/pyproject.toml

backend/app/services/llm/client.py
```

## Interface intent

**`backend/pyproject.toml`** — move `httpx` from `[dependency-groups] dev` into the
project's runtime `dependencies`, keeping a compatible version constraint. It stays
available to `TestClient` exactly as before; nothing else in the file changes, and no new
dependency is added.

**`backend/app/services/llm/__init__.py`** — the package marker for
`backend-structure.md`'s `services/llm/` package. Empty of logic. `frames.py` and
`tools.py` are `019`/`021`'s and are not created.

**`backend/app/services/llm/client.py`** — the one client, parameterised by base URL and
credential, with **no branch on provider kind anywhere** (`context.md` D5).

- **A frozen probe-outcome value** — the typed result of one models-listing call: the
  outcome, one of `reachable` / `unreachable` / `auth_failed` / `model_list_empty`; the
  model names the server offered, empty for every outcome but `reachable`; and an optional
  short provider-side note for diagnostics, which **no caller persists**
  (`context.md` D6). The four values are a closed set declared here and reused by the
  registry, the router model and the frontend; nothing downstream re-declares them.
- **The client class** — constructed from the base URL, the already-resolved credential
  (or none) and the timeout in seconds. It resolves **nothing**: `resolve_secret` is the
  registry's call, made before construction, so a `secret_ref_missing` is raised before
  any network object exists. It composes the request URL from the base URL and the
  OpenAI-compatible path, tolerating a base URL written with or without a trailing slash
  and with or without a `/v1` suffix already present, and sends the credential as a
  **bearer** header when there is one and no authorization header at all when there is
  not.
- **A probe operation** — issues the models-listing `GET`, classifies the result into the
  outcome value above per `context.md` D6's table (2xx with at least one name →
  `reachable`; 2xx with none → `model_list_empty`; 401 or 403 → `auth_failed`; a transport
  failure, a timeout or any other non-2xx → `unreachable`), and **raises nothing**. A
  response body that is 2xx but unparseable, or shaped unlike a models listing, is
  `unreachable` rather than an exception — the probe's contract is that it always answers.
  Model names are read from the listing's entries and returned in the order the server
  gave them.
- **An embed operation** — posts one or more input strings to the embeddings path for a
  named model and returns the vectors as lists of floats. It **raises** `llm_unreachable`
  for a transport failure, a timeout, or any non-2xx, with `detail` carrying a structured
  reason (`unreachable` or `auth_failed`) and never a request body; and it raises the same
  error with a distinct structured reason when the response is 2xx but carries no usable
  vector, which is the "this is not an embedding model" case `context.md` D2 needs to
  block a designation. It never returns an empty vector as a success.
- Both operations use **`httpx.AsyncClient`** and are `async`; the client opens and closes
  its transport per call or as an explicit context — either is acceptable, but a module-level
  long-lived client is not, because the timeout and the credential vary per server.

**`chat_stream` is not written and not stubbed** (`context.md` D3). Nothing in this module
imports `fastapi`, names a status code, or touches the database.

## Definition of done

1. `[test]` `httpx` appears in `backend/pyproject.toml`'s runtime `dependencies` and no
   longer only in the dev group, with a version constraint compatible with the one it had.
   (`context.md` D3 — **no product id**)
2. `[test]` The client is constructed from a base URL, an optional already-resolved
   credential and a timeout, and **performs no secret resolution of its own** — given no
   credential it sends no authorization header at all, and it never reads the process
   environment. (`backend-structure.md`'s secret-pointer pattern — **no product id**)
3. `[test]` Given a credential, every request the client issues carries it as a bearer
   authorization header. (UC-010)
4. `[test]` The request URL is composed correctly from a base URL given with a trailing
   slash, without one, and with a `/v1` segment already present — the same three forms
   produce the same endpoint, with no doubled or missing separator. (UC-010 — the admin
   supplies "its details" free-hand)
5. `[test]` A 2xx models listing naming at least one model yields the `reachable` outcome
   with those names, in the order the server gave them. (US-013.AC-1)
6. `[test]` A 2xx models listing naming no models yields `model_list_empty` with an empty
   name list. (`admin-surfaces.md`'s result taxonomy; `context.md` D6 — **no product id**)
7. `[test]` A **401** and a **403** each yield `auth_failed`. (`context.md` D6 — **no
   product id**)
8. `[test]` A transport failure, a timeout, a 500, and a 2xx body that is unparseable or
   not shaped like a models listing each yield `unreachable`, and the probe **raises
   nothing** in any of those cases. (US-013.AC-2)
9. `[test]` The probe honours the timeout it was constructed with: a server that does not
   answer within it yields `unreachable` rather than hanging. (US-013.AC-2;
   `context.md` D13)
10. `[test]` `embed` returns one vector per input string for a 2xx embeddings response,
    preserving input order. (UC-013; `llm-and-streaming.md`'s client sketch)
11. `[test]` `embed` raises `llm_unreachable` for a transport failure, a timeout, a 401/403
    and any other non-2xx, with a structured `detail` naming the reason and carrying **no
    request body and no credential**. (`context.md` D2, D7; `backend-structure.md`'s error
    table)
12. `[test]` `embed` raises `llm_unreachable` with a distinct structured reason when the
    response is 2xx but carries no usable vector, and returns no empty vector as a success
    — the case that must block a designation. (`context.md` D2 — **no product id**)
13. `[test]` The module contains **no branch on provider kind** — no `llamaswap` or
    `openai` literal reaches any conditional, and the same code path serves both.
    (`llm-and-streaming.md`, "One OpenAI-compatible client"; `context.md` D5 — **no
    product id**)
14. `[test]` The module imports no `fastapi` symbol, names no HTTP status code of its own
    beyond classifying a provider response, and issues no SQL.
    (`backend-structure.md`'s routers-versus-services split — **no product id**)
15. `[test]` `chat_stream` does not exist on the client in any form, stubbed or otherwise.
    (`brief.md`'s Out list; `context.md` D3 — **no product id**)
16. `[manual/live]` Against a real llamaswap server and a real OpenAI endpoint, the probe
    answers `reachable` with a plausible model list, a deliberately wrong key answers
    `auth_failed`, and a deliberately wrong host answers `unreachable`.
17. `[manual/live]` `mypy app`, `ruff check .` and `pytest` all pass from `backend/`, and
    the backend still starts with the promoted dependency installed.
