# Fast feature 016 — own-text-muted — context

## What and why

User request: "To distinguish assistant from my texts — make my text light gray" in
the chat (the current zone). Built in code as a technical decision, no product or
architecture change now (DEC-F016-1). Mechanism, reach and test hook are
DEC-F016-2..4 — read them; this plan does not restate them.

Requirements cited (no AC covers the tone itself): US-114.AC-2, US-115.AC-1,
US-116.AC-1 (role-aware zone rows, 022 `006`); US-040.AC-1 (Discussion group,
022 `007`).

## Files involved

- `frontend/src/app/ZoneList.tsx` — `ZoneMessage` (exported, `observer`) and
  `ZoneList`. `ZoneMessage` takes the stream state, the message, an optional abort
  signal and `editable` (default true). It picks a `body` by role: assistant →
  `AssistantBody` (not live), tool → `ToolBlock`, otherwise (user) → `MessageBody`
  with variant `"painted"`. The row is a `Box component="li"` holding a `Stack`:
  a header `Group` (author label as dimmed small bold `Text` — "You" /
  "Assistant" / "Tool" — plus edit and delete icon buttons), then the body, or the
  edit `Textarea` while editing. The list is `Box component="ul"
  aria-label="Zone messages"`.
  **The working tree carries uncommitted fast/014 (message delete) edits in this
  file; plan and code against the on-disk state, do not revert them.**
- `frontend/src/app/MessageBody.tsx` — read-only for this feature. Props: text and
  variant (`"painted" | "decision" | "plain"`), react-markdown, no colour
  pass-through. Colour set on an enclosing element inherits into the prose; the
  fragment chip (`data-paren="fragment"`) and OOC card (`data-paren="ooc"`) set
  their own colour.
- `frontend/src/app/DiscussionGroup.tsx` — read-only. Renders each buried row as
  `ZoneMessage` with `editable={false}`, so it inherits the change.
- `frontend/src/app/StreamRecord.tsx`, `LiveMessage.tsx` — not touched
  (DEC-F016-3).

## Constraints

- TypeScript only; Mantine style props only — no new stylesheet, no CSS module, no
  inline `<style>` (`ui-conventions.md` Accessibility floor; `tests/stylesheets.test.ts`).
- Test conventions bind to `data-*` markers and accessible names, never to computed
  colours.
- Suites that must stay green: `frontend/tests/app/ZoneList.test.tsx`,
  `ZoneListAssistant.test.tsx`, `MessageBody.test.tsx`, `DiscussionGroup.test.tsx`,
  `StreamRecordDiscussion.test.tsx`, `tests/stylesheets.test.ts`.
- Commands (from `frontend/`): `npm test`, `npm run typecheck`, `npm run build`.
- The new test file needs a glossary line in `frontend/tests/app/CLAUDE.md`; that
  glossary is fenced (agent-ready) and regenerated by its own tooling — not edited
  by this feature.
