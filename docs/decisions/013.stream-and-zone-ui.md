# Decisions — 013.stream-and-zone-ui

**Stage:** 002.record · **Feature:** 013.stream-and-zone-ui

The session screen's stream: the record and the current zone rendered, the composer with its kind switch, Send / Settle / Discard / re-open, partner paste filing and zone edit in place. The behaviour sits in `workspace-shell.md` and `ui-conventions.md`. These entries record how it was realised and why, below architecture altitude. Several were later superseded (021, 014, fast/011, fast/014); those are kept as short entries so the plan-local ids still resolve.

### DEC-013-1 — Settle preview is a client-side port of the parens rules
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D1
- **Date:** 2026-10-02 · **Decided by:** user
- **Question:** How does the composer preview what a settle would produce?
- **Decision:** A pure client-side port of 012 D8's parens rules (`app/parens.ts`). The preview targets what Settle would settle: the draft if it is non-blank, otherwise the last zone row. It shows one of three fixed sentences. It is never authoritative; the server's settle is the truth (R12).
- **Reason:** A preview route would add a route and a round trip per keystroke for a display hint.
- **Rejected:** a server preview route (cost per keystroke).
- **Lands in:** `frontend/src/app/parens.ts`, the stream composer.
- **Cites:** `session-stream.md` (( )) seam; `workspace-shell.md` composer.

### DEC-013-2 — Settle with composer text appends, then settles
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D2
- **Date:** 2026-10-02 · **Decided by:** user
- **Question:** What does Settle do when the composer holds text?
- **Decision:** It posts the text to the zone, then posts settle, then re-reads both lists. A failed append skips the settle and the text stays in the composer. A failed settle leaves the row in the zone. Settle is disabled (not hidden) when the zone is empty and the composer blank, while busy, and on *partner*. It is never gated on an assistant reply.
- **Reason:** One gesture for "this is my turn, file it". Each failure leaves the text where the user can see and retry it.
- **Lands in:** `frontend/src/app/streamState.ts`, `frontend/src/app/Composer.tsx`.
- **Cites:** `workspace-shell.md` composer.

### DEC-013-3 — Discard only for an empty zone with a blank composer
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D3
- **Date:** 2026-10-02 · **Decided by:** user
- **Question:** When is Discard offered, and what does it do?
- **Decision:** It is present only when the zone is empty and the composer blank; otherwise it is absent. It clears whitespace, resets the kind switch to its default, and sends no request. Glyph `IconX`, labelled "Discard empty zone".
- **Reason:** It discards an empty turn, not content.
- **Rejected:** `IconTrash`, which promises the deletion of content that does not exist.
- **Lands in:** `frontend/src/app/Composer.tsx`.
- **Cites:** `ui-conventions.md` icon table.

### DEC-013-4 — Re-open on the last entry; accepted imprecision
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D4
- **Date:** 2026-10-02 · **Decided by:** user
- **Question:** Where is re-open offered, given the client cannot see whether the last entry is re-openable?
- **Decision:** `IconArrowBackUp` "Re-open last entry" on the last entry. It is present only when the zone is empty and that entry is not *partner*; the composer does not gate it. Accepted imprecision: it also shows on a lone, directly settled entry. There `nothing_to_reopen` is refused, reported through `notifyFailure`, and followed by a re-read.
- **Reason:** Exact gating needs data the client lacks. The refusal is harmless.
- **Rejected:** exact gating now.
- **Flip condition:** a buried-read route (022) makes exact gating possible.
- **Lands in:** `frontend/src/app/SessionStream.tsx`.

### DEC-013-5 — Bodies rendered with react-markdown; three MessageBody variants
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** 004
- **Plan-local:** 013 D5; 004.context data-paren contract, chips inline, blockquote
- **Date:** 2026-10-02 · **Decided by:** user
- **Question:** How are message bodies rendered, and where is (( )) painting shown?
- **Decision:** `react-markdown` (^10.1.0) renders bodies. MessageBody has three variants: *painted* (zone, any role), *decision card* (by kind), *plain* (settled partner or turn). Painting happens in the zone only and is display only. Painted spans carry `data-paren="ooc"` or `data-paren="fragment"`. Prose paragraphs flow inline around the chips. A blockquote renders with no icon.
- **Reason:** A data attribute marks the span without changing what assistive technology reads.
- **Rejected:** `aria-label` on the chip, which overrides the element's text.
- **Lands in:** the MessageBody component under `frontend/src/app/`.
- **Cites:** `ui-conventions.md`; `session-stream.md` (( )) seam.

### DEC-013-7 — Partner paste files immediately; a failed paste is not re-inserted
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** 006
- **Plan-local:** 013 D7; 006.context paste handling, disabled-not-hidden vs absent
- **Date:** 2026-10-02 · **Decided by:** planner
- **Question:** What does a paste do on *partner*?
- **Decision:** It files immediately as a partner entry. The default is prevented on *partner* only. The position is read at paste time, and the text comes from `getData("text/plain")`. A blank paste sends nothing. Send on *partner* files the typed text. There is no zone precondition (012 D14). A failed paste is reported and not re-inserted. Controls follow one rule: Settle is disabled, not hidden; Discard and re-open are absent when they don't apply.
- **Reason:** The clipboard still holds the failed text. Re-inserting it would put partner text where my-turn text is composed.
- **Rejected:** restoring the failed paste into the composer.
- **Lands in:** `frontend/src/app/Composer.tsx`, `frontend/src/app/streamState.ts`.

### DEC-013-8 — Default kind alternates; the override holds until the record changes
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D8; 002.context id-sequence compare
- **Date:** 2026-10-02 · **Decided by:** planner
- **Question:** Which kind does the switch default to, and when does a manual override reset?
- **Decision:** The default alternates from the last partner or turn entry, skipping decisions. An empty record defaults to *my turn*. A manual override holds until the entries' id sequence differs (in length or at any position) or until Discard. Zone-only re-reads never clear it.
- **Reason:** A wrong *partner* default files a block that cannot be re-opened. A wrong *my turn* default costs one click.
- **Lands in:** `frontend/src/app/streamState.ts`.

### DEC-013-10 — Zone edit in place, committed on blur
- **Status:** accepted; blank-commit case superseded in part by DEC-F014-10
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D10
- **Date:** 2026-10-02 · **Decided by:** planner
- **Question:** How is a zone message edited?
- **Decision:** `IconEdit` "Edit message" swaps in a Textarea "Edit message text". Blur commits. An unchanged text sends no request. A blank text now deletes the row (DEC-F014-10). The PATCH response replaces that row. On failure: `notifyFailure`, a zone re-read, and the editor stays open with the typed text. The edit flag and the draft are component-local. The control is always visible, with no stylesheet.
- **Reason:** One place, one gesture. A failure never loses typing.
- **Lands in:** `frontend/src/app/SessionStream.tsx`.

### DEC-013-15 — Failure and busy posture
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** —
- **Plan-local:** 013 D15
- **Date:** 2026-10-02 · **Decided by:** planner
- **Question:** How are load and mutation failures shown, and what does "busy" cover?
- **Decision:** A load failure is shown inline: "Could not load the stream" plus Retry. Mutation failures go to `notifyFailure`, followed by the re-read in DEC-013-17. The UI never branches on error codes, and success raises no toast. `busy` covers send, file, settle and re-open. Edits don't set it.
- **Reason:** Edits are local to one row and must not freeze the composer.
- **Lands in:** `frontend/src/app/streamState.ts`.
- **Cites:** `ui-conventions.md` async feedback.

### DEC-013-16 — Client blank test uses JS trim
- **Status:** accepted

- **Decision:** The client uses JS `trim()`. It differs from Python `isspace` on U+001C–U+001F and U+0085 (blank only in Python) and on U+FEFF (blank only in JS). This is accepted, because the client's test is display only and the server decides.

### DEC-013-17 — Load, re-read and abort rules
- **Status:** accepted
- **Stage:** 002.record · **Feature:** 013.stream-and-zone-ui · **Step:** 002, 003
- **Plan-local:** 002.context paired load; 003.context re-read table, draft clear, abort posture
- **Date:** 2026-10-02 · **Decided by:** planner
- **Question:** How does the stream load and refresh, and how does it behave on abort?
- **Decision:**
  - **Load.** Both GETs are issued together. State is written once, after both succeed.
  - **Re-reads.**
    - Append → zone.
    - File → entries.
    - Settle → both (a failed append re-reads the zone only).
    - Re-open → both.
    - Edit: success → none; failure → zone.
  - Ids returned by settle or re-open are not used to patch local state.
  - **Draft.** The draft is cleared only if it is unchanged since it was sent.
  - **Abort.** The signal is checked after every await. Nothing is written once aborted, `busy` included. An abort is never notified.
- **Reason:** Re-reads keep the client honest without patch logic. The abort rules stop a late response from writing into an unmounted screen.
- **Lands in:** `frontend/src/app/streamState.ts`.
